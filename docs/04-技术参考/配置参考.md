# 配置参考

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：环境变量、`app_settings` 设置键、模型协议、Keyring、受管目录与构建配置<br>
> 最后更新：2026-10-28（单 Pi 分支同步；本轮未复跑产品测试）

> 复核状态（2026-10-25）：环境变量表由 `main@763a019` 中 `std::env::var*` 调用与 `*_ENV` 常量整理（`apps/desktop/src-tauri/src`、`crates/fox-agent-backend/src`），只列生产代码读取的变量，测试 / 评测专用变量单列；`app_settings` 键来自 `commands/agent_backend_routing.rs`、`external_model.rs`、`local_knowledge_storage.rs`、`database/repositories.rs`；构建配置来自 `package.json`、`apps/desktop/vite.config.*`、`tauri.conf.json`。

## 结论

- 敏感凭据只进系统 Keyring；产品事实与非敏感设置进 SQLite（`app_settings` 等表）；可重建资源用文件缓存；开发与管理员覆盖用环境变量。
- 驱动配置以当前支持列表为准：`FOX_EXTERNAL_BACKENDS` 仅做旧值解析和诊断，不能启用退休后端；历史外部权限变量不构成当前执行授权。
- 新 Run 和子 Run 一律走 **Authoritative + PiNative**，没有执行路径开关：`FOX_EXECUTOR_ROUTE` 已删除，`FOX_KERNEL_MODE` 不再决定新 Run 路径，失败不回退。

```mermaid
flowchart TD
    ENV["环境变量（启动时读取）"] --> HOST["Tauri Host / 历史驱动兼容配置"]
    UI["设置界面"] --> DB[("SQLite：app_settings 与业务表")]
    UI --> KEY["系统 Keyring：API Key、Token、MCP 凭据"]
    UI --> LS["前端 localStorage：界面偏好"]
    FILE["受管目录"] --> ASSET["Session / 附件 / Skill / 缓存"]
```

## 环境变量

### 数据与执行

| 变量 | 取值与默认 | 作用 | 代码 |
| --- | --- | --- | --- |

### 外部 Agent（pi、DeepSeek、Codex）

这三条会话级外部驱动已退休。以下变量用于兼容诊断或共享资源，不能用来恢复驱动执行：

| 变量 | 当前含义 |
| --- | --- |
| `FOX_EXTERNAL_BACKENDS` | 保留旧取值解析与未知项报告；`all`、列表、`0` 等均不能启用退休后端 |
| `FOX_EXTERNAL_FULL_ACCESS` / `FOX_EXTERNAL_FULL_ACCESS_FORBIDDEN` | 旧外部权限兼容项；本分支不提供对应的新会话执行入口 |
| `FOX_EXTERNAL_EXTRA_DOMAINS` / `FOX_PI_PROVIDERS` | 旧外部 SRT 网络策略字段，SRT 已删除，不再生效；Fox 不用沙箱 |
| `FOX_EXTERNAL_ENV_PASSTHROUGH` / `FOX_PI_ACP_PROGRAM` / `FOX_DSH_PROGRAM` / `FOX_CODEX_ACP_PROGRAM` | 兼容模块或独立后端测试使用，不能绕过退休准入 |
| `FOX_CODEX_API_KEY` / `FOX_PI_BIN` | 旧后端私有配置/启动内部名称，不是用户启用当前驱动的步骤 |
| `FOX_AGENT_RUNTIME_ROOT` / `FOX_RUNTIME_ROOT` / `FOX_RUNTIME_VERSION` | 受管运行时位置/版本配置（外部 Agent 计划在阶段三恢复时使用；运行时包不再含 SRT） |

受管资源与安装边界见[构建与发布](../06-运维指南/构建与发布.md)。驱动和阶段状态见[单 Pi 主线状态](../01-项目概览/单Pi主线状态.md)。

### 本机资料库辅助进程（内部）

## app_settings 设置键

`app_settings(key, value, updated_at)` 保存非敏感设置。读取失败或值无法解析时使用安全默认值，不阻止数据库打开。

| 键 | 值 | 写入位置 | 说明 |
| --- | --- | --- | --- |
| `agent_backend.default_backend` | 历史 `fox/pi/deepseek/codex` 值保留 | 兼容偏好接口 | 实际新会话只用 `fox`；界面显示固定说明；显式请求退休值仍拒绝 |
| `agent_backend.new_external_full_access` | `1` / `0` | 旧设置，界面已移除 | **已弃用**：不再决定新会话权限，也不能启用退休驱动 |
| `agent_backend.codex_responses_probe` | JSON（base URL 与探测结果） | `agent_backend_probe_codex_responses` | 最近一次对模型服务 `POST {base}/responses` 的探测缓存 |
| `agent_backend.native_mode.conversation.<会话 id>` | 原生权限选项 id | `agent_backend_native_permission_set` | 该外部会话选择的原生权限 |
| `agent_backend.native_mode.last.<后端>` | 原生权限选项 id | 同上 | 该后端历史上最近一次选择；当前不作为可运行驱动的新会话初值 |
| `agent_backend.native_mode.draft_full.<后端>` | `1` / `0` / 空 | 同上 | 旧外部会话草稿的完全访问值；当前无对应驱动准入 |
| `model.protocol.<供应商 id>.<api_type>.<协议 id>` | 规范 JSON（base URL、模型 id、供应商更新时间） | 外部 Agent 模型连接测试（`agent_backend_model_connection`） | 连接已验证的缓存；供应商被编辑后自动失效 |
| `local_knowledge_storage_path` | 路径 | 设置 → 资料库 → 本机存储（存储迁移完成后写入；`local_knowledge_storage_path_reset` 清除） | 本机资料库根目录；未设置时为 `<data>/local-knowledge`。已设置但不可用时降级打开，不改用默认目录 |
| `knowledge_preview_cache_limit_bytes` | 字节数；默认 500 MiB，范围 250 MiB–5 GiB | `knowledge_preview_cache_limit_set` | 知识预览缓存容量 |
| `user_profile` | JSON | `user_profile_save` | 用户资料 |
| `host_data_root_instance_uuid` | UUID | `Database::open` 首次写入 | 数据根实例标识，写入后不可替换 |

其他设置有专用表：通知偏好在 `notification_preferences`（单行），模型供应商在 `model_providers`（v97 起含 `protocol_profiles`），知识库服务、MCP、Hook、Skills 见下文。

前端 localStorage 偏好（不在 SQLite）：「新项目权限」`fox.preferences.defaultPermission`（默认「询问」）等。

旧 `agent_backend.native_mode.*`、`new_external_full_access`、探测与协议分配字段保留兼容数据；上表的历史用途不表示退休驱动仍可执行。设置页不再展示退休驱动的默认原生权限。

## 模型配置

供应商字段：名称、Base URL、API Type、启用、默认、`protocol_profiles`（v97，JSON 数组）；模型字段：modelId、显示名、contextWindow、maxOutputTokens、supportsImageInput、默认。API Key 不进 SQLite，在系统凭据库中按 base URL 保存。

每个协议配置（`crates/fox-agent-backend/src/provider_protocol.rs` 的 `ProtocolProfile`）含 `id`、`apiType`、`baseUrl`、`modelId`、`backends`、`separateCredential`。历史后端适配器的协议兼容表（`supports`，不授予驱动执行权；当前真实 Pi 端点另行验证）：

| Agent | 支持的 API Type |
| --- | --- |
| Fox | `openai-completions`、`anthropic-messages` |
| pi | `openai-completions`、`anthropic-messages`、`openai-responses` |
| Codex | `openai-responses` |
| DeepSeek | `anthropic-messages` |

模型服务的连接测试（`model_service.rs`）支持这三种协议。Runtime 正忙时更换模型配置会返回 `model.runtime_busy`。

## 知识库服务配置

字段：名称、Base URL、enabled、连接类型、最近状态 / 版本 / 延迟。Token 使用 Keyring。产品层称「知识库服务」，代码 / 数据库兼容名仍为 yuxi。

## 项目权限

Fox 会话有四档执行方式：只读 / 询问 / 自动 / 完全访问，存储为 `read_only` / `ask` / `allow`（界面名「自动」）加 `conversations.full_access`；在「设置 → Agent → 项目权限」修改，新会话创建时复制项目当前值，之后两者独立。该值只控制 Fox Host 审批引擎，Fox 不用沙箱，放行的命令以当前用户身份执行。外部 Agent 权限值保留兼容，计划在阶段三恢复时映射到各自原生档位；见[权限参考](权限参考.md)。项目路径失效时 status 变为 `missing` 或命令返回不可用。

## 扩展源与 Lifecycle Hook 配置

SQLite 的 `mcp_servers` 保存 name、`transport`（`stdio` / `streamable_http` / `openapi`）、command/args、endpoint、OpenAPI definition、enabled 和健康状态；stdio 环境变量或 HTTP Header 保存到 `com.fox.agent.mcp` Keyring。MCP 参数必须是字符串数组，凭据必须是字符串映射。HTTP 端点只允许 HTTP/HTTPS；Streamable HTTP 必填 endpoint，OpenAPI 可使用显式 endpoint 覆盖或规范 `servers[0].url`。

`lifecycle_hooks` 保存事件、matcher、动作、reason、priority 和 enabled。`before_tool` 可使用 `block|require_approval|annotate`；其他事件只允许 `annotate`。配置不接受脚本、Shell、webhook 或参数改写代码。管理入口：插件中心「策略」和「设置 → 插件 → 策略」。

## Skills 配置

目录为 `<data>/skills/<id>/SKILL.md`，启用项记录在 `agent_runtime_config`。Skill 变更需重新扫描；无效 Skill 不注入 Prompt。

## 构建配置

- 工作区：pnpm 11.7.0（根 `package.json` 的 `packageManager`）。
- 前端：Vite 6，开发地址 `127.0.0.1:1421`。
- Tauri：主窗口 1120×768，最小 600×560，无系统装饰（`tauri.conf.json`）；应用版本 0.1.0。
- Sidecar：`pnpm runtime:build` 产出 `services/agent-runtime/dist` 并作为资源打包。
- 知识预览缓存：默认 500 MiB，设置范围 250 MiB 至 5 GiB（`maintenance.rs`）；单预览文件上限 500 MiB，分段读取 4 MiB。

## 配置变更原则

敏感配置用 Keyring；产品事实用 SQLite；可重建资源用文件缓存；开发与管理员覆盖用环境变量。新增配置必须说明作用域、默认值、校验、迁移、清理和诊断输出是否脱敏，并补到本页。

## 失败恢复与验证

- Keyring 写入失败时不得把密钥退回 SQLite 或明文文件，应保留旧凭据并返回错误（`model.credential_save_failed`、`mcp.credential_save_failed` 等）。
- 无效 URL、模型上下限、MCP/OpenAPI 参数、Hook 枚举和缓存容量在保存前拒绝。
- `FOX_KERNEL_ENGINE`、`FOX_RESOURCE_GATEWAY_READS` 取值非法时启动 Run 失败并给出提示，不静默回退。
- 应用设置缺失或无法解析时使用安全默认值；不得因此阻止数据库打开。
