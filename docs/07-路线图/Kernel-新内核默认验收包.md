# 新 Kernel 默认验收包

本包按用户 2026-09-10 的要求制作。安装后正常打开即可使用新 Kernel，无需 PowerShell 启动脚本或环境变量设置。

- 应用名：Fox Kernel Preview。
- 窗口标题：Fox 新 Kernel 验收版。
- 新建任务的内置默认执行方式：Authoritative Kernel；默认模型适配器仍为 Pi。
- 应用标识：`com.fox.agent.kernel-preview`，使用独立应用数据目录，旧 Fox 的测试任务不会自动带入。
- 仍可通过显式 `FOX_KERNEL_MODE=legacy` 做开发回退；普通新电脑不需要设置该变量。

## 新电脑怎么测

1. 安装包安装完成后，直接打开 **Fox Kernel Preview**。
2. 配置允许使用的模型，先测试普通问答。
3. 新建空的测试文件夹作为项目，要求创建一个文本文件。确认审批前没有文件，批准后才出现文件。
4. 测试取消任务，再退出程序重新打开，检查对话记录和任务状态。
5. 把测试结果或错误截图发回。测试通过后，再把普通版本也切成新 Kernel 默认；当前普通版本的默认设置尚未改变。

这是未签名的验收包。缺少 WebView2 时，安装器会联网获取运行组件。C++ 运行库已随包提供。无需迁移旧测试数据库。

构建入口：`pnpm tauri:build:kernel-preview`。`kernel-default` 编译特性决定无环境覆盖时的新任务默认模式，安装配置决定独立应用名和数据目录。已有持久绑定仍按原绑定运行。
