# Kernel 原生引擎验收与回退

更新：2026-09-09。本文件描述已实现的控制方式和待完成的发布条件，不代表已发布或已切换默认模式。

## 已实现的选择与冻结

进程未设置 `FOX_KERNEL_MODE` 时继续使用 Legacy。显式设置为 `authoritative` 后，新 Kernel Run 可通过进程级 `FOX_KERNEL_ENGINE` 选择 `pi`（默认）、`codex` 或 `deepseek_harness`。已有 Run 始终使用自己的持久绑定，不跟随新的环境设置改换引擎。

| 引擎 | 当前适配方式 | 要求与边界 |
| --- | --- | --- |
| Pi | 现有公开 SDK，独立一次性 worker | 保留现有支持范围；关闭 SDK 自动重试和自动压缩，由 Host 控制 |
| Codex | 原生 App Server、动态 Host 工具、原始历史注入 | 模型连接须为 `openai-responses`；`FOX_KERNEL_CODEX_BINARY` 须为本机绝对路径。首次准备冻结文件 SHA-256，每次调用验证，并探测 `environments`、`dynamicTools`、`ephemeral` 和 `thread/inject_items` 能力。程序升级导致哈希变化时旧 Run 不自动换版本 |
| DeepSeek Harness | 锁定 `0.1.2-rc.1` 的公开 `DeepSeekAdapter.stream` 和消息组装 API | 模型连接须为 `openai-completions`；目前支持文本、推理和工具历史，图片会在模型 I/O 前明确拒绝。推理设置只接受 SDK 支持的 off/low/high/max；不挂载其 Agent Loop、文件/终端执行器、会话存储或重试插件 |

原生适配器只接受已支持的冻结模型选项；不支持的 profile override 会拒绝执行，不能通过换成当前设置继续旧 Run。Codex 的原生推理条目与不透明状态保存到 Host 历史；跨引擎纯文本推理作为历史数据保留。原生多模态尚未完成云供应商验收。

Codex 使用独立临时 `CODEX_HOME`，不加载用户会话和全局配置。Native 模型代理只放行一次固定模型请求，供应商密钥仅在 Node 代理内使用；原生进程取得的是临时本机代理令牌。模型响应有大小上限，完整保存一次响应的工具批次后中断原生工具请求，避免串行调度只保留第一个提案。当前代理会先缓冲这一轮响应，因此不把 Codex 的临时预览称为实时逐 token 流。

所有资源提案仍由 Host 校验、审批和执行。Windows Host 为独立 worker 建立只覆盖自身进程树的 Job Object，取消、超时或释放 worker 时一起回收原生子进程。测试覆盖真实子进程树退出。

## 发布前应取得的证据

1. 对待发布提交执行远端 Windows CI，保留提交号与各任务结果。已新增 Kernel 核心、Rust/JavaScript 协议一致性和独立程序 worker 检查。CI 未配置原生 Codex 文件时相关用例会明确跳过，不能当作 Codex 准入已通过。
2. 从最终 Runtime 与桌面构建制作安装包，在隔离 Windows 环境验证安装、启动、v60→v61 迁移、已冻结 Pi Run 的恢复、原生引擎选择和程序升级后的版本拒绝。当前本地 DLL 测试复制目录不等同于安装验收。
3. 对明确授权的模型进行有界合成长会话测试；对企业连接器确定测试账号、业务对象、只读查询及可核对的回执。不得以本机合成 Provider 或连接器缓存状态代替真实服务结果。
4. 定义小时级负载的并发数、持续时间、延迟/失败与内存阈值后执行 soak。当前短时并发样本不代表生产容量。
5. 经发布负责人确认后再为限定用户/进程显式启用；先读任务，再由用户审批隔离写入。观察取消、重启恢复、结果不确定、对账及重复执行计数后扩大范围。

## 回退规则

- 停止向试运行进程分配新任务。对新启动进程撤去 authoritative 设置或设为 legacy，使之后创建的 Run 回到 Legacy。
- 已冻结的 Authoritative Run 不得改写 authority/engine、删除租约或转投旧引擎。让它按原绑定完成，或由用户取消；已派发但结果不确定的操作走核对入口。
- 核对后创建的是关联新 Run。默认只读；选择重新审批时清除全部旧 grants，后续写入和外部操作重新产生审批。人工确认不是原操作的系统执行证明。
- 运行数据库已经升级时，不直接覆盖成旧程序或回滚 schema。保留兼容当前 schema 的版本，以“仅新任务回到 Legacy”方式回退；如需数据库恢复，应先停写并按经过验证的备份恢复流程处理。
- 保留原数据库与核对证据，分别记录真实服务结果、构建/安装结果及远端 CI。只有这些结果明确通过后，才能宣告生产放量完成。

本轮未推送、未发布安装包、未切换默认权威模式，也未主动停止用户的 Fox。云复测因自动审批审查要求明确提供商与凭据使用范围而未执行，等待用户确认；真实企业范围和生产负载阈值尚未提供。
