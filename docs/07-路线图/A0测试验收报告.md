## 失败矩阵

| 路径 | 结果与证据 |
| --- | --- |
| proposed Goal 关闭/恢复 | proposed 状态由 SQLite 持久化；确认状态转换由 runtime_proposal_is_intercepted_and_user_confirmation_controls_activation 覆盖 |
| active Goal 收到无关消息 | Host 复用现有非终态 Goal，不创建或取消 Goal；work_mode_gate 复用分支与普通问答负向测试覆盖 |
| Sidecar 崩溃 | mark_run_interrupted_cascades_without_completing_the_task、failed_and_cancelled_run_events_interrupt_owned_tasks |
| App 关闭时 Task 仍在运行 | startup_audit_interrupts_tasks_owned_by_terminal_runs |
| 工具失败 / Task blocked | task_block_resume_and_skip_transitions_are_supported |
| 用户补充信息后恢复 | user confirmation Evidence 引用校验与 blocked -> in_progress 状态转换测试覆盖 |
| Evidence 文件删除 | deleted_artifact_file_becomes_missing_and_keeps_history、deleted_tool_call_evidence_becomes_missing_and_keeps_history |
| 代码版本变化 | evidence_validity_updates_without_deleting_history 覆盖 stale 状态且保留历史 |
| 用户取消 Goal | Goal 状态机测试覆盖取消；活动 Task 在同一事务中转为 interrupted |
| SQLite busy | sqlite_busy_retry_is_bounded 验证 5 次有界重试后返回可重试错误 |

## 性能基线

同一轮测试的 P95 实测结果：

| 指标 | 预算 | 实测 |
| --- | ---: | ---: |
| 含 500 Task 的会话 Goal 快照加载 | < 50ms | 2.14ms |
| 500 Task Goal 视图 SSR | < 120ms | 94.26ms |
| 单次状态更新事务 | < 20ms | 0.73ms |

性能测试会在失败消息和测试输出中打印本轮 P95；数值受机器负载影响，阈值仍以规格预算为准。

## 结论

A0 第 13 节完成定义均有自动化测试或上表中的明确验证证据。会话加载现直接返回 SQLite 中的 Goal、Task 和每 Task 最新 50 条 Evidence；前端模型、真实 Work Event 载荷和完成态展示已与该契约同步。
