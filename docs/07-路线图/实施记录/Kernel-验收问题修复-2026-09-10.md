# Kernel 验收问题修复（2026-09-10）

本轮针对用户在 `c836ab9` 新 Kernel 默认验收包中反馈的七项问题实施修复。普通版本的默认执行方式不变，修复包仍为独立的 Fox Kernel Preview。

## 修复内容

| 反馈 | 原因与处理 |
| --- | --- |
| 供应商图标下拉无反应 | 下拉浮层层级低于弹窗遮罩。提高 Popover 与 Select 的浮层层级，保留原有图标选择交互。 |
| 验证连接无反应 | 原先只有异步完成后的通知，缺少弹窗内状态。补上验证中、连接成功、连接失败提示及重复点击保护。 |
| 向导从第二步直接完成 | 原逻辑进入第三步后立即启动隐藏配置区的动画。去掉自动隐藏，第三步展示配置状态，由用户点击“进入 Fox”。 |
| 模型名称显示 configured-model | 模型供应商保存后，其他已挂载的模型状态未刷新。增加变更通知与刷新，配置占位符不再作为界面模型名称兜底。 |
| 取消后已输出内容消失 | 流式正文原先仅是内存预览。Host 在发出显示通知前保存当前片段，取消/失败后标记为 interrupted，重开数据库仍保留。最终响应使用相同消息身份替换草稿，避免重复和较长旧内容覆盖最终回复。 |
| 深度思考、工作步骤与工作动画缺失 | 补充供应商返回的 thinking 内容和 Kernel 工具状态的显示投影。运行状态继续驱动原有动画；没有返回思考内容的模型不会生成虚构思考。 |
| 生成 HTML 无法在 Fox 内预览 | Kernel 成功写入/编辑文件后登记文件卡片；项目文件与产物面板默认渲染 HTML，支持切换源码。iframe 仅启用脚本，不授予同源、弹窗或顶层导航权限。 |

显示内容不是执行凭据：流式片段不能完成任务、批准工具或替代原始模型响应恢复检查点。旧版本取消时未保存的内存片段不会被本次修复自动找回。

## 本地验证

- Rust Kernel 相关测试：101 通过、1 忽略。新增三个场景覆盖取消/失败后重开、最终短回复替换草稿、实际批准写入 HTML 后在续答期间取消；验证了真实临时文件、SQLite 中的文字/思考记录和文件卡片。
- 前端测试：211 通过；包含数据库草稿与流式显示去重、取消后的记录保留、最终响应覆盖旧文本。
- Runtime 源码专项：28 通过、1 跳过。Windows 打包 worker 专项：17 通过、1 跳过。跳过项需要外部 Codex 程序配置，其他模型调用使用本机合成服务。
- 共享协议：4 通过，生成绑定检查通过。
- 生产前端构建、包体预算与验收代码隔离检查通过。
- 独立浏览器验收页加载实际组件，连接和数据操作使用模拟服务：图标选择、连接等待/成功/失败、保存后模型立即变化、向导第三步停留、思考和工具步骤展示、工作动画 running 状态、HTML 点击交互与源码切换均通过。桌面 1200×800 和最小窗口 760×560 已检查，弹窗无横向溢出。
- HTML 验收页无法读取父页的模拟宿主对象。该项是浏览器中的隔离验证，不等同于完整 Tauri 实装安全验收。
- 界面检测器发现 9 项既有 CSS 提示，均不在本次新增样式中；未借此改动其他界面。

## 使用与范围

安装修复包前关闭 Fox Kernel Preview，再覆盖安装。应用名与标识保持不变，保留该验收版已有配置和对话，不要清理其数据目录。

复测重点：新增供应商 → 连接测试 → 完成三步向导 → 批准创建 HTML → 说明输出中取消 → 重新打开对话 → 点击文件卡片预览。

内置“浏览器”仍是手动网页预览与联网记录面板，并不是完整的网页自动操作引擎。部分远程网站禁止嵌入时需外部打开。本轮新增的本地 HTML 预览适用于单文件/内联资源页面；依赖同目录其他资源的完整站点仍需本地服务器或系统浏览器。未签名安装包、真实供应商以及其他电脑上的覆盖安装仍需用户复测；未推送或触发远端 CI。
