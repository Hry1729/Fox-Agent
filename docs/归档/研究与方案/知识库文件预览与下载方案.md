# Fox 知识库文件预览与下载方案

> 状态：已归档；当前预览架构和体验文档已吸收本方案。

> 2026-07-27 完整能力盘点、未完成项与优先级见 [产品与稳定性审计](./产品与稳定性审计-2026-07-27.md)。

更新日期：2026-07-26

## 目标

Fox 在不暴露 MinIO 凭证、不上传文件到第三方服务的前提下，提供原文件下载、本机打开和常见格式的只读预览。预览失败不能影响下载和知识库问答。

## 架构

1. 知识库服务只负责鉴权、原文件元数据和严格 Range 传输。
2. Tauri 使用 `sourceRevision` 管理本地预览缓存，采用 `.part` 写入后原子替换。
3. 前端按文件类型懒加载成熟预览库。
4. 不再使用 LibreOffice Worker、派生 PDF、Preview Job 或 `layout-pdf`。

## 预览技术选型

| 格式 | 实现 | 策略 |
| --- | --- | --- |
| PDF | `pdfjs-dist` | 原文件进入 Fox 受控缓存，前端只挂载和渲染当前页，支持翻页、缩放与搜索 |
| DOCX | `docx-preview` | 浏览器端只读渲染正文、图片、表格、页眉页脚；识别到分页时只展示当前页，否则在受限容器中连续滚动 |
| XLS/XLSX/ODS | `@js-preview/excel` 1.7.14（MIT） | 原文件缓存读取，浏览器端只读渲染，多工作表切换；查看器与样式均懒加载 |
| PPTX | `@aiden0z/pptx-renderer` 1.2.4（Apache-2.0） | 原文件缓存读取，单页按需渲染，上一页/下一页切换；复杂动画以本机打开为准 |
| 图片/文本/代码/CSV | 浏览器原生能力和已有通用组件 | 限制最大读取量，长列表虚拟化 |
| DOC/PPT 等旧二进制格式 | 不内置预览 | 下载或本机打开 |

### 成熟库准入规则

- 必须支持本地离线运行，不能把私有文档上传到云端。
- 许可证必须允许随桌面应用分发。
- 必须能通过动态导入拆包，避免拖慢 Fox 首屏。
- 必须有明确的销毁接口或可控生命周期。
- 对 ZIP 容器格式先执行条目数、解压体积和压缩比检查。
- 不在 Fox 内自行实现 OOXML 排版引擎。

当前 PDF、DOCX、电子表格与 PPTX 均满足规则。电子表格使用 `@js-preview/excel`；PPTX 使用 `@aiden0z/pptx-renderer` 的单页模式，并启用幻灯片和媒体惰性解析。两者加载原文件前均保留 64 MB 输入上限与 ZIP 条目数、展开体积、压缩比检查，在组件卸载时销毁查看器。PPTX 原候选 `pptx-react-viewer` 的整个 2.x 发布线错误包含 `pptx-viewer-mcp@workspace:*`，标准包管理器无法安装，已排除。

## 缓存

- 位置：Fox 管理目录，不写入项目目录。
- 缓存键：知识库连接、知识库 ID、文件 ID、`sourceRevision` 和预览器版本。
- 上限：默认 500 MB。
- 清理：LRU；启动时清理残留 `.part`；删除连接时清理对应缓存。
- 原文件版本变化后创建新缓存项，旧项进入回收队列。

## 后端要求

原文件 `HEAD` 至少返回：

```text
Content-Length: <bytes>
Content-Type: <mime>
Accept-Ranges: bytes
X-Source-Revision: <versionId | sha256 | compat value>
X-Available-Variants: original
```

Range 请求必须返回 `206` 和精确的 `Content-Range`。版本不匹配返回 `412`，非法范围返回 `416`。详见 [知识库原文件网关契约](../../04-技术参考/知识库原文件网关契约.md)。

## 验收

- PDF 可以逐页翻阅，第二页及之后不白屏，页面中始终只挂载当前页 Canvas。
- DOCX 的正文、图片和表格可见；存在可识别分页时逐页切换，没有可识别分页时使用查看器内部连续滚动，不能伪造 Word 原生页码。
- XLSX 可切换工作表，滚动大表时界面不卡死。
- PPTX 可逐页切换；失败时可下载或本机打开。
- 下载完成提示、文件名和保存位置正确。
- 无任何 Office 转换任务、转换进度或版式转换按钮。
- 预览错误不会阻塞下载、文件详情和知识库问答。

## 引用定位

- 引用事件内部保留知识库 ID、文件 ID、页码、标题锚点、正文摘录和 chunk ID。
- Fox 界面不展示内部 chunk ID。
- PDF 有页码时直接打开对应页；没有页码时使用摘录搜索并跳转到命中页。
- DOCX 有可识别分页时结合页码与引用正文打开对应页；文档只被渲染为一个连续页面时，按引用正文定位、高亮并滚动到附近。
- 文本类文件使用引用正文作为搜索词并滚动到匹配位置。

## 后续性能专项

- 当前文件查看器均已按格式动态导入，但生产构建仍包含较大的 PPTX、WASM、图谱和语法高亮 chunk。
- 后续单独执行主工作台/设置路由拆分、Shiki 按需语言与主题注册、Mermaid/G6/PPTX 隔离和预加载策略优化。
- 性能拆包不与预览正确性修复混合提交，避免影响当前安装包验收。
