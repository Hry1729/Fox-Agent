# 归档说明

> 状态：生效<br>
> 适用范围：`docs/归档`<br>
> 最后更新：2026-07-29

本目录保存已经被常青文档吸收、已经完成或已经退役的阶段记录、研究过程和旧方案。归档内容用于解释历史背景，不能单独作为当前接口、架构或进度的事实来源。

## 使用规则

- 当前设计优先查阅 `01-项目概览` 至 `06-运维指南`。
- 当前计划和规格优先查阅 `07-路线图` 与 GitHub Issues。
- 当前接口、Schema 和配置优先查阅 `04-技术参考` 以及代码和测试。
- 归档文档中的 Yuxi 名称、接口、进度和本机环境可能已经过时。
- 引用归档结论前必须重新核对当前代码。

| 目录 | 内容 |

| `知识库后端` | 知识库后端扩展过程与已经退役的版式转换设计 |
