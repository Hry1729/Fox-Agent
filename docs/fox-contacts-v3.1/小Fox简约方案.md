# 小 Fox 简约方案（v0.5，对应方案 v3.1）

> 2026-11-06，基于 main `81cc1b3c`。一页纸总览，只讲你在 Fox 里能看到、能做到的事。细节以《Fox联系人改造方案.md》（v3.1）和《Fox联系人开发方案.md》（v3.1）为准；和 v0.4 的差别见文末「v0.5 有什么变化」和《修订说明.md》第〇节。

## 1. 一句话

小 Fox 是住在 Fox 里的长期联系人：有名字、头像、职责、一个固定私聊、自己的笔记和一个**工作目录**（存放它工作文件的文件夹），就在你的电脑上干活。专家是它的模板；默认送你一只「小狐」。

## 2. 怎么得到一只小 Fox

- 在专家页点「加为联系人」，侧栏「联系人」里就多一只，点开就是它的私聊。一个专家同时只有一只。
- 已经加过的，按钮变成「打开私聊」；归档过的，变成「恢复并打开」。
- 小狐默认就有，可以改名、归档，不能删除。

## 3. 私聊里你会看到什么

- 永远是同一个对话，记录只往后加。
- **说错了，就发下一条消息纠正**：私聊里没有「编辑旧消息重发」，也没有「重试」，整段经过都留着。
- 你说「每周一发给我」，它会如实告诉你：现在还不能定时自动做事。定时任务放在下一期。
- 私聊里它能读写自己工作目录里的文件、查网页、查知识库、算表格；**不能运行命令行程序、不能用外部扩展（MCP）、不能派子任务、不能查 Git 记录**。Git 记录可能指向工作目录外面的仓库，所以私聊里先不开放；在项目对话里照常能用。（这份清单按建议默认如此，待你最终确认。）

## 4. 文件：复制进来，各改各的

- 把文件拖进私聊，Fox 会把它**复制**到这只小 Fox 的工作目录里。原件不动。
- 同一份文件交给两只小 Fox，它们各改自己的那份，互不影响。
- 改好的文件，你可以「另存为」到任何地方；要不要覆盖原件，由你在保存时决定。
- 它在材料里看到一个外部路径（比如 `D:\报价\三月.xlsx`），会出现「把这个文件加入」的按钮，你点了才复制。
- 它碰不到工作目录以外的地方，也碰不到别的小 Fox 的工作目录。私聊的权限只有「只读 / 询问 / 自动」三档，没有「完全访问」。

## 5. 记忆：共享记忆和它自己的笔记

- **共享记忆**：关于你本人的稳定事实和偏好（比如「我喜欢先看结论」），所有 Fox 都能读。你在私聊里**明确说自己**长期怎样，它可以直接记下；聊天里会出现「已记住」和「撤销」。
- 下面这些它**不会直接记**，最多弹一张卡片问你「以后都这样 / 只这次 / 不记」：
  - 说的是别人：「客户喜欢长报告，我不喜欢」——这句里虽然有「喜欢长报告」，那是客户的；
  - 只管这一次：「这次周报用三段」；
  - 否定或拿不准是不是在改以前的习惯：比如以前记过「我喜欢详细的长报告」，现在说「我喜欢简短的报告」，哪怕换了个说法，它也会把旧的那条摆出来问你。
- 它自己猜的、或者从附件里看到的话，不会被当成你的偏好记进共享记忆。
- 项目预算、客户报价这类业务数据，不进共享记忆，放在项目对话或它的笔记里。
- 普通对话里主 Fox 的做法不变：先提候选，你确认。

## 6. 笔记：每轮带一页，详细的放专题

- **主笔记**：每次对话都会带上，最多 4,000 字（中文、英文、表情都按 1 个字算）。资料页能看到「已用 x / 4,000」。这个上限**对所有操作都算数**：新写、修改、重新启用一条停用的、撤销一次整理，只要会超过 4,000，都不会做，而是告诉你「还需腾出 N 字」。不会偷偷挪走或截掉内容。
- **专题**：详细材料按主题分成多份笔记（比如《供应商报价》），平时不占地方，问到时它会去查、去翻。资料页能看到专题列表，也能自己打开编辑。**删掉一个专题**，它和挪进去的条目从下一轮起就查不到了，在获准的项目里也查不到；已经在聊天里说过的话不会被撤回。
- **整理**：主笔记快满时，它可以在当前对话里把**自己写的**明细原文挪进专题，主笔记只留常用规则。资料页「整理记录」能看到每条去了哪里，必要时撤销。
- **你写的条目它不乱动**：你手写的（比如「报价绝不能低于 85 折」）默认一直在主笔记里；它要改、要删、要挪走，都会先弹卡片问你。
- 你手写超过 4,000 字时，会提示超出多少，草稿完整留着（关掉 Fox 也在），可以一键「转存为专题」。
- 小 Fox 的笔记只在它自己的资料页管理；原来那个通用的「记忆」管理页看不到、也改不了它的笔记。
- 它写错了：刚记下的那条可以「撤销」；之前就记过的，卡片会写「之前已经记过」，不会误删原来那条；你删掉的内容，它不会再自己记回来。

## 7. 谁能看到它的笔记

- 默认只有它自己。别的小 Fox、普通对话都看不到。
- **项目例外**：你在项目设置里（或它的资料页）给某个项目开了「可读取 XX 的笔记」，并且那个项目里的对话**引入了它的专家**，这段对话才能**只读**它的笔记——每轮都是最新版，专题按需查。少一个条件都读不到。
- 项目里只能看，不能改它的笔记。
- 以前就在项目里用过这位专家的对话，不会因此自动获得权限，要你单独授权。随时可以撤销。
- 它被**归档**期间，项目里暂时读不到它的笔记；恢复后不用重新授权，原来的授权接着用。（按建议默认如此，待你最终确认。）

## 8. 删除、归档

- **归档**：暂时收起，什么都留着，随时恢复。
- **删除**（小狐不能删）：删除前会列一张清单，写明要删什么、留什么，你确认后才删。
  - 删掉：它的身份、私聊、主笔记、专题、模型会话记录、所有项目授权，以及**私聊里附件的内部副本、预览图之类的中间文件**（这些只在 Fox 内部用，删了联系人就没有地方能打开它们）。
  - 保留：它工作目录里的文件，包括你拖进来的副本和它在私聊里做出来的成果（在「设置 → Agent → 联系人 → 已删除联系人留下的文件」里可以打开）、它帮你记下的共享记忆、专家本身（普通对话里照常能选）。
  - 删到一半关机或出错：重启后会接着删完，删的和留的跟没中断时完全一样。
  - 已经写进项目聊天记录里的内容也保留。
  - 之后再把同一个专家加为联系人，会是一只全新的小 Fox：空私聊、空笔记、新的工作目录，项目要重新授权。

## 9. 出问题时

- **对话的模型上下文坏了**：私聊顶部会说明情况，你点「修复后继续」才会开启新的一段上下文。聊天记录、笔记、授权、文件都在；它只是不再记得之前对话的细节。不点就什么都不变。只要私聊真的接不下去（包括会话文件已经建好、却是空的这种少见情况），就一定会出现这个按钮；能自己接上的情况不会打扰你。
- **工作目录不见了**：会直接报错，并给「重新创建工作目录」的按钮，不会偷偷换到别处。
- 平时主动「重置上下文」要到第二期才对私聊开放。

## 10. 专家更新了怎么办

- 新加的小 Fox 直接用最新的专家。
- 已有的小 Fox 继续用原来的版本，资料页会提示「有新版」，你点「采用新版」后从下一句起生效；它的名字、你改过的职责、笔记都不变。
- **你在专家页关掉的技能，立刻对所有小 Fox 生效**：哪怕它还在用旧版本，也不会因为旧版本里有这个技能就重新用上。
- 默认的小狐跟着 Fox 一起更新，你给它改过的职责保留。（按建议默认如此，待你最终确认。）
- 模型首版跟随 Fox 的全局设置，资料页只显示用的是哪个模型，不能单独换。（按建议默认如此，待你最终确认。）

## 11. 分期

- **第一期（M1）**：以上第 2–10 节全部（除了「主动重置上下文」）。
- **第二期（M2）**：私聊跨重启、压缩后接着聊的完整验证，开放主动重置。
- **下一期**：定时任务交给小 Fox、任务结论写回笔记、（若决定）按联系人换模型。
- **以后**：同一专家多只、多 Fox 协作、群聊。

## 12. 还要你确认的事

下面四项已经按建议写成默认做法，整套方案都按它们来写；你确认后就不用再改，改主意也只影响对应那一项（详见《修订说明.md》第四节）：

1. 小 Fox 的模型跟随全局设置，首版不能单独换。
2. 私聊只开放已经证实守得住「只在自己文件夹」的工具；首版去掉查 Git 记录。
3. 归档期间项目暂停读取它的笔记，恢复后沿用原来的授权。
4. 默认小狐跟着 Fox 更新，保留你改过的职责。

## v0.5 有什么变化（相对 v0.4）

- 私聊里不能查 Git 记录（第 3 节）。
- 共享记忆更谨慎：说别人的、只管这次的、可能在改旧习惯的，都先问你（第 5 节）。
- 主笔记 4,000 字的上限对撤销整理、重新启用等所有操作都算数；删掉专题后真的查不到了（第 6 节）。
- 归档期间的项目读取、默认小狐的更新方式写成了默认做法（第 7、10 节）。
- 删除联系人会一并清掉私聊附件的内部副本，工作目录里的成果仍保留；中断后能接着删完（第 8 节）。
- 修复按钮在私聊真的接不下去时一定会出现（第 9 节）。
- 专家页关掉的技能立刻对所有小 Fox 生效（第 10 节）。
