## 阶段4

- 子 Run 沿父链解析小 Fox 归属。断链返回错误；普通对话仍按普通路径执行。
- 子 Run 不独占小 Fox 执行位置。父任务等待时保留该小 Fox 的位置，子任务仍可使用全局执行位置。
- 子 Run 继承父任务冻结的能力和工具目录。每次调用检查当前授权，撤权立即生效；子 Run 无权修改资料、计划或笔记。
- 父任务完成、停止、归档和删除时包含后代清理。父任务等后代实际释放后才放行下一项任务。重启后中断小 Fox 子任务的待审批操作，普通对话审批恢复行为保持原样。
- 根 Run 汇总各父子 Run 最新累计用量和工具调用。重复用量事件不重复加总；超额停止根任务及子任务。
- 自动化门槛通过后开放 `child_run_start`、`child_run_collect`、`child_run_cancel`。真实侧车测试覆盖普通对话、私聊和后台任务的等待与结果回收。
