# 智能体体验

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：`apps/desktop/src/features/agents`、`apps/desktop/src/features/workspace/entity-card.tsx`，以及设置 → Agent 中的专家与通用助手<br>
> 最后更新：2026-10-25

## 结论

- 界面统一称「专家」。助手模式左侧栏的「专家」进入专家中心（`AgentListPage`，页面标题「选择一个专家」），只列 `agentKind=expert`、`invocationMode=inline`、`visibility=expert_center` 的记录（`expertCatalogAgents`）。
- 聊天可选的助手是 `assistant / primary / chat_selector` 且可用的记录（`chatSelectableAgents`）；Worker 不出现在任何选择入口。
- 专家来源有三类：内置专家、本机专家、资料库服务专家（`runtimeType=yuxi`）。内置专家和已安装专家包只读，可「复制专家」为本机专家后修改；资料库服务专家的设置由服务端管理，Fox 只展示。
- 专家详情页有 7 个栏目：专家介绍、资料库、技能、连接器、工具、工作记录、记忆。长期记忆和专家版本记录已经实现。
- 设置 → Agent 中也能编辑通用助手和专家（Sheet），与专家详情共用同一个编辑器（`useAgentEditor`）。

## 目标与范围

说明专家中心列表、详情、新建 / 导入、启用专家开始对话、长期记忆、版本记录和数字同事入口的前端体验。专家能力包、团队、工作流的宿主实现见 `docs/02-架构/专家*.md` 和 `数字同事架构.md`。

## 专家中心列表

页面元素（`agent-pages.tsx`）：

- 标题「选择一个专家」和「搜索专家」；
- 筛选：状态（全部状态 / 可使用 / 不可用）、环境（全部环境 / 本机 / 资料库）、分类（全部分类 / 通用 / 工程 / 设计 / 规划 / 审查 / 业务）；
- 「N 个结果」、刷新；
- 「导入能力包」（`.foxexpert` 或 JSON，不超过 2 MiB）、「数字同事」、「新建专家」。

`useAgents` 先读本地数据库立即渲染，再在后台同步资料库服务专家；刷新不清空列表，同步期间刷新按钮显示加载。

### 卡片

`entity-card.tsx` 的专家卡片显示头像、名称、简介、来源（本机 / 资料库）、资料库 / 技能 / 连接器 / 工具数量、可用状态，按钮「详情」「开始对话」。不可用时提示「该专家暂不可用」。卡片上的数量对本机专家取能力包声明（`agent-card-data.ts`）。

### 开始对话

「开始对话」调用 `navigate('chat', expertId)`。`Workbench` 识别为专家后执行 `selectExpert(expertId, true)`：新建一个由默认助手负责、带该专家的对话，并把专家声明的资料库加入会话。目标是助手时改为 `createConversationForAgent`；Worker 被忽略。

在已有对话里通过输入框的专家胶囊「更换专家」时，专家在当前对话中更换（`changeExpert`），聊天记录保留；运行中不能更换。

## 新建与导入

- 「新建专家」对话框：基本设置（名称、分类、头像、简介、开场建议、工作要求）和能力设置（资料库、技能、连接器、工具权限）。资源从当前可用列表中勾选，不手填 ID。
- 「导入能力包」先显示安装预览：专家包、版本变化（安装 / 升级 / 已是当前版本 / 拒绝降级 / 版本冲突）、包哈希、项目权限请求。安装只登记声明式资源，不执行包内脚本，也不自动授予项目权限。

## 专家详情

左侧栏切换为专家上下文导航（`fox-sidebar.tsx` 的 `agentContextItems`）：

| 栏目 | 内容 |
| --- | --- |
| 专家介绍 | 运行位置（本机 Fox Runtime / 资料库服务）、版本记录、能力资源、提问示例、工作要求；「开始对话」「管理专家」 |
| 资料库 | 绑定的资料库；无资料库时提示先在资料库页面创建 |
| 技能 | 启用 / 停用技能；「添加技能」跳到 设置 → 插件 |
| 连接器 | 启用 / 停用连接器；「添加连接器」跳到 设置 → 插件 |
| 工具 | 工具权限；预置工具默认开启 |
| 工作记录 | 活跃天数、工作记录数、参与项目、活动热力图、对话任务列表 |
| 记忆 | 长期记忆管理（见下） |

专家操作菜单：编辑信息、导出专家、删除专家（`confirmDialog`）。有能力包版本历史时可「恢复版本」。资料库服务专家显示「工作要求与管理设置保留在资料库服务，Fox 仅展示普通用户可见字段。」

### 长期记忆

记忆页（仅桌面版）：

- 搜索记忆、证据或键；「添加记忆」；
- 每条记忆可启用 / 禁用、编辑、查看变更记录、删除；
- Agent 提交的候选显示为「Agent 候选」，可「确认使用」；同键冲突时可「保留原内容」或「改用新内容」；
- 新增 / 编辑：使用范围（全局 / 当前专家 / 项目，创建后不可更改）、类型（偏好、身份、项目、工作流、事实、其他）、规范键、记忆内容、来源依据。

远程 Runtime 只支持查看和治理，不注入本机记忆。

## 数字同事

「数字同事」打开 `digital-colleague-manager.tsx`：把已版本化的专家部署为长期实体，冻结当前专家版本；支持暂停 / 恢复、撤销、立即执行、定时执行和签名 Channel（密钥只显示一次）。外部触发数据按低权限上下文处理。

## 设置中的专家编辑

设置 → Agent →「专家」列表点击专家，右侧 Sheet 打开同一个编辑器（基本 / 能力）。「添加技能 / 添加连接器」跳到设置的插件页并显示「返回〈专家名〉」。详见 [设置中心](设置中心.md#agent)。

## 能力边界

- 专家不扩大权限：实际可用能力是 Fox 授权、助手约束和专家声明的交集。
- 技能只注入指令；连接器调用仍经过审批和审计。
- 资料库服务离线时，远程专家标为不可用，本机专家继续可用。

## 异常与边界

- 不可用专家仍可在历史绑定中展示，但「开始对话」禁用。
- 资源数量依赖服务端映射和本地扫描，刷新期间可能变化。
- 后台同步的超时时长本次没有核对（旧文档写的是 3 秒）。

## 测试与验证

自动测试（`apps/desktop/tests/`）中与专家相关的有 `agent-classification`、专家绑定、`settings-batch3-dom.test.tsx`（设置中的专家 Sheet）等用例；未逐个核对覆盖范围。

人工验证：资料库服务在线 / 离线时列表差异；筛选组合；开始对话后带专家和资料库；新建、复制、导入、导出、删除；版本恢复；记忆的候选确认和冲突处理；数字同事暂停 / 恢复 / 撤销；深浅主题和窄窗口。

## 已知限制

- 工作记录基于会话汇总，不是独立任务与证据模型。
- 卡片上的能力数量是展示口径，不覆盖全部 Runtime 能力声明。
- 远程专家的管理仍需在资料库服务管理端完成。
