# 任务：按原型重做 Fox 桌面端右侧栏，并修小 Fox 定时任务卡片高度

你在 Fox 仓库 `D:\python\projects\Fox\Fox`（分支 `main`）里工作。技术栈：React 19 + Tauri 2，前端在 `apps/desktop`，包管理器 pnpm。界面文案全部是中文，和用户沟通也用中文。

## 2. 要做什么

### 2.1 摘要页（新的右侧栏首页）
- 删掉顶栏的「对话摘要」图标和 `ConversationSummaryPopover`。它用到的数据和取舍（不显示 token、上下文占比、工具调用次数）搬进右侧栏的「摘要」页。
- 「摘要」固定是第一个标签，不能关闭，替代原来首页的 6 个功能按钮列表（`fox-context-home`）。
- 分组从上到下依次是：模型、任务计划、生成文件、后台程序、协作助手、资料来源。哪一组没有内容，整组就不显示。空对话只显示模型卡片和一张说明卡片（参考帧 `empty`）。
- 每组右上角的「全部 ›」打开对应页面：生成文件 → 文件，任务计划 → 运行详情，后台程序 → 运行详情，协作助手 → 协作助手，资料来源 → 资料库。
- 默认状态：普通对话在没有存储状态时，右侧栏默认展开并显示「摘要」。用户手动关闭以后，沿用现有的存储逻辑记住这个状态。小 Fox 对话保持现在的详情侧栏，不受影响。

### 2.2 标签栏
- 顺序是：摘要、已打开的页面、已打开的文件，然后是「＋」，右侧是全屏和关闭按钮。
- 当前标签显示图标、名称和关闭按钮。**不在当前的标签只显示图标**，要加 tooltip 和 `aria-label`。
- 「＋」菜单列出 6 个页面，这部分沿用现有逻辑。

### 2.3 其他页面（逐帧对照原型）
- **文件**：顶部是搜索框卡片。「文件版本」按日期分组，可以展开每个文件的版本列表；当前版本标「当前」，「恢复」按钮只在悬停时出现，强制恢复的流程保留；底部注明「恢复前会自动备份当前内容」，范围说明收进 ⓘ。下面是「项目文件」树卡片。刷新、打开文件夹都做成小标题右侧的图标按钮。
- **文件预览**：顶部是文件信息卡片（名称、新建 / 已修改、位置、大小），下方放「打开 ▾」下拉和「打开文件夹」。下拉里的系统打开、打开文件夹、复制路径、编辑器列表全部保留。预览区单独一张卡片。HTML 预览、截断提示、加载和失败状态都保留。
- **资料库**：分成「已绑定」和「本次引用」两组，引用每行显示标题和最多两行摘录。去掉每行原来的类型标签。
- **更改**：上面是「更改」列表卡片（文件编辑和命令混排，选中的行高亮），下面是「详情」卡片。命令详情显示退出码、耗时、目录和输出，`requiresAttention` 和 `uncertain` 的说明保留；文件详情显示对比；证据数量放在「详情」小标题右侧。
- **运行详情**：去掉页面大标题，分成以下几张卡片：最近一次运行、相关依据（只在 focusedEvidence 存在时出现）、目标（进度、暂停 / 继续、删除目标、停止协作，「查看计划、任务和证据 ›」展开后显示原来的内容）、工具记录、自动放行记录、运行记录。工具记录默认显示最近几条，其余收进「还有 N 条」。
- **网页与网络**：顶部是分段切换「网页预览 / 网络记录 (N)」，地址栏单独一张卡片，网页预览放进圆角卡片，隔离提示改成一行小字。网络记录每行一次调用，点开能看到结果。
- **协作助手**：按「进行中 / 已结束」分组，去掉「显示更多」。点开后进入只读消息记录：顶部是一张带返回按钮、名称、状态的卡片，下面分成「Fox 交给它的任务」「过程」「回复」三组，运行中时底部显示一行实时状态。超时和失败的说明文案沿用 `childRunFailureTitle` 等现有函数。

### 2.4 颜色和状态
- 完成、进行中一律用中性灰。失败用 `--destructive`，需要用户批准或回答用 `--warning`。长列表里已完成的项目只写灰色文字「已完成」，不加胶囊。
- 开发者模式（`developerUi`）下的额外信息（工具名、事件名、状态码等）照旧显示。
- 加载、空状态、错误、重试，以及所有 toast 和确认弹窗都要保留。

## 3. 组件怎么用

不要引入新的组件库。交互全部复用项目里已有的组件，外观用一层很薄的自写样式：

| 部分 | 用什么 |
|---|---|
| 行（图标 + 标题 + 说明 + 右侧操作） | shadcn 官方的 `Item` 组件。项目里还没有，在 `apps/desktop` 下执行 `pnpm dlx shadcn@latest add item` 添加（`components.json` 已配置，style 是 `radix-mira`）。添加后检查生成的文件是否符合项目风格 |
| 分组标题 + 卡片 | 新写 `SideSection`（标题、数量、右侧链接或图标按钮）和 `SideCard`，放在 `src/components/fox-ui/`，配一个 CSS 文件，变量照搬原型 |
| 标签、下拉、提示 | `ui/tabs`、`ui/dropdown-menu`、`ui/tooltip` |
| 搜索框、地址栏 | `ui/input-group` |
| 版本展开、计划展开 | `ui/collapsible` 或现有的 `fox-ui/fox-disclosure` |
| 文件树 | 继续用 `animate-ui/components/base/files` |
| 网页预览 | 继续用 `ai-elements/web-preview` |
| 命令输出、对比 | `ai-elements/terminal`、`ai-elements/code-block`，或者保留现有实现、只换外观 |
| 状态胶囊、按钮、进度条、空状态、滚动 | `ui/badge`、`ui/button`、`ui/progress`、`ui/empty`、`ui/scroll-area` |
| 任务计划勾选列表 | 自己写，照原型做。ai-elements 的 `plan` / `task` 是另一种样式，不要硬改 |

重构完以后，确认没人再用的旧类名和旧样式要删掉。删之前全仓库搜一遍，确认没有别的地方在用。

## 4. 小 Fox 定时任务卡片高度

`contact-side-card.tsx` 详情页里，「定时任务」那组的外层用了 `className="fox-library-card"`（大约在第 207 行）。这个类在 `styles/globals.css`（大约第 235 行）里有 `min-height: var(--fox-library-card-height) !important`，本来是给资料库卡片用的，所以这张卡片被撑高了。改成和同页其他分组一样的 `fox-contact-list-card`，让它的行高和下面「模型」「这个对话」等分组的行一致。修完后用 `tests/contact-side-card-dom.test.tsx` 验证，需要的话补一个断言。
