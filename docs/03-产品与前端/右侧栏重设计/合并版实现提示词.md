# 右侧栏合并版 · 实现提示词

把下面整段交给负责实现的 agent。

## 你要做什么

Fox 桌面端（`apps/desktop`，React 19 + Tauri 2）的右侧栏要按「合并版」原型改造：

1. 右侧栏不再是对话卡片旁边的独立圆角卡片，而是并进对话卡片的右边，中间一条 1px 浅灰细线。
2. 摘要页改成平铺的行：每行「名称 ›」在左、数值在右；可以展开；悬停出现拖动把手，可以调整顺序。
3. 「模型」行展开后显示上下文占用。
4. 文件页只保留搜索和项目文件树；Fox 改过的文件在树里标「新建 / 已修改」。文件历史版本功能整体删除，改成在对话里按轮撤销（见《撤销功能提示词》）。
5. 文件预览的头部压成一行：文件名 + 三个图标按钮。
6. 其余页面（资料库、更改、运行详情、网页与网络、协作助手、协作助手消息记录）全部改成同一套平铺样式。
7. 所有控件只用 app 已有的 `--fox-*` token，规则见 `统一token提示词.md`。

## 3. 摘要页

数据来源不变：`src/features/chat/right-panel/conversation-summary.tsx` 里已有的「项目、模型、任务计划、生成文件、后台程序、协作助手、资料来源」。去掉每组的 `SideSection` 标题和 `SideCard` 卡片，改成原型里的行（CSS 在 `合并版.html` 的 `.sm-row`、`.sm-item`、`.sm-group`、`.meter`）：

- 行高 44px，左边名称 13.5px + `chevron-right`（展开时转 90°），右边数值用 `--fox-muted`，`tabular-nums`。行与行之间一条 1px `--fox-border`。
- 数值：项目名；模型名；任务「完成数 / 总数」+ 30×6 小进度条；生成文件「N 个」；后台程序「N 个运行中」；协作助手有待批准时「N 个需要你批准」用 `--warning`，否则「N 个」；资料来源「N 条」。
- 只有需要用户处理的状态上色（待批准橙色，失败红色），其余全部灰色文字，不用胶囊。
- 展开内容是 32px 的小行（图标 14px + 文字 + 右侧小字状态）。任务计划全部列出；其他组最多 3 条，后面一个文字按钮「查看全部 N 条 ›」打开对应页面（沿用现在的 `mode`）。项目展开显示路径（等宽字）和「打开项目文件夹」。
- 某组没有数据就整行隐藏（项目、模型除外）。新对话只有项目和模型两行，下面一句「开始对话后，任务计划、生成文件和协作助手会显示在这里。」
- 展开状态：运行中时任务计划默认展开，其他默认收起；用户点过之后在本次会话内记住。

### 拖动调整顺序

- 每行最右边有一个 `grip-vertical` 把手，宽度 0、透明；行悬停或把手获得键盘焦点时展开到 20px，数值往左让开（`.sm-row .grip` 的过渡）。
- 拖动时：被拖的行浮起来（`--fox-card` 背景、1px 边框、`--shadow-md`、轻微旋转 -0.6°、`cursor: grabbing`），原位置变成虚线占位框，其余行实时让位，松手立即生效。
- 依赖：`@dnd-kit/core` 和 `motion` 已经装了，`@dnd-kit/sortable` 没装。用已有的库实现（例如 `motion` 的 `Reorder.Group` + `useDragControls`，只从把手发起拖动），**不要新增依赖**，确实需要的话先问。
- 键盘：Tab 到把手，空格拿起，↑ ↓ 移动，空格或 Enter 放下，Esc 取消；用 `aria-live` 读出「已移到第 3 位」。把手 `aria-label="拖动调整「生成文件」的顺序"`。
- 顺序存在 localStorage（全局，所有对话共用），存组 id 数组；读出时丢掉未知 id、把新增的组按默认顺序补在后面。隐藏的组不影响其他组的相对顺序。
- 顺序和默认不同时，摘要最下面出现文字按钮「恢复默认顺序」（`rotate-ccw` 图标）。
- `prefers-reduced-motion` 时去掉让位动画和旋转。

### 模型行展开：上下文占用

- 数据：`kernel_reliability_snapshot` 返回的 `contextBudget`（`ContextBudgetDto`），现在只有 `src/features/chat/components/RunReliabilityPanel.tsx` 在调用。把加载和轮询抽成一个 hook（如 `useContextBudget(conversationId, active)`），两处共用，不要复制一份。展示用 `context-budget-presentation.ts` 里已有的 `contextBudgetRows`、`compactTokenCount`、`pressurePercent`、`calibrationNote` / `estimateSourceLabel`。
- 布局（原型 `.ctx*`）：第一行「58% 上下文已用」，右边「115.3k / 200k」；一条 6px 分段条；下面每类一行：色块、名称、用量、比例。分类：历史消息、工具定义、系统提示、输出预留、安全余量（协议余量 + 误差余量合并），最后一行「剩余可用」只有描边色块、灰字。「待追加输入」为 0 时不显示。不加估算来源等说明文字。
- 颜色：分段用原型里的 `--ctx-history / tools / system / reserve / margin`（浅色、深色各一组，见 `合并版.html` 40–45 和 57–61 行），定义在全局 token 文件里；剩余可用用 `--fox-hover` 底。
- 收起时：占用 ≥ 80% 在模型名后面加百分比，橙色；≥ 90% 红色。
- 没有数据（非桌面运行时、还没发过消息、`contextBudget` 为空）：展开后一句「发送消息后显示上下文占用。」
- 轮询：右侧栏可见且在摘要页时才拉；运行中 1.5s，其他 5s；页面不可见就停。

## 6. 其余页面

都用同一套平铺结构（原型 `.grp`、`.gh`、`.li`、`.st`、`.hint`）：

- 组标题 38px，12.5px `--fox-muted`，后面跟灰色数量；右边可放小图标按钮或文字按钮。组与组之间 1px `--fox-border`，没有卡片和阴影。
- 列表行最小 40px：16px 图标或 24px 头像、标题 13px 中等字重 + 12px 灰色副标题、右侧状态文字。状态用文字颜色区分（失败 `--destructive`、待批准 `--warning`、其余 `--fox-muted`），运行中带转圈图标，不用胶囊或徽章。悬停 `--fox-hover`，选中 `--fox-selected`。
- 只有「内容框」（输入框、地址栏、网页 / 文件预览、命令输出、diff）有 1px 边框和 `--fox-radius-card`。

各页要点（详见原型每帧下面的三栏说明）：

- 资料库：「已绑定」「本次引用」两组；引用行显示来源和两行摘录；解绑等操作收进行尾 ⋯；去掉行尾类型标签；底部不加「在输入框「+」里绑定更多」的提示。
- 更改：文件改动和命令同一列表、按时间倒序；下面「详情」组：命令显示命令 / 结果 / 耗时 / 目录 + 输出框，文件显示改动行数 + diff；证据数量是「详情」右边的文字按钮；去掉详情头部的两枚大徽章。
- 运行详情：要重新组织结构，不能只换样式（`ActivityDetailPanel.tsx`、`PermissionAuditList.tsx`）。最近一次运行是一行列表行：标题「已完成 · 21 步」、副标题用时、右边停止按钮，不要三列分散排开；工具记录每行是图标 + 动作名（读取文件、编辑文件、运行命令…，非开发者模式也显示这种友好名称，不要统一写「工具调用」）+ 副标题目标路径或命令 + 右侧状态，点开才看细节；「自动放行」每行同样是动作名 + 目标 + 「当前模式自动放行 · 时间」，不要直接显示 `write_file` 这种原始工具名；目标（标题、完成数、4px 进度条、暂停 / 删除目标）；专家团队一行；「查看计划、任务和证据 ›」；工具记录只列最近 4 条 +「还有 N 条 ›」；自动放行；去掉页面大标题，「运行记录」分组只在开发者模式显示。
- 网页与网络：顶部两段切换（网页预览 / 网络记录，样式同标签栏的选中态）；地址栏是输入框样式（刷新、网址、在浏览器中打开）；网络记录每行一次调用，选中后下面缩进显示返回结果；预览下方和网络记录下方都不加说明文字。还没打开网页、还没有联网记录时的空状态说明保留。
- 协作助手：「进行中」「已结束」两组；超时、失败用红字写原因；去掉状态胶囊和「显示更多」。
- 协作助手消息记录：顶部一行（返回、头像、名称、「只读 · 消息会自动更新」、状态）；「Fox 交给它的任务」「过程」「回复」三组；去掉长串消息气泡。

## 7. token 和样式规则

- 不放说明性的提示文字（「这里只记录…」「点开一行可以…」「「新建」「已修改」是…」等）。只有空状态（页面没有任何内容时）可以有一句说明；数据本身（如「新增 6 行，删除 2 行」）不算提示。
- 只用 `--fox-*`（以及上面新增的 `--ctx-*`），不要再用 `--rp-*` 或写死颜色、圆角、阴影、字号。缺的 token（如 `--fox-selected`）按 `统一token提示词.md` 加到全局。
- 图标按钮 28px（小号 24px）、`--fox-radius-control`、无边框；悬停 `--fox-hover` + `--fox-text`；选中 `--fox-accent-soft`；键盘焦点 2px `--ring`、`outline-offset: -2px`。
- 每个可点击元素都有悬停态和焦点态；所有按钮都有 `aria-label` 或可见文字。
- 浅色、深色、暖纸、雾蓝四种组合都要看一遍，深色下不能出现白色光晕阴影。

## 8. 约束

- 只改右侧栏、对话卡片外框和顶栏按钮，不动对话区内容、输入框、左侧导航。
- 不新增 npm 依赖；不改 Rust 侧接口。需要的数据都已有 IPC。
- 文件保持 LF 换行（有测试按 LF 匹配 CSS 文本）。
- `mock.module` 是进程级的：测试里 mock 时展开真实模块，并在 `afterAll` 里还原。
- 不要提交、不要推送。
