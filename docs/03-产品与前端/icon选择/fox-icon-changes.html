PanelLeft / PanelRight 不是「替换」，是两处要拆开看。 站点上不存在 panel-left / panel-right 这两个组件名， 只有 panel-left-close、panel-left-open、panel-right-open 三枚。 它们的动作和仓库现在的一样——都是把分栏线挪 2px（9 → 7 或 15 → 17）——但被拆成了「开」和「关」两个独立图标。

问题在于 PanelLeft / PanelRight 在你的代码里是四个不同按钮共用的名字： 左栏开合（标题栏）、右栏开合（右栏自己的头部）、顶栏展开右栏，另外还出现在侧栏右键菜单里。 「面板在左边还是右边」和「当前是开还是关」是两件事，而站点的命名把前一件事丢掉了—— PanelRight 连 panel-right-close 都没有。 这两枚建议保留 animate-ui 的实现，比硬塞站点组件干净。

03新增 · 站点没有，照仓库字形自写（6 枚）

知识库导航栏的六个入口，站点 468 枚里一个都没有—— 不是「有但不合适」，是同名项根本不存在（最接近的 file-stack、 home 字形也不是同一个）。所以这六枚只有两条路：保持静态，或者自己写。 下面这六个文件已经写好并通过 tsc --strict， 可以直接放进 apps/desktop/src/components/animate-ui/icons/。

图标位置自写动效
Database仓库字形本机资料库 · 侧栏导航顶盖椭圆抬起 y [0,-1,0]，中间那道弧 y [0,1.4,0]——一层从筒身里抽出来再落回去，0.6s easeInOut站点没有 database 这枚（只有 database-backup，字形不同）。

这六枚的共同点：字形已经在仓库里了（就是现在这些 lucide-react 图标），要新增的只有外面那层 motion 包装。所以动的过程中、以及静止帧，形状都和现在一模一样——不存在 §01 那种「换了库导致字形漂移」的问题。

六个文件都按 animate-ui 现有的 icons/ 契约写好了（getVariants + useAnimateIconContext + IconWrapper，对外导出 X / XIcon / animations），放进 apps/desktop/src/components/animate-ui/icons/ 就能用，不需要引入任何新依赖。调用点那一行的写法完全不用改——<Icon size={18} /> 换成换过去的组件即可。

六个文件已经过 tsc --strict 编译通过（连同 animate-ui 的 icon.tsx 一起做类型检查，零报错）。但「能编译」和「16px 下好看」是两件事——文末 §05 第五条写了验收要求。

04评估后建议保持静态的

这几枚评估下来建议不动——理由写在下面，免得以后再翻出来重新讨论一遍。 其中 House 是唯一的例外情况：站点上确实有近似组件，但字形不同、且被两处共用， 真要动得先解决共用问题。

X标题栏 · 关闭站点有 x 这枚（两笔用 pathLength 依次画出），但关闭是系统级窗口控件——它一动会让人以为窗口出了问题，而且它就在窗口右上角、是要精确命中的目标，任何位移都会降低可点性。
Minus标题栏 · 最小化站点没有 minus（只有 folder-minus 这类变体）。而且它的图形只是一根 14px 的横线，没有可映射的动作。
LoaderCircle文件加载中它现在已经在用 CSS 的 animate-spin 转；站点版本是 motion 驱动的无限旋转。两个都能转，但同时挂着就是两套系统驱动同一个图形，相位迟早对不上。二选一，不要都留——保留 CSS 版本即可。
ChevronRight目录树的展开箭头站点有 chevron-right，但这一枚已经在转、而且转得对：local-knowledge.css:2305 给它挂了 transition: transform 120ms ease，[aria-expanded='true'] 那条再把它 rotate(90deg)。换过去就是 motion 和 CSS 抢着改同一个 transform，相位对不上。另外这一枚一屏会出现十几个，同屏一起动是典型的干扰源。
Folder / FolderOpen目录树的文件夹站点没有 folder——只有 folder-open / folder-minus 这类变体。而且这一整行的可点区域是整个 row，行里还带着文件夹名和文件数徽标，图标偏离中心一个像素，整行的视觉重心都跟着偏。同样是一屏十几行的情况。
House侧栏「专家介绍」· 与知识库「最近」共用同一枚站点上没有 house，只有 home；而且 home 的字形和仓库的 House 不是同一个——屋顶那条线仓库写作 l7-6，站点是 l7-5.999。真正的问题是它被两处共用：知识库导航的「最近」和侧栏的「专家介绍」。换过去只换了一处，两处就会长得不一样；两处都换，就把字形漂移也带进去了。如果决定要动，先决定这两处是不是同一个入口。

05落地时必须一起处理的事

前四条不加处理就会出问题；第五条只针对 §03 那六枚自写的， 是它们和站点现成组件之间最大的差别。

一两条 > svg 直接子选择器会失效animate-ui 渲染出的 motion.svg 是按钮的直接子元素；lucide-animated 多包了一层 <div>，svg 变成孙元素。会踩到 workbench.css:1172 的 .fox-shell .fox-sidebar-command > svg（尺寸 + flex: 0 0 … 防挤压 + stroke-width: 1.8）和 workbench.css:175 的 .fox-notification-trigger > svg。知识库导航栏用的正是前者。
注意 workbench.css:99（.fox-titlebar-sidebar-controls button svg）和 workbench.css:1051（.fox-sidebar-search-trigger svg）是后代选择器，不受影响。
二描边会整体变粗lucide-animated 每个文件都硬编码 strokeWidth="2"，而全站是 1.65–1.8（侧栏 1.8、标题栏 1.65）。好在源码是拷进仓库的，把 strokeWidth 属性删掉、让 CSS 接管即可。
三hover 的可点区域会缩小，而且现有触发层驱动不了新组件现在 AnimatedIconTrigger 包在按钮外面，整个按钮（含文字标签）都能触发。lucide-animated 的 onMouseEnter 挂在图标自己那个 <div> 上，而它默认是行内收缩的——结果是必须戳中图标才播。给该 div 加 display:flex 撑满按钮即可。另外 lucide-animated 不读 AnimateIconContext，它暴露的是 forwardRef + useImperativeHandle 的 { startAnimation, stopAnimation }；现有 50 处 AnimatedIconTrigger 驱动不了它们，过渡期需要包装层按 ref 分流。
四字形版本会漂移，同屏混用会看出粗细不一把站点 16 枚的字形和仓库的同名图标逐属性比对，只有 Maximize / Minimize / MessageCirclePlus / Plus / ChevronRight / FolderOpen / LoaderCircle / X 这 8 枚完全一致。Bell / Blocks / Search / Settings / SunMoon / Users / Sparkles / House 这 8 枚站点用的是旧版几何（House 的 l7-5.999 vs 仓库 l7-6、Bell 整个铃身形状不同、Blocks 的圆角方块退回直角）。它们和仓库里其余 150 多枚静态 lucide 图标会并排出现，比例差异虽小但看得见。
五§03 那六枚是自写的，没有现成动效可以照抄——必须补一步验收§01/§02 的十四个文件都是从站点 registry 拷下来的，参数别人已经调过。§03 的六枚没有这个保证：它们能编译、能跑，但「在 16px 下是否读得出来」是设计问题，不是编译问题。至少要手动看一眼这四件事：
① transformOrigin 写的是用户坐标（4px 20px 这种），在 svg 的 24 单位 viewBox 里 px 和用户单位是 1:1，所以没问题；但一旦以后把 viewBox 改成别的比例，这几个数字全要跟着改。
② 四根书脊（Library）各自转轴、错峰 0.05s，在 16px 下 5 毫秒级的错峰几乎看不出来，可能得把错峰拉到 0.08–0.1s 才有「依次」的感觉。
③ 幅度是为 24px 设计的观感，侧栏实际是 16px（--fox-sidebar-icon-size），位移会被等比缩到 2/3。真要上台，要么整体放大 1.4 倍，要么接受它是「极轻的一下」。
④ 必须走一遍 prefers-reduced-motion——animate-ui 的 IconWrapper 目前没有内置这个判断，六个文件都要确认在减弱动效下是静止的。
动效参数抄自 lucide-animated.com/r/<slug>.json（实际抓取的 registry 内容） 与仓库 apps/desktop/src/components/animate-ui/icons/*.tsx。 字形比对为逐属性 diff，结果 8/16 完全一致（Maximize、Minimize、MessageCirclePlus、Plus、 ChevronRight、FolderOpen、LoaderCircle、X），其余 8 枚站点用的是旧版几何。 站点清单核对于 lucide-animated.com/icons/llms.txt（468 枚）。 §03 的六枚不在该清单内，动效为自行设计，已通过 tsc --strict。
