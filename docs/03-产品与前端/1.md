## 2. 需求与验收要点

### UI-01 历史对话的初始阅读状态

**现象：** 新建测试环境后，已有历史对话显示“已完成”的动态图标，造成待查看的错觉。

**目标：** 已阅读的历史对话不显示完成提示图标。首次导入或初始化已有历史数据时，按已阅读处理。

**边界：** 这项要求针对历史数据的初始展示。不能在每次启动时把所有会话标为已读，也不能隐藏正在运行、执行失败或等待审批的状态。执行完成与已阅读需要分别处理。

**验收要点：** 初始历史对话没有完成提示；本次运行新产生的未读结果仍可提示；打开阅读后提示按既有规则消失；重启不反复重置阅读状态。

### UI-02 小狐动态形象遮挡

**现象：** 小狐在部分场景被其他内容遮挡。

**目标：** 小狐在所属区域内完整显示。原始建议是提高层级，具体修复方式需根据遮挡原因确定。

**边界：** 检查父容器裁切、定位和层叠关系，不能只无限增大 `z-index`。小狐不得覆盖模态窗口、菜单、输入框或可点击操作。

**验收要点：** 在出现问题的页面、小窗口和动画边界位置复查；形象不被裁切，也不拦截其他控件的点击。

### UI-03 侧边栏项目名称单行显示

**目标：** 项目名称始终占一行，与会话标题采用一致的溢出表现。超长名称在尾部省略或渐隐，不换行。

**验收要点：** 长中文、英文及混合名称不撑高行；窄侧边栏中状态标记和操作按钮仍可使用；用户可通过提示查看完整名称。

### UI-04 本地资料库显示全部文件类型

**现象：** `D:/python/projects/icones-main` 资料库只显示部分文件和文件夹。

**目标：** 资料库能够识别并列出各种文件类型，包括 `.gitignore` 等点文件、无扩展名文件，以及暂不支持预览或向量化的文件。

**能力划分：**

| 能力 | 预期行为 |
|---|---|
| 文件可见 | 不因扩展名不受支持而直接从文件列表中消失 |
| 文件预览 | 支持的类型正常打开；不支持的类型说明原因 |
| 向量化 | 仅对支持的内容执行；不支持时保留文件条目并说明状态 |

**待核对：** 缺失是否由扫描过滤、忽略规则、权限、索引或前端筛选导致。隐藏文件和显式排除规则的关系需另行说明；文件类型覆盖不等于自动取消全部目录排除规则。

**验收要点：** 用上述目录对比磁盘清单与页面清单，记录排除项及原因；不支持的类型仍可见；权限错误与不支持的类型分别展示，不显示为成功导入。

### UI-05 文件预览页合并标题栏

**目标：** 将现有第二行、第三行的信息和操作并入标题行。文件信息位于标题右侧；操作按钮位于同一行最右侧。

**验收要点：** 常用窗口下只保留一条标题工具栏；长文件名不挤掉主要操作；窄窗口下保持操作可达，不产生重叠。内容区获得更多可用高度。

### UI-06 资料库搜索入口统一

**现象：** 资料库详情页搜索图标尺寸不一致，点击后没有展开搜索栏。

**目标：** 详情页与资料库首页使用一致的搜索图标、尺寸和点击区域。详情页点击搜索后展开搜索输入框。

**验收要点：** 输入框可获得焦点并完成搜索；空结果可辨识；关闭后可重新打开；键盘可操作。实施时明确详情页搜索范围，避免误搜其他资料库。

### UI-07 区分文件视图并重设计网格卡片

**现象：** 紧凑视图与列表视图区别不明显；网格卡片的信息排列和操作位置混乱。

**目标：** 紧凑视图强调浏览密度，列表视图强调文件信息的可读性。网格卡片重新设计，“预览”和“更多”操作固定在右上角。

**待选方案：** 提供多个网格卡片方案供选择。各方案使用相同文件样本和主题，展示长文件名、无预览、处理中、错误、选中及菜单展开状态。当前文档不代替视觉方案，也不默认选定其中一种。

**验收要点：** 三种视图有明确用途；切换视图不丢失搜索、排序和选中状态；卡片操作可通过键盘访问；错误和处理状态不被装饰遮挡。

### UI-08 关系图页面压缩工具栏

**目标：**

- 标题行最左侧增加返回按钮。
- 搜索框、筛选项和节点数量控件放入标题行，缩小搜索框宽度。
- 节点数量文案由“最多 XX 个节点”改为“节点 XX”。若数值表示显示上限，通过控件说明保留该含义，避免与实际节点数混淆。
- 条目数和关系数放在“关系画布”小标题右侧。页面保留一行主工具栏，统计信息归入画布标题区。

**待选方案：** 评估圆形图谱布局；评估右侧区域可折叠或悬浮显示。原始记录中的“右侧的关系图”具体指哪个区域，需结合截图和当前页面确认。这两项尚未确定实现方式。

**验收要点：** 返回后保留原页面状态；搜索与筛选有效；长文案和窄窗口不覆盖画布操作。若采用圆形布局，应检查节点重叠、标签可读性及缩放拖拽；若隐藏右侧区域，应保留明确的恢复入口。

### UI-09 设置页重构与布局整理

**目标：** 模型服务、项目权限两个页面需要重构；其余设置页调整布局。卡片标题的上边距与左边距保持一致。

**待形成方案：** 助手设置、专家和插件相关页面存在功能重叠，需要先列出现有入口、配置内容、作用范围和保存位置，再提出合并或保留方案。

**边界：** 入口整合不能直接等同于删除配置。模型服务重构需要保留已有连接配置；项目权限重构需要保留作用范围、当前授权和审批含义。具体页面划分尚未确认。

**验收要点：** 形成“原入口 → 新入口 → 配置是否迁移”的对照表；旧配置可继续读取和保存；卡片间距统一；加载、空状态、错误及未保存状态有完整表现。

### UI-10 新对话输入区增加项目与 Agent 外框

**目标：** 保留现有聊天输入框样式，在外部增加使用主题色的大圆角容器。

| 位置 | 内容与行为 |
|---|---|
| 外框内部 | 现有聊天输入框，保持原样式 |
| 外框底部左侧 | 项目选择入口 |
| 外框底部右侧 | Agent 选择入口，可选择四个 Agent，默认 Fox |
| 输入框内专家入口 | 将“默认专家”改为“专家”；点击直接打开专家选择弹窗 |

**边界：** 仅调整新对话页。四个 Agent 的显示名称、标识和可用状态以实际接入配置为准；选择结果必须用于新会话，不能只改变标签。外框主题色与圆角的具体呈现需结合现有设计变量确认。

**验收要点：** 默认选中 Fox；四个 Agent 均有明确入口；项目与 Agent 选择互不覆盖；专家入口直接打开选择弹窗；输入草稿、附件、中文输入法、发送和取消保持正常；历史对话页面不受此项布局调整影响。
