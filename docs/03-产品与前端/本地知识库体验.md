# 本地知识库体验

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：资料区（`apps/desktop/src/features/local-knowledge`）：最近、本机资料库、本机文件夹、向量模型、任务中心与存储位置<br>
> 最后更新：2026-10-25

## 结论

- 左侧栏顶部「助手 / 资料」中的「资料」进入资料区。界面统一称「资料」「资料库」；代码和本文件名仍沿用 local-knowledge / 本地知识库。
- 资料区左侧导航：**最近**、**资料库**、**向量模型**、**任务中心**；下方「本机」分组列出本机资料库和本机文件夹（带「新建资料库」按钮），登录资料库服务后另有「远程」分组。
- 「资料库」页（标题「资料库」，说明「集中浏览本机资料和 Yuxi 远程资料。」）有「存储位置」和「新建资料库」。新建分三步：挑选文件、命名、导入；第一步也可以「将本机文件夹作为资料库」。
- 搜索方式分「按字词查找」和「智能搜索」；智能搜索需要在「向量模型」页装好搜索模型。本机向量检索已经实现，不再是“后续接入”。
- 存储不可写时 Fox 照常启动，资料库只读或不可用，并在资料库页和 设置 → 资料库 显示「知识库路径不可写：〈路径〉」与「修改存储位置」。

## 本机与远程

| 维度 | 本机资料库 | 远程资料库 |
| --- | --- | --- |
| 数据位置 | Fox 管理的本机目录（默认应用数据目录下 `local-knowledge/`） | 知识库服务 |
| 编辑能力 | 新建、添加 / 移除资料、重新处理、改名、改搜索方式、删除 | Fox 内只读 |
| 离线使用 | 支持 | 依赖服务和登录 |
| 检索 | Tauri 宿主：按字词查找；开启智能搜索后为全文 + 向量混合检索 | 知识库服务 |
| 会话引用 | `{ source: 'local', id }` | `{ source: 'remote', connectionId, id }` |

远程资料库见 [知识库体验](知识库体验.md)。

## 页面

### 最近（`local-knowledge-home`）

- 标题「今天想找点什么？」和搜索框「搜索资料内容，或直接问一个问题」，下面有「试试」示例问题；
- 「最近查看」：按文档去重，最多 8 条，只在 localStorage（`fox.local-knowledge.recent-documents`）保存导航快照，不缓存正文；
- 「最近动态」：资料整理记录，「查看全部处理进度」跳到任务中心；
- 有使用指南时底部显示「第一次使用？看看使用指南」。

### 资料库（`local-knowledge`）

- 顶部：搜索（「搜索资料库和本机文件」）、「存储位置」图标、「新建资料库」；
- 本机资料库卡片和本机文件夹卡片；卡片菜单可编辑信息或删除 / 移除；
- 有搜索词时显示「匹配的本机文件」；
- 底部远程区（`library-remote-section.tsx`）。

### 新建资料库

对话框三步（`local-knowledge-pages.tsx`）：

1. 挑选文件：从电脑不同位置挑选，可多次添加；或「将本机文件夹作为资料库」（收录为本机文件夹，见下）；
2. 命名：名称、简介（选填）、搜索方式（按字词查找 / 智能搜索）；「更多选项」里有段落长度（128–4096）、衔接长度、搜索模型；
3. 导入：后台导入，可继续浏览。

单个文件不超过 256 MB；单次导入有文件数上限（`LOCAL_IMPORT_MAX_FILES`）；同名文件会导入到同一位置时拒绝。

### 资料库详情（`local-knowledge-detail`）

- 面包屑；「添加文件或文件夹」菜单：添加文件 / 添加文件夹（保留目录结构）；新建文件夹；
- 文件管理器（`library-file-manager.tsx`）：详细列表 / 紧凑列表 / 网格视图，按名称、类型、大小、状态、修改时间排序，多选；
- 文件菜单：打开、重新处理、在文件夹中显示、下载原件、从资料库移除（只删副本和搜索数据，原文件保留）；
- 子视图：任务记录、检索测试；「资料库设置」：名称、简介、搜索方式、高级（段落长度、搜索模型、存放位置）、统计（资料、段落、上次整理）、删除资料库。

文档阅读页可「问问这份资料」、复制路径、查看分段（最多显示 100 段）、重新读取、从资料库移除。

内置的「Fox 使用指南」资料库：名称和搜索方式不能改，不能删除。

### 本机文件夹（`local-files`）

收录用户选择的文件夹，不复制文件：

- 页面：面包屑、「搜索文件名称」、刷新文件夹；
- 文件菜单：打开（Fox 预览弹窗）、在文件夹中显示；预览弹窗有「打开所在文件夹」「系统打开」；
- 卡片菜单：编辑信息（只改 Fox 中的名称和简介）、移除文件夹（只取消收录）。

本机文件夹里的文件不会被切分成可检索的段落，也没有「加入资料库」按钮；要检索请新建资料库并添加文件。宿主按文件 ID 重新校验真实路径，预览按最多 4 MB 的范围读取（`MAX_LOCAL_PREVIEW_RANGE_BYTES`）。

### 向量模型（`local-knowledge-models`）

标题「向量模型」，说明「让 Fox 读懂文字的意思，搜索时不必记得原文怎么写。装好一个就够用。」

- 未安装时提示「现在只能按字词查找」，可「下载推荐模型」或从「其他可选」下载；下载可暂停、断点继续；
- 「导入模型包」：手动模型包需通过 manifest 校验；
- 「设为默认」：没有单独绑定模型的资料库使用默认模型；
- 运行状态：引擎（正常 / 兼容模式 / 未就绪）、读写检查（已通过 / 未通过）。兼容模式下智能搜索结果可能不如预期。

### 任务中心（`local-knowledge-jobs`）

页面标题「处理进度」（进入某个资料库时为「任务状态」）。任务状态：排队中、进行中、已暂停、已完成、只完成一部分、失败、已取消、已中断；存储迁移任务另有等待迁移、迁移中、迁移完成、迁移失败。进行中可取消，失败可重试。

## 导入与任务

- 支持 PDF、DOCX、PPTX、XLSX、Markdown、TXT（导入区说明文字）。
- 文件先写 staging，流式复制并计算 SHA-256，校验后原子移动到受管目录。
- Office ZIP 解析限制条目数、展开体积（单条目 64 MB）、压缩比和路径。
- 一个批次一个父 Operation，每个文件一个子 Job；部分成功显示「只完成一部分」。
- Job 保存 sequence、heartbeat 和 checkpoint；应用重启后未完成的运行中任务标为已中断。

## 在对话中使用

在输入框「添加内容 → 添加资料库」或 `/资料库` 选择资料库，或使用声明了资料库的专家。会话中的资料库引用统一为 `KnowledgeReference`；Runtime 使用 `list_knowledge_bases`、`search_knowledge`、`read_knowledge_document` 等工具，由宿主按 `source` 路由（工具路由本次未逐条复核）。

## 存储位置与降级

- 修改位置：资料库页「存储位置」图标，或 设置 → 资料库 → 本机存储 →「修改位置」，打开 `StorageLocationDialog`。显示当前位置、新位置，「选择文件夹」→「确认迁移」；迁移进度在对话框内，完成后提示重启 Fox。
- 迁移步骤：校验目标目录、暂停资料库任务、写入并刷新索引、释放文件句柄、复制、校验、切换存储配置、重新打开数据库、完整性检查、清理旧目录；失败时回滚。
- 降级：路径不可写时资料库只读或不可用，对话框可「使用此位置」选择新文件夹（重启后生效，原位置数据不移动）或「恢复默认位置」。

`knowledge.db`、受管文件、索引和向量数据属于资料库存储；`fox.db` 只保存会话引用和产品配置。文档、段落和检索结果都视为不可信输入，不能扩大工具或项目权限。
