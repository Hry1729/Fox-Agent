# 本地知识库体验

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：本地知识工作区、文档导入、任务状态、对话绑定与存储配置<br>
> 最后更新：2026-08-24

## 产品定位

顶部工作空间切换中的“知识”进入本地知识库。这里的数据由当前用户在本机创建和维护，可以导入、解析、索引、删除和迁移；助手侧栏的“远程知识库”仍是外部服务的只读客户端，两者不会混在同一个管理列表中。

| 维度 | 本地知识库 | 远程知识库 |
| --- | --- | --- |
| 数据位置 | Fox 受管本地目录 | 外部知识库服务 |
| 编辑能力 | 创建、导入、重命名、删除、重建索引 | Fox 内只读 |
| 离线使用 | 支持 | 依赖服务与登录 |
| 检索执行 | Tauri Host；当前为 SQLite 文本检索，Embedding 后续接入 | 远程 Provider |
| 会话引用 | `source = local` | `source = remote`，带连接 ID |

## 页面结构

进入“知识”后，默认打开“最近”页，左侧导航切换为知识专属结构，只显示“最近”“本地文件”“本地知识库”“任务中心”和“我的知识库”。助手模式中的专家、插件、项目、远程知识库与会话历史不会出现在知识侧栏。再次切回“助手”时返回原对话；再次进入“知识”时回到“最近”，避免落入上次打开的深层文档。

本地知识工作区包含：

1. 最近：顶部 Fox 形象和标题尺寸与新建对话页一致，标题下方直接放置本地文件、本地知识库、任务中心和“查看使用指南”四个无图标 34px 胶囊入口，下方展示紧凑字号、增加左右留白的无外框最近访问列表。
2. 本地文件：用户主动添加受控文件夹，按类型与关键词筛选文件，预览、定位或加入目标知识库。
3. 知识库列表：搜索、创建、存储位置、状态、文档数和活动索引代次。
4. 知识库详情：存储、文本索引与最近任务摘要。
5. 文档阅读：选中知识库后，侧栏展开限高文件列表；选中文档后在右侧使用内置查看器阅读。
6. 导入页：调用系统文件选择器，显示待导入文件并创建 Host Job。
7. 任务中心：全局查看任务；进入具体知识库后可只查看该库任务。

最近访问记录仅保存知识库和文档的展示快照，不复制文档内容；按最近打开时间去重并最多保留 8 项。用户从“最近”点击记录后直接恢复对应文档阅读页。

“本地文件”不是知识库本身。Fox 不做全盘扫描，只递归扫描用户主动选择的普通文件夹；符号链接、Fox 自身受管知识目录、不支持的格式和超过 256 MB 的文件会被跳过。取消管理文件夹只删除目录与目录缓存记录，不删除用户原文件。把文件加入知识库时复用既有导入 Job，将文件复制到 Fox 受管存储，之后原文件与知识库副本互不覆盖。

本地文件按 PDF、演示文稿、Word、电子表格和文本使用不同图标。文件行右侧固定提供“加入知识库、在 Fox 中打开、打开所在文件夹”三个图标操作；直接点击文件行进入 Fox 内置预览，不再触发加入知识库确认。Host 根据目录表中的文件 ID 重新校验真实路径，并以 4 MB 范围读取提供预览数据。列表使用分页查询与滚动哨兵渐进加载，首屏只读取固定数量，接近底部后继续追加。内置查看器不支持或加载失败时，弹窗提供系统打开入口。

列表页顶部只显示黑色“本地知识库”主标题；右侧依次提供“存储位置”和“新建知识库”两个 34px 高度按钮，不显示英文 Kicker 或标题注释。创建知识库 Dialog 采用与新建专家一致的 13px 表单字体与 18px 标题；名称必填，描述可选。导入必须通过 Host 获得本地绝对路径，WebView 不把文件内容整体编码后传给 Rust。

知识库列表沿用远程知识库的卡片层级、边框、悬停和统计布局。搜索与刷新工具栏不使用额外的外框、底色或内边距。点击卡片会激活该知识库，并在左侧“我的知识库”条目下展开浅灰文档框；文档框与知识库条目等宽、不做子级缩进，最大高度为 228px，超出后内部滚动。文档行显示类型图标和名称，点击后将 `documentId` 写入工作区路由，并在右侧打开对应内容。受管文件只允许从当前知识库的 `documents/` 目录读取，Host 会拒绝符号链接、目录逃逸和非普通文件。

## 导入与任务

- 支持 TXT、Markdown、PDF、DOCX、PPTX 和 XLSX。
- 文件先写入 staging，流式复制并计算 SHA-256，校验后原子移动到受管目录。
- Office ZIP 解析限制条目数、展开体积、压缩比和路径；拒绝反斜杠穿越、Windows 设备名和 ADS。
- 一个批次使用父 Operation，每个文件使用子 Job；部分成功显示为 partial，不能伪装成整批失败。
- Job 保存 sequence、heartbeat 和 checkpoint；页面通过快照恢复漏失事件。
- 应用重启后，未完成的运行中任务标记为 interrupted；可幂等的 queued 导入继续执行。

## 对话使用

本地与远程知识使用统一 `KnowledgeReference`：

- 本地：`{ source: 'local', id }`
- 远程：`{ source: 'remote', connectionId, id }`

会话选择器必须分组展示来源。Runtime 继续使用现有 `list_knowledge_bases`、`search_knowledge` 和 `read_knowledge_document` 工具，由 Host 根据 `source` 路由，不新增重复的“本地知识”工具名。本地知识图谱未生成时返回明确的 `local_knowledge.graph_unavailable`。

## 存储与隐私

- 默认目录位于 Fox 应用数据目录的 `local-knowledge/`。
- 点击列表页“存储位置”打开迁移 Dialog；用户选择新目录并再次确认后才启动迁移，迁移进度和重启提示保留在 Dialog 内。
- `knowledge.db`、受管原文件和文本索引属于本地知识数据；后续接入的模型与向量索引也放在本地知识存储边界内。`fox.db` 只保存会话引用和产品配置。
- 文档、分块和检索结果都视为不可信输入，不能扩大工具或项目权限。
- 迁移目录时必须先停止任务并关闭 SQLite、索引和模型文件句柄，再复制、校验和切换。

## 当前边界

- 当前阶段明确不实现 Embedding 安装、推理和向量状态 UI，只提供解析、分块与受限词法检索，不得声称向量索引已就绪。
- 本地图谱属于后续阶段，不阻塞普通检索。
- 市场模型下载未完成前，不在首次启动时隐式联网。
- 首次启动创建“Fox 使用指南”默认知识库；教程以文件夹和 Markdown 文档维护在 `apps/desktop/src-tauri/resources/default-knowledge/fox-guide/`，编译时嵌入并按内容 Hash 增量更新。
