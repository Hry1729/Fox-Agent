关键规则

  • 一次添加，一个资料库。选择文件夹后允许改名，展示预计处理范围和模型位置；关闭“用于问答”时只浏览。使用云端模型前明确资料发送范围。
  • 避免重复与嵌套。重复路径打开已有库；父子目录重叠时提示范围冲突，选择复用已有库或排除重叠目录，不静默重复导入。
  • 变更可追踪。按来源标识、相对路径、文件指纹识别增量变更；处理任务幂等。原文件被移动或删除时保留历史引用标识，并提示来源失效。
  • 搜索分两层。默认按文件名筛选，可用全文检索时再提供“搜内容”。跨库搜索标明实际覆盖的库，远程失败时不声称搜索完整。
  • 失败不挡阅读。单文件失败单独重试；失效文件夹可重新定位；远程过期可重新连接。缓存内容标注时间，失效连接暂停问答。
  • 能力决定按钮。浏览、预览、检索、上传、删除、同步均由来源能力与当前权限决定。界面统一不代表能力相同。

分阶段接入，保留退路

  1. 统一导航和只读聚合。给现有本地库、文件夹来源、远程库建立带来源类型的稳定标识；旧路由重定向到统一详情，保留库 ID、文档 ID、会话引用。
  2. 接入文件夹资料库。先建立来源与索引库的关联。已有文件夹不自动重复建库；一对多历史导入关系单独列出，用户确认后关联，不能按同名自动合并。
  3. 接入增量同步与问答。区分文件目录记录和索引文档；覆盖新增、改名、删除、离线、解析失败、重试。远程继续走原服务适配器。
  4. 验收后收起旧入口。通过开关小范围启用，保留旧路由和数据读取方式；迁移前留映射快照，未通过时撤回入口切换，不删除旧数据。

接入前的验收范围

空库、千级文件分页、中文长路径、文件夹失联、重复添加、父子目录重叠、历史一对多导入、云模型告知、远程无目录 / 无预览 / 只读 / 过期权限，以及旧对话引用跳转。键盘操作、窄窗口和三主题明暗模式分别检查。
