# Fox 设计系统

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：`apps/desktop/src/styles/themes.css`、`apps/desktop/src/styles/globals.css`、`apps/desktop/src/components/ui`、`apps/desktop/src/features/settings/settings-layout.tsx`、`settings-layout.css`、`color-theme.ts`、`text-scale.ts`<br>
> 最后更新：2026-10-25

## 结论

- **颜色唯一来源是 `themes.css`。** 三套配色主题：石墨（`graphite`，默认）、暖纸（`paper`）、雾蓝（`mist`），每套都有浅色和深色。每套主题给出完整的 shadcn 语义令牌和少量 Fox 扩展令牌；`globals.css` 里的旧 `--fox-*` 颜色都是这些令牌的别名。
- **默认主题石墨是纯中性灰阶**：主色、品牌色都是近黑（深色模式为近白），只有状态色（destructive / success / warning）带色相。旧文档中“Fox 蓝作为主强调色”不再成立；蓝色调只存在于雾蓝主题。
- **字体是 HarmonyOS Sans SC**，回退 `Segoe UI Variable`、`Segoe UI`、`system-ui`。字号令牌 12 / 13 / 14 / 15 / 16 / 24 / 32px，都乘以用户的文字大小（70%–140%）。字重最高 600。
- **控件高度：页面级 32px（`--fox-action-height`），行内 28px。** 旧文档中的 34px 已不成立。
- **基础组件来自 `components/ui`**（shadcn/ui 风格，基于 `radix-ui`）。设置相关的四种浮层：`Select`（下拉选择）、`AlertDialog`（经 `confirmDialog` 使用的确认框）、`Sheet`（右侧编辑面板）、`Dialog`（居中对话框，如「添加服务」、`promptDialog`）。
- **设置页使用统一的行布局**：`SettingsPageLayout` / `SettingsGroup` / `SettingsRow`，标题 + 一句说明，细线分隔的分组和行，不用卡片。

## 目标与范围

记录当前代码中的视觉令牌、主题机制、基础组件和设置页布局，供新增或修改界面的前端工程师查阅。本文只描述代码里能看到的事实；产品风格判断不在本文范围内。

不在范围内：各业务页面的具体结构（见 [导航与页面布局](导航与页面布局.md)、[设置中心](设置中心.md)、[本地知识库体验](本地知识库体验.md)、[插件中心体验](插件中心体验.md)）。

## 样式架构

`main.tsx` 依次引入：

1. `styles/globals.css`：引入 `tailwindcss`、`tw-animate-css`、`shadcn/tailwind.css`、`themes.css` 和 HarmonyOS Sans SC 字体（Regular / Medium / Semibold / Bold 四个字重文件，来自 `harmonyos-sans-sc-webfont-splitted`）；用 `@theme inline` 把语义令牌映射成 Tailwind 颜色（`bg-background`、`text-muted-foreground`、`bg-brand` 等）；定义 `--fox-*` 尺寸、间距、字号令牌；
2. `styles/workbench.css`：工作台外壳、侧栏、对话；
3. `styles/workspace-pages.css`：管理页面。

另有按功能就近引入的样式：`styles/plugin-center.css`、`styles/local-knowledge.css`、`features/settings/settings-layout.css`、`settings-pages.css`、`components/assistant-ui/elements/fox-elements.css` 等，以及少量 CSS Module（`components/arc/*`）。

启动时 `main.tsx` 先调用 `applyStoredTextScale()` 和 `applyStoredColorTheme()`，再渲染应用，避免先闪默认值。

## 主题

### 配色主题

`features/settings/color-theme.ts`：

| id | 名称 | 说明（代码中的描述） |
| --- | --- | --- |
| `graphite` | 石墨 | 中性灰阶，墨色主按钮，紧凑利落（默认） |
| `paper` | 暖纸 | 米白暖灰，暖金主色，圆润柔和 |
| `mist` | 雾蓝 | 冷调蓝灰，延续 Fox 经典配色 |

- 写在 `<html data-color-theme="…">` 上，保存到 localStorage `fox.preferences.colorTheme`；非法值回落到石墨。
- `themes.css` 的选择器是属性选择器，所以子树（如主题预览色块）可以单独套另一套主题。石墨同时绑定裸 `:root`，在读取偏好前就有主题。
- 石墨规则必须写在最前：非默认主题的深色模式依赖源码顺序覆盖石墨的 `:root.dark`（文件头注释）。

### 明暗模式

`workbench.tsx` 在 `<html>` 上切换 `.dark` 类，偏好存 localStorage `fox.theme`。只有浅色和深色，没有「跟随系统」。Tailwind 的 dark 变体定义为 `&:is(.dark *)`。

### 旧 `--fox-*` 颜色别名

`globals.css` 的 `:root` 中，旧令牌都指向主题令牌，不再单独定义颜色，例如：

- `--fox-canvas` → `--background`，`--fox-card` → `--card`，`--fox-panel` → `--muted`，`--fox-sidebar` → `--sidebar`；
- `--fox-text` → `--foreground`，`--fox-muted` → `--muted-foreground`，`--fox-border` → `--border`；
- `--fox-blue` / `--fox-accent` → `--brand`，`--fox-blue-soft` / `--fox-accent-soft` → `--brand-soft`。名字里虽然有 blue，在石墨主题下是近黑色；
- `--fox-hover`、`--fox-border-strong`、`--fox-faint`、`--fox-surface-*`、`--fox-accent-*`、`--fox-danger-*`、`--fox-success-*`、`--fox-focus-ring`、`--fox-mark`（搜索高亮，取品牌色而不是黄色）等用 `color-mix()` 从主题令牌混合得到；
- `.dark` 只调整混合比例（如 `--fox-faint` 改为不透明混合，注释说明是为了 12px 次要文字在各表面上保持 ≥ 4.5:1 对比度）。

## 字体与字号

- `--font-sans`：`"HarmonyOS Sans SC", "Segoe UI Variable", "Segoe UI", system-ui, sans-serif`；`--font-heading` 同 `--font-sans`。
- `:root` 字号 14px；`font-synthesis: none`；`body` 抗锯齿。
- 字号令牌都乘 `--fox-text-scale`（由 `text-scale.ts` 写入，70–140，默认 100，存 `fox.preferences.textScale`）：

| 令牌 | 基准 | 注释 / 用途 |
| --- | --- | --- |
| `--fox-type-caption`、`--fox-type-meta`、`--fox-type-card-stat` | 12px | 辅助信息、时间、Tooltip |
| `--fox-type-chrome`、`--fox-type-ui`、`--fox-type-control` | 13px | 侧栏、菜单、控件（注释：比对话低一级） |

- 字重令牌：`--fox-weight-regular: 400`、`medium: 500`、`semibold: 600`；`--fox-weight-bold` 也是 600（注释：字重止于 600，bold 只作别名）。

## 全局约定（`globals.css`）

- 可点击元素（按钮、链接、`role=button/menuitem/option/tab/switch/checkbox`、Select 触发器和选项）显示手型指针；禁用元素显示 `not-allowed`。
- Radix `ScrollArea` 的原生滚动条始终隐藏（注释：打包版 WebView2 会画出 15px 经典滚动条）；其他滚动容器统一 thin 滚动条。
- 弹层文字统一：Select 选项、下拉菜单项、右键菜单项最小高 32px、字号 `--fox-type-control`；菜单标签用 `--fox-type-meta`；Tooltip 用 `--fox-type-caption`。
- 状态圆点 `.fox-status-dot`：6px，`is-ok` / `is-error` / `is-warning` / `is-brand` / `is-empty`（空心）。
- 应用禁用了 WebView 默认右键菜单（`main.tsx`）。

## 基础组件

`apps/desktop/src/components/ui` 包含：accordion、alert、alert-dialog、avatar、badge、breadcrumb、button、button-group、card、carousel、collapsible、command、confirm-dialog、context-menu、dialog、dropdown-menu、empty、hover-card、input、input-group、kbd、popover、progress、prompt-dialog、resizable、scroll-area、select、separator、sheet、skeleton、sonner、spinner、switch、tabs、textarea、tooltip，以及 `window-chrome.ts`。其他目录：`components/fox-ui`（`FoxEmptyState`、动画图标）、`components/ai-elements`、`components/assistant-ui`、`components/arc` 等。

### Button

`button.tsx` 的 `variant`：`default`（`bg-primary`，石墨下为墨色实心）、`outline`、`secondary`、`ghost`、`destructive`（卡片底色 + 红色边框和文字，不用整块红底）、`link`。

`size`：`default` 高 `--fox-action-height`（32px）、`sm` 高 `--fox-inline-action-height`（28px）、`xs` 24px、`lg` 40px，以及 `icon` / `icon-sm` / `icon-xs` / `icon-lg` 方形按钮。

### Select

`select.tsx`，基于 Radix Select：

- 触发器圆角 `--fox-radius-control`，`size="default"` 高 32px、`size="sm"` 高 28px，字号 `--fox-type-control`；
- 下拉内容 `z-[110]`、`bg-popover`、`shadow-md`；
- 组件内选项类名是 `text-xs`、`min-h-7`，但 `globals.css` 把所有 portal 中的选项覆盖为最小 32px、`--fox-type-control`。

设置中心约定所有下拉选择都用这个组件（见 [设置中心](设置中心.md#交互约定)）。

### AlertDialog 与 `confirmDialog`

- `alert-dialog.tsx`：居中（纵向中心扣除标题栏高度），遮罩 `bg-black/20`（深色 `/50`）+ 轻微模糊，内容 `z-50`、`rounded-xl`、`bg-popover`，`size` 为 `default` / `sm`。
- `confirm-dialog.tsx` 基于它提供 `confirmDialog(options)`：`title`、`description`、`confirmLabel`（默认「确定」）、`cancelLabel`（默认「取消」）、`destructive`。只有点确认才返回 `true`；取消、Esc、关闭或未挂载 `ConfirmDialogProvider` 都返回 `false`。多个请求排队逐个显示。
- `ConfirmDialogProvider` 和 `PromptDialogProvider` 挂在 `app/App.tsx` 根部。
- `apps/desktop/tests/no-native-confirm.test.ts` 禁止前端使用原生 `confirm` / `prompt` / `alert`。

### Dialog 与 `promptDialog`

- `dialog.tsx`：居中，遮罩和内容 `z-[100]`，最大高 `100vh - 48px - 标题栏`，圆角 `--fox-radius-overlay`，阴影 `--fox-shadow`，正文字号 `--fox-type-body`，标题 `--fox-type-title`、600；默认带关闭按钮（`showCloseButton`）。
- `prompt-dialog.tsx` 基于 Dialog 提供 `promptDialog`（需要用户输入时用，如重命名服务）。
- 设置中的居中对话框加 `fox-settings-dialog`（宽 `min(440px, 100vw - 32px)`）；「添加服务」另加 `fox-provider-add-dialog`（宽 560px，最大高 720px）。

### Sheet

- `sheet.tsx` 基于 Radix Dialog，`side` 为 `top` / `right` / `bottom` / `left`，默认 `right`；从标题栏下方开始（`top: var(--fox-titlebar-height)`），`z-50`，遮罩同 AlertDialog。
- 设置中的编辑面板加 `fox-settings-sheet`：宽 480px（不超过视口），头部 `fox-settings-sheet-head`（下边细线），可滚动主体 `fox-settings-sheet-body`（`scrollbar-gutter: stable`），底部 `fox-settings-sheet-foot`（上边线，放「删除 / 取消 / 保存」）。
- Sheet、Dialog 的内容都用 `keepOpenOnWindowChrome` 包装外部点击处理：点击标题栏不会关闭浮层（`window-chrome.ts`）。

| 组件 | z-index |
| --- | --- |
| Sheet、AlertDialog（含遮罩） | 50 |
| Dialog（含遮罩） | 100 |

### 其他

- `Tabs`：`tabs-list` 默认高 32px、圆角 `rounded-lg`，有 `line` 变体；设置页的分段控件就是加了 `fox-settings-segmented` 的 Tabs。
- `FoxEmptyState`（`components/fox-ui/empty-state.tsx`）：`variant` 为 `empty` / `search` / `error`，支持 `icon`、`action`。
- 集合卡片 `.fox-library-card`：最小高 126px、圆角 `--fox-radius-card`、无阴影（专家、资料库、插件卡片共用）。

## 设置页行布局

`settings-layout.tsx` 提供三个组件，`settings-layout.css` 的选择器都挂在 `.fox-settings-page` 下，旧的 `.fox-settings-layout` 卡片样式影响不到：

```tsx
<SettingsPageLayout title="模型" description="管理模型服务和 Fox 默认使用的模型。" actions={<Button>添加服务</Button>}>
  <SettingsGroup id={settingsSectionId('default')} title="默认">
    <SettingsRow title="默认模型" description="〈一句说明〉">
      <Select>…</Select>
    </SettingsRow>
  </SettingsGroup>
</SettingsPageLayout>
```

（示例只展示结构，文案以各页面代码为准。）

| 部分 | 样式 |
| --- | --- |
| 页面 | 宽 `min(760px, 100% - 48px)`，居中，上下内边距 48 / 64px |
| 页头 | `h1` 字号 `--fox-type-page`、600；说明 `--fox-type-chrome`、`--muted-foreground`；右侧可放 `actions`；下方留 28px |
| 分组 | 组间距 32px；组头最小高 28px，标题 `--fox-type-chrome`、600，下边框 `--border`；右侧 `aside` 用 `--fox-type-caption` 和等宽数字；`scroll-margin-top: 24px` 便于锚点滚动 |
| 行 | 左右两栏，间距 24px，最小高 60px，上下 12px；行间是 70% 透明度的细线，最后一行无线；左侧标题 `--fox-type-body`、500，说明 `--fox-type-caption`；右侧控件右对齐；`align="start"` 时顶部对齐 |
| 控件 | 页面、Sheet、Dialog 内的 Input 和 Select 触发器统一高 32px（`--fox-control-md`） |

配套函数：`settingsSectionId(section)` 生成 `fox-settings-section-<section>`；`useScrollToSettingsSection(section)` 在渲染后最多重试 20 帧滚动到该分组（旧设置路由重定向用）。

除「通用」外，设置中心 6 个页面使用这套布局；「通用」仍是旧的 `SettingsScaffold` + `Card` 结构（见 [设置中心](设置中心.md)）。

## 代码现状与不一致

按事实记录，未在本次修复：

1. **工作模式组件不跟随主题。** `GoalProgress.tsx`、`TaskItem.tsx`、`EvidenceList.tsx` 使用写死的 Tailwind 调色板类（`text-blue-600`、`bg-yellow-100`、`border-green-200` 等）。`components/` 下另有 21 个文件（主要是 `ai-elements`、`arc` 等第三方风格组件）也有同类写法。
2. **CSS 中仍有十六进制颜色。** 除 `themes.css` 的形象色外，`expert-lanyard.css`、`workspace-pages.css`、`workbench.css`、`fox-sidebar.css` 等文件共约 30 处。
3. **AlertDialog 层级低于 Dialog。** `confirmDialog` 用的 AlertDialog 是 `z-50`，Dialog 是 `z-[100]`。资料库设置对话框（Dialog）在关闭时会调用 `confirmDialog`「放弃修改」，按 z-index 推断确认框可能被对话框遮住。未在运行中验证，也未找到覆盖该层级的 CSS。
4. **加载了未使用的字重。** `globals.css` 引入 HarmonyOS Sans SC 的 Bold 字体文件，但字重令牌最高 600，CSS 中也没有 `font-weight: 700` / `bold`。
5. **两处字体栈不一致。** `@theme inline` 和 `:root` 的回退含 `Segoe UI Variable`；`@layer base` 中 `.theme` 类的 `--font-sans` 没有它。
6. **令牌名带 blue 但不是蓝色。** `--fox-blue*` 在石墨和暖纸主题下分别是近黑和暖金。
