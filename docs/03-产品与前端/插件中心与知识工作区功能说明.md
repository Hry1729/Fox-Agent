# 插件中心与知识工作区功能说明

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：插件中心（`apps/desktop/src/features/plugins`）与资料区（`apps/desktop/src/features/local-knowledge`）的入口、操作和边界概览<br>
> 最后更新：2026-10-25

本文是两块功能的概览，便于快速了解入口和分工。细节以专题文档为准：

- 插件中心：[插件中心体验](插件中心体验.md)
- 资料区：[本地知识库体验](本地知识库体验.md)
- 设置 → 插件 / 资料库：[设置中心](设置中心.md)
- 侧栏与路由：[导航与页面布局](导航与页面布局.md)

## 结论

- 左侧栏顶部模式切换是「助手 / 资料」两项。界面上已不再使用「知识」作为模式名，「知识工作区」在界面中叫 **资料**。
- 插件中心在助手模式下，**只展示已安装条目**，分「内置工具 / 技能 / 连接器 / 策略」四页；不能在这里安装、开关或配置范围。
- 启用、添加、配置都在 **设置 → 插件**。
- 资料区导航为 **最近 / 资料库 / 向量模型 / 任务中心**，下方是「本机」资料库与本机文件夹，登录资料库服务后另有「远程」分组。

## 工作空间入口

| 模式 | 左侧栏内容 | 来源 |
| --- | --- | --- |
| 助手 | 新建对话、专家、插件；项目分组和对话列表 | `fox-sidebar.tsx` |
| 资料 | 最近、资料库、向量模型、任务中心；「本机」分组（带「新建资料库」按钮）；「远程」分组 | `local-knowledge-sidebar.tsx` |

切换行为（`workbench.tsx` 的 `switchAssistantMode`）：

- 切到「资料」时总是导航到 `local-knowledge-home`（最近）；
- 切回「助手」时导航到 `chat`。

侧栏折叠时，模式切换变成一个图标按钮，提示「切换到资料」或「切换到助手」。

## 插件中心

页面：`h1`「插件」+ 搜索框（「策略」页不显示搜索），下方四个分页：

| 分页 | 内容 |
| --- | --- |
| 内置工具 | Runtime / Host 提供的工具，名称、说明、分类来自 Tauri 侧 `builtin_tool_*` |
| 技能 | 技能目录中扫描到的技能 |
| 连接器 | `mcp_servers` 中的 MCP / 连接器 |
| 策略 | 生命周期 Hook 管理（`LifecycleHooksSection`） |

前三页的卡片只显示图标、名称、说明（异常时改为红色错误原因）、来源标签（内置 / 官方 / 社区 / 本机）和类型标签。卡片没有开关和按钮。

**与设置的分工**：

| 操作 | 位置 |
| --- | --- |
| 开关技能、查看说明和指令 | 设置 → 插件 → 技能 |
| 添加连接器（本机 MCP / HTTP MCP / OpenAPI）、开关、健康检查、编辑、删除 | 设置 → 插件 → 连接器 |
| 生命周期 Hook | 插件中心「策略」页，或 设置 → 插件 → 策略 →「生命周期 Hook」→「管理」 |
| 回到插件中心 | 设置 → 插件 → 策略 →「工具插件」→「插件中心」（打开「内置工具」页） |

**代码现状**：`plugin-center-page.tsx` 中 `showInstalled = true` 写死，目录区（精选 / 全部 / 分类 / 安装按钮 / 添加插件）成为不可达代码；已安装卡片的开关和范围配置被 `void` 掉，`ScopeDialog` 无法打开。前端网关的安装、更新、卸载直接返回「需要等待 Host 操作命令接入」。详见 [插件中心体验](插件中心体验.md#代码现状)。

插件中心只是聚合视图：MCP 由 Host 管理，技能只注入指令、不获得新的工具权限，工具权限仍受项目权限、专家工具白名单和审批限制。

## 资料区

### 最近（`local-knowledge-home`）

- 标题「今天想找点什么？」，搜索框和「试试」示例问题；
- 「最近查看」最多 8 条，按文档去重，只在 localStorage（`fox.local-knowledge.recent-documents`）存导航快照，不缓存正文；
- 「最近动态」显示资料整理记录，可跳到任务中心；
- 存在「Fox 使用指南」时，底部显示「第一次使用？看看使用指南」。

### 资料库（`local-knowledge`）

本机资料库和本机文件夹卡片、搜索、「存储位置」、「新建资料库」，底部是远程资料区。新建资料库分三步：挑选文件、命名、导入。详情页有文件管理器、任务记录、检索测试和资料库设置。

本机资料库会把文件复制到 Fox 受管存储，再做导入、解析、分块和索引；存储位置可在资料库页或 设置 → 资料库 修改，迁移需要确认，完成后重启生效。

### 本机文件夹（`local-files`）

收录用户选择的文件夹，**不复制文件，也不参与检索**：

- 文件菜单：打开（Fox 预览弹窗）、在文件夹中显示；预览弹窗提供「打开所在文件夹」「系统打开」；
- 没有「加入资料库」按钮。要检索这些文件，需要新建资料库并添加文件；
- 宿主按文件 ID 重新校验真实路径，前端不能提交任意绝对路径；预览单次读取范围不超过 4 MB（`MAX_LOCAL_PREVIEW_RANGE_BYTES`，`local_knowledge.rs`）。

### 向量模型（`local-knowledge-models`）

下载、导入、设为默认搜索模型。未安装时只能「按字词查找」；装好后资料库可以使用「智能搜索」。

### 任务中心（`local-knowledge-jobs`）

页面标题「处理进度」（在某个资料库内为「任务状态」）。显示导入、解析、分块、索引等任务；进行中可取消，失败可重试。任务状态持久化，重启后未完成的运行中任务标为「已中断」。

### Fox 使用指南

Fox 启动时由 `ensure_default_fox_guide`（`apps/desktop/src-tauri/src/local_knowledge.rs`）创建 id 为 `fox-user-guide` 的「Fox 使用指南」资料库：

- 教程源文件在 `apps/desktop/src-tauri/resources/default-knowledge/fox-guide/`，通过 `include_str!` 逐个编译进应用（文件清单写在 `DEFAULT_FOX_GUIDE_DOCUMENTS` 里，新增教程文件必须同时加到这个列表）；
- 每次启动比较文件内容和 SHA-256 内容 Hash，有变化才重写，不需要联网；
- 这个资料库名称和搜索方式不能改，不能删除（见 [本地知识库体验](本地知识库体验.md)）。

## 已知限制

- 插件中心不能安装、开关或配置范围，相关代码保留但不可达。
- 本机文件夹不参与检索。
- 资料库页和远程区的部分文案仍含「Yuxi」字样（见 [本地知识库体验](本地知识库体验.md#已知限制)）。
