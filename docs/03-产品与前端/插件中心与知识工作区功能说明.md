# 插件中心与知识工作区功能说明

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：插件中心与本地知识工作区页面入口、操作和边界<br>
> 最后更新：2026-08-24

本文集中说明助手侧的插件中心和知识侧的本地知识工作区，作为页面入口、用户操作和实现边界的统一说明。详细设计分别参考[插件中心体验](插件中心体验.md)和[本地知识库体验](本地知识库体验.md)。

## 工作空间入口

顶部“助手 / 知识”切换决定当前工作空间：

- 助手工作空间显示对话、专家、插件、项目和远程知识库；
- 知识工作空间显示最近、本地文件、本地知识库、任务中心和本地知识库快捷列表；
- 切回助手时保留原对话；进入知识时统一回到“最近”，再由最近访问快速恢复文档位置。

新页面统一只显示黑色主标题，不增加蓝色英文 Kicker、标题下注释或重复的蓝色说明卡。主操作按钮统一使用 `--fox-action-height`，当前值为 34px。

## 插件中心

插件中心是助手工作空间中的独立页面，不放入设置。页面首行左侧直接使用三段胶囊切换 MCP、Skills 和工具，右侧依次提供搜索、“我安装的”和“添加插件”；分类筛选左对齐放在下一行，刷新位于该行右侧。页面不再显示重复的“插件中心”标题。

目录卡片保持一行三列，只保留图标、名称、类别、两行简介和必要的安装状态，不显示“内建能力”、运行时元数据、底部分割线或卸载按钮。工具卡片使用与专家简介一致的字号，并展示各工具自身用途，不使用统一的“Host 执行和授权”占位描述。“我安装的”进入独立管理页，页首提供返回入口、“我安装的”标题、总数角标与搜索框；已安装插件使用紧凑卡片和开关管理启用状态。

插件中心只聚合展示和配置，不改变各类扩展的运行事实源：MCP 由 Host 管理，Skill 是方法和指令包，工具来自 Runtime Contract、Fox Tool Definition 与 Host Capability。兼容的 Pi Custom Tool 可以通过适配层接入，但插件安装或启用不能扩大当前项目和专家的权限边界，也不会自动执行未受信任的 Pi 扩展代码。

## 本地文件

用户主动添加文件夹后，Fox 才会扫描其中受支持的普通文件。扫描结果只保存目录和文件元数据，不移动或删除原文件。

文件类型使用独立图标和颜色。列表右侧操作栏依次提供：

1. 加入知识库；
2. 在 Fox 中打开；
3. 打开所在文件夹。

直接点击文件行会打开 Fox 内置预览弹窗，不再弹出“是否加入知识库”。PDF、PPTX、DOCX、XLSX、Markdown 和 TXT 使用现有只读查看器或文本视图；不支持、损坏或超过限制的文件显示明确说明，并提供系统打开按钮。文件列表按页读取，滚动接近底部时自动加载下一批，避免一次把大目录全部送入 WebView。

Host 只接受文件目录表中的稳定 ID。读取预览内容前会重新校验文件仍位于已登记来源目录，前端不能提交任意绝对路径。大文件通过 4 MB 分段读取，避免把完整文件一次编码进 WebView 命令参数。

## 本地知识库

本地知识库将用户选择的文件复制到 Fox 受管存储，并创建可恢复的导入、解析和索引任务。存储位置可以由用户修改；迁移需要显式确认，并迁移 `knowledge.db`、受管文件和索引。

“最近”作为知识空间首页，顶部使用 Fox 形象和阅读提示语，提示语下方直接提供本地文件、本地知识库、任务中心和“查看使用指南”四个 `104 × 36px` 胶囊入口，下方以无外框紧凑分栏列表展示最多 8 个最近访问文件。最近访问按文档去重，仅保存本地导航快照，不缓存文件正文。

Fox 首次启动会创建“Fox 使用指南”默认知识库。教程源文件位于：

`apps/desktop/src-tauri/resources/default-knowledge/fox-guide/`

教程按文件夹和 Markdown 文档组织，编译时嵌入应用；启动时按内容 Hash 增量写入本地知识库。更新 Fox 可以同步新版教程，不需要首次启动联网。

点击知识库后，左侧“我的知识库”中会在当前知识库下展开一个与知识库条目等宽、限高且可滚动的浅灰文档列表。点击文档后直接在右侧工作区打开内容；PDF、Office 和文本格式复用与远程知识库一致的只读查看器，文档路径和读取范围由 Host 再次校验。知识库列表的搜索与刷新不再套用额外大卡片外框。

## 任务中心

任务中心显示导入、解析、分块和索引状态。标题区域不显示副标题和蓝色说明卡。Operation 与子 Job 持久化 sequence、进度、结果和错误，刷新或重启后可以恢复显示。
