# 插件中心体验

> 状态：生效<br>
> 适用版本：Fox 0.1.x<br>
> 维护范围：MCP、Skills、内建工具的统一目录、启用状态与安装入口<br>
> 最后更新：2026-08-24

## 产品定位

助手工作区主侧栏增加“插件”。插件中心与专家、知识库一样直接打开在右侧工作区，不归入设置中心。页面统一展示 MCP、Skill 和内建工具，但不把三者强行变成同一种运行机制：

- MCP 继续由 Host 管理进程、凭据、Schema、审批和调用审计。
- Skill 是指令包，只能收窄或声明所需工具，不能获得额外执行权限。
- 内建工具来自 Runtime/Host Capability，只读展示兼容性与可用状态。

## 页面结构

- 页面不显示重复的“插件中心”标题。首行左侧直接放置 MCP/Skills/工具三段胶囊，右侧依次放置搜索框、“我安装的”和“添加插件”，并保持水平对齐。
- 第二行分类筛选左对齐，刷新位于最右侧；所有输入框和操作按钮统一使用 `--fox-action-height`（当前为 34px），不使用标签分割线。
- 页面滚动区固定预留垂直滚动条占位，切换不同插件类型时不得产生横向抖动。
- “精选工具”“全部工具”“最近操作”等内容区块只显示黑色主标题，不显示蓝色英文 Kicker 或标题下注释。
- 目录卡片一行三列，只展示图标、名称、类别、两行简介和必要的安装动作或状态；不展示“内建能力”、运行时元数据、底部分割线、底部说明或卸载按钮。
- 点击“我安装的”进入独立管理页。左上提供返回图标和“全部技能”，页标题“我安装的”后紧跟总数角标，右侧提供搜索框；MCP、Skill 和工具使用紧凑卡片，右上开关用于启用或停用，不显示安装/已安装标签。
- 全局启用项可以直接切换；按 Agent 启用的 Skill 显示已启用 Agent 数量，并进入范围配置。
- 未接入真实市场前，精选区域只使用内建目录；安装、更新和卸载返回明确不可用状态，不能伪造成功。

## 状态与事实源

插件卡片是聚合视图，不是新的运行事实源：

| 类型 | 事实源 |
| --- | --- |
| MCP | `mcp_servers`、Keyring 与最近测试状态 |
| Skill | Skills 目录、Agent Runtime Config |
| Tool | Runtime Contract 与 Host Capability |
| 市场安装 | `plugin_installations`、`plugin_operations` |

激活状态区分 `global`、`per_agent` 和 `not_applicable`。前端只提交合法的 `PluginActivationUpdate`；Host 再校验目标类型和权限边界。

## 安全与安装

- ZIP 导入必须防路径穿越、设备名、ADS、符号链接和压缩炸弹。
- 安装包需要来源、版本、Hash、签名和兼容性信息。
- 密钥只写系统凭据存储，目录卡片只能看到 configured 状态。
- 安装、更新、卸载使用可恢复 Operation；进度事件丢失后通过 Operation 快照恢复。

## 当前边界

- 当前真实闭环覆盖现有 MCP/Skill/Tool 的聚合展示与启用。
- 远端市场 Catalog、签名下载、更新和下架机制属于后续阶段。
- 当前 stdio MCP 是按操作启动，不展示误导性的长期“运行中”开关。
