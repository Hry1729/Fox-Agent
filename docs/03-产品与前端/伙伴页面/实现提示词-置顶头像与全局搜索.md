## 要改的几项

### 1. 删除伙伴页侧栏的搜索框

模式切换行右侧已经有全局搜索按钮，伙伴页不再单独放搜索框。

- 删除伙伴页侧栏的搜索框、「搜索结果」列表和「没有找到「…」」空状态，以及只为它服务的状态、筛选函数和样式。
- 「新建伙伴」行下面直接接置顶大头像（第 2 项）。
- 工作页「管理常用伙伴」浮层里的搜索框保留，它只在浮层内筛选，不属于这次删除的范围。

### 2. 置顶伙伴改成大头像网格，去掉分组标题

参考 OpenMausBot 的 `src/components/SidebarTiles.tsx`（路径 `D:/python/projects/Fox/output/ui-refresh-20261111/reference/OpenMausBot-main`，只读）。规格见方案第 5.1 节的表格，原型 CSS 是 `index.html` 里的 `.ptiles` 和 `.ptile`。

- 每块 76 × 92px，56px 圆形头像，名称在头像下方 6px，`--fox-type-ui`、中等字重、居中、单行省略。块之间间距 4px，236px 的轨道内一排正好 3 个，多了换行，最后一行居中（`flex-wrap: wrap` 加 `justify-content: center`）。网格上下外边距 6px / 8px。
- 新增 token `--fox-sidebar-companion-tile-avatar-size: 56px`，加在 `globals.css` 的 `--fox-sidebar-*` 旁边，并同步写进 `docs/03-产品与前端/design-system/DESIGN-SYSTEM.md` 第 9.8 节和 `tokens.json`。块宽、块高如果要用 token，也放在同一处。
- 状态：运行中在头像右下角显示 12px 绿点；等待确认显示橙色「!」；未读在头像右上角显示 11px 圆点，不显示数字；免打扰时圆点改为灰色。状态点都带 2px 侧栏底色描边，深色主题下描边跟随侧栏底色。
- 悬停和选中使用侧栏统一的悬停、选中底色，圆角 `--fox-radius-control`。如果列表行用了 `data-sidebar-motion-item` 的移动高亮，大头像也接入同一套；接不进去就用静态底色，不要另写一套动画。
- 点击打开私聊，和点击列表行一样。右键单击打开与列表行相同的菜单（「取消置顶」在里面）；键盘焦点在大头像上时，Shift+F10 或菜单键也能打开。大头像悬停时不显示「…」，悬停 tooltip 显示全名。每块是一个 `button`，`aria-label` 为伙伴名称，带上未读和状态。
- 小狐始终是第一块：读取时把 `is_default = 1` 的伙伴视为置顶并排第一，不依赖 `pinned_at`。小狐的菜单里没有「置顶 / 取消置顶」「归档」「删除…」，也不提供隐藏。Rust 的 `companion_set_pinned` 对默认伙伴返回错误，拒绝文案的写法参考 OpenMausBot `server/default-bot.ts` 的 `defaultBotRefusal`。
- 其余置顶伙伴沿用现有的 `pinned_at DESC`；不限制置顶数量。因为小狐总在，网格总会渲染。
- 小狐和置顶的伙伴只出现在网格里，下面的列表不再重复。取消置顶后回到列表。
- 删除「置顶」「全部伙伴」两个分组标题、「全部伙伴」后面的数量，以及标题右侧的排序菜单。下面的列表按最近消息时间倒序。
- 侧栏收起时，头像顺序与展开时一致：先置顶，再其他伙伴。

### 3. 全局搜索新增「伙伴」分类

规则见方案第 5.6 节，界面见原型 `search` 帧（截图 `images/10-全局搜索伙伴.png`）。

Rust（`src-tauri/src/database/repositories/app_management.rs` 的 `global_search`）：

- 新增一段查询 `companion_profiles`：`archived_at IS NULL AND deleting_at IS NULL`，`display_name` 或 `duty` 用 `LIKE ?1 ESCAPE '\\'` 匹配，转义沿用函数开头的写法。
- 返回 `kind = "companion"`、`title = display_name`、`subtitle = duty`、`workspace_view = "companions"`、`entity_id = 伙伴 id`、`updated_at` 取伙伴的 `updated_at`。
- 伙伴结果最多 5 条，按 `updated_at` 倒序，单独放在结果最前面；其余结果仍按原规则排序，截断到 `limit` 减去伙伴条数。
- 私聊消息仍然不进全局搜索。`commands/mod.rs` 里断言私聊不在搜索结果中的测试保持通过，不要改它的断言。

前端：

- `features/conversations/model/types.ts` 的 `GlobalSearchRecord.kind` 增加 `'companion'`；`features/chat/fox-shared.tsx` 的 `globalSearchKindLabel` 增加 `companion: '伙伴'`。
- `features/chat/shell/fox-sidebar.tsx` 现在按结果出现的先后分组，改成按固定顺序输出，「伙伴」排第一，其余分类保持现有顺序。
- 伙伴结果左侧显示 28px 圆形头像，从已加载的伙伴列表里按 `entityId` 取；取不到时用默认头像。第一行名称，第二行职责，职责为空时显示「伙伴」。命中的字高亮，做法沿用现有结果。
- `openGlobalSearchResult` 遇到 `companion` 时：关闭搜索，切到伙伴页，选中该伙伴，打开它的私聊。在工作页里点击也切到伙伴页。
- 输入框占位文字改为「搜索对话、伙伴、项目、资料、文件或任务」。

## 约束

- 只用现有的 `--fox-*` 和主题变量，不写死颜色、圆角、阴影和字号。
- 三条对齐线（轨道 12、图标列 20、动作列距右 14）保持不变。大头像网格本身居中在轨道内，不要求对齐图标列，但不能超出轨道。
- 不新增 npm 依赖。Rust 侧不新增表和字段。
- 文件保持 LF 换行。
- `mock.module` 是进程级的：测试中 mock 时展开真实模块，并在 `afterAll` 里还原。
- 工作区有用户未提交的改动，在它们的基础上继续，不要还原或 stash。
- 不要提交，也不要推送。

## 测试

新增或更新的测试至少覆盖：

- 伙伴页侧栏没有搜索框，也没有「置顶」「全部伙伴」标题。
- 只有小狐时网格里只有小狐一块；再置顶 3 个伙伴时，网格里有 4 块（小狐第一），列表里没有这 4 个伙伴。
- 小狐的菜单没有置顶、归档、删除；Rust 测试取消默认伙伴的置顶返回错误。
- 大头像点击打开私聊；右键打开菜单，菜单里有「取消置顶」；取消后伙伴回到列表。
- 大头像上的运行中、等待确认和未读状态。
- Rust：按名称命中、按职责命中、已归档和正在删除的伙伴搜不到、伙伴结果排在最前且最多 5 条、私聊消息搜不到。
- 前端：「伙伴」分类排第一，标签为「伙伴」，点击后切到伙伴页并选中该伙伴。
