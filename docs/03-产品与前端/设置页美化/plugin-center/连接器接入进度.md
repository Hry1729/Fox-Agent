## 验证范围

- 108 个条目与原候选目录逐项核对了 ID。原生目录测试覆盖新增配置后的合并，避免同一个连接器显示两次。
- 51 个固定公网地址响应了匿名 MCP 初始化请求。HTTP 200 或 401 只说明服务响应。Obsidian 采用本机地址，单独计入固定服务。
- DeepWiki 已由 Fox 原生客户端列出工具并读取公开仓库。13 个随 Fox 提供的业务适配器通过标准输入输出返回了工具定义。
- 本机 MQTT 测试通过真实消息代理收件、通过 MCP 读取消息，并将回复发送回原设备主题。其余机器人待平台账号联调。
- OAuth 回调、PKCE、刷新、飞书令牌交换和预注册应用的服务端密钥交换已通过本机测试。飞书真实租户创建文档和追加内容仍待验收。

## 飞书首批验收

用测试租户授权 Fox，在对话中请 Fox 新建一篇测试文档。打开返回的飞书链接，再请 Fox 追加一段文字并读回。发布前记录该租户所需的管理员审批和用户实际操作步骤。
