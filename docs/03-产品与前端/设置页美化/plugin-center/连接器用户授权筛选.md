# 按用户授权体验筛选 108 个 Fox 连接器

2026 年 11 月 25 日。范围与[原始目录](连接器候选清单.md)一致。假设 Fox 已完成应用注册、审核、凭证续期、适配器分发或托管。这里考察普通用户从点「连接」到完成第一项有效操作，还要做什么。结论来自平台文档和维护者仓库，均未视为 Fox 桌面实测通过。

## 首批建议接入的 6 项

| 顺序 | 连接器 | 为什么先接 | 第一条验收用例 |
| ---: | --- | --- | --- |
| 1 | 飞书文档（目录名「飞书 / Lark」） | 国内协作优先。官方提供搜索、读取、创建和更新。选择允许安装或已放行 Fox 的租户验证成员授权，另用受管租户核对管理员审批。 | 成员点「连接飞书」并同意，在 Fox 里说「把这段结论追加到《产品周报》」，返回链接并读回新内容。 |
| 2 | 滴答清单（国内） | 官方已有浏览器授权，个人可以独立验证，任务的增改结果也容易核对。 | 普通国内账号授权后创建「明天提交周报」，再让 Fox 标记完成，在滴答清单核对。 |
| 3 | Notion | 同一授权流程覆盖知识库检索和页面写回，能与飞书对照。Enterprise 可限制外部客户端。 | 在有编辑权限的页面追加一段文字，返回页面链接。 |
| 4 | Trello | 官方明确支持所有套餐。个人免费账号就能验证核心看板操作。 | 新建卡片，将它移到「完成」，在原看板核对。 |
| 5 | GitHub | 用个人仓库即可验证按仓库授权。Fox 可以自行注册 GitHub App，选仓库、授权和调用 API 均有厂商支持。 | 仅授权一个测试仓库，新建一个 Issue 并返回真实链接。 |
| 6 | Linear | 官方授权后就能操作工单。普通工作区与启用应用审批的工作区可以分别验证。 | 新建一项任务，再把状态改为完成，读回工单编号和状态。 |

若下一批优先做办公文件，排 **Google Drive**。按文件授权时用户登录后还要在 Google Picker 选文件。若目标是「从我的整个云盘找文件」，Fox 需另行申请合适的访问范围并完成审核，不能用选中文件的样例验收全盘搜索。[Drive 授权范围](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)

## 怎么读这份清单

每项只按目录所列用途和当前选定路线计数一次。「用户可自行授权」含登录同意、绑定账号及公开机器人的私聊入口。个人自助和企业限制可以同时成立，例如 GitHub 的个人仓库能自助授权，但组织仓库可能要求所有者同意。表内另列角色、地区、套餐和部署条件。未查到明确的免费版承诺时，保留为待验，未据此保证免费。

| 主要门槛 | 项数 | 用户实际会遇到什么 |
| --- | ---: | --- |
| 用户自行授权或绑定 | 38 | 已有适用账号或项目时，可以按提示授权。企业限制、角色差异和免费额度见各行。 |
| 组织或角色 | 28 | 对目录目标，先看企业是否已启用、用户是否有权安装、资源是否已分配，已放行时成员也可能只需点几下。 |
| 密钥或授权码 | 21 | 已核实路线需手填密钥。有些公共服务可由 Fox 采购并代用户配置。 |
| 已有环境 | 10 | 要有数据库、知识库、已发布工作流或本地软件。已有托管服务可以复用，不要求每个成员自行部署。 |
| 无需平台账号 | 5 | 可以直接使用，或只需选择文件夹、允许使用本机浏览器。 |
| 待核 | 3 | 已有参考实现或单一入口，Fox 对外分发或目标功能仍缺依据。 |
| 集成平台 | 3 | 面向 Fox 开发团队采购或自建，下游应用的用户仍要各自授权。 |

### 审批、付费和部署分别看什么

- **管理员审批。** 飞书优先验证已放行租户，同时保留「向管理员申请」分支。Notion Enterprise、Linear 和 GitHub 组织可启用第三方应用限制。Box 推荐先在管理控制台启用。Jira 和 Confluence 还要看 Fox 的回调域名是否获准。Fox 提交应用接受厂商审核属于接入成本。[飞书成员安装](https://www.feishu.cn/hc/zh-CN/articles/360049067396-%E6%99%AE%E9%80%9A%E6%88%90%E5%91%98%E8%8E%B7%E5%8F%96%E4%B8%8E%E4%BD%BF%E7%94%A8%E5%BA%94%E7%94%A8) · [Linear 审批策略](https://linear.app/docs/third-party-application-approvals) · [Atlassian 域名控制](https://github.com/atlassian/atlassian-mcp-server)
- **先有付费权益。** 语雀的个人 Token 路线涉及会员，MiniMax Coding Plan 专属工具依赖订阅，Salesforce Hosted MCP 面向有 Flex Credits 的客户。**部分动作或超额才收费**的例子有 Figma 低席位配额、OpenAlex 查询预算、企查查积分和在线抓取额度。Trello 基础看板可以在免费版使用，其 Planner 高级动作另计。地图类若由 Fox 购买商用授权，应列为 Fox 成本。[语雀令牌](https://docs.agent.bailian.aliyun.com/zh/connector/apps/yuque) · [Salesforce 权益](https://developer.salesforce.com/docs/platform/hosted-mcp-servers/guide/hosted-mcp-servers-overview.html) · [Figma 配额](https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/) · [Trello 套餐](https://github.com/atlassian/trello-mcp-server)
- **需要有人准备环境。** 10 项里，PostgreSQL、Redis、MongoDB、ClickHouse、Elasticsearch、Grafana、MQTT 和 WeKnora 需要已有可达实例或有人部署。Dify 需要应用所有人先发布工作流，云版也可以。Obsidian 需要本机已有笔记库并启用相应插件。Fox 打包本地工具、运行机器人服务的工作由 Fox 承担。
- **验证标准。** 首批均用普通账号从 Fox 点「连接」，在官方页面同意，回到 Fox 完成上表的真实操作，重启后能继续使用。对写操作核对目标系统里的实际结果。企业场景分别用已放行和受限租户检查授权页面。
