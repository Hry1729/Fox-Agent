# 开发环境搭建

> 状态：当前<br>
> 适用版本：Fox 0.1.0<br>
> 维护范围：Fox 工作区、桌面端、Tauri 后端与 Agent Runtime<br>
> 最后更新：2026-07-29

## 目标与范围

本文帮助新工程师在 Windows 上完成依赖安装、前端开发、Tauri 联调和生产构建前的基础检查。Fox 当前以 Windows 桌面端为主要交付目标；其他平台虽然保留了 Tauri 图标资源，但尚未形成经过验证的构建基线。

## 工作区结构

```text
Fox/
├─ apps/desktop/                 # React 19 + Vite 6 + Tauri 2
│  ├─ src/                       # 前端
│  └─ src-tauri/                 # Rust Host、SQLite、外部服务适配
├─ services/agent-runtime/       # Node/Bun Sidecar Runtime
├─ scripts/                      # 跨模块契约校验脚本
├─ docs/                         # 项目文档
├─ package.json                  # 根脚本入口
└─ pnpm-workspace.yaml           # pnpm 工作区声明
```

## 工具要求

仓库目前没有机器可读的最低版本文件。以下为仓库声明或本项目已经验证的版本，不代表正式最低版本承诺。

| 工具 | 用途 | 当前依据 |
| --- | --- | --- |
| Windows 10/11 x64 | 主要开发与发布平台 | Tauri Sidecar 目标为 `x86_64-pc-windows-msvc` |
| Node.js | Vite、测试脚本、开发态 Runtime | 本地验证为 `24.15.0` |
| pnpm | 唯一工作区包管理器 | `packageManager` 声明 `pnpm@11.7.0` |
| Bun | 编译独立 Runtime Sidecar | 本地验证为 `1.3.14` |
| Rust MSVC 工具链 | 构建 Tauri 后端 | 本地验证为 `rustc/cargo 1.95.0` |
| Microsoft C++ Build Tools | Windows 原生链接 | Tauri/Rust MSVC 构建依赖 |
| WebView2 Runtime | 运行 Tauri WebView | Windows 桌面运行依赖 |

发布前应固定并验证正式最低版本；在此之前，优先使用上述已验证组合。

## 安装依赖

在 `D:\python\projects\Fox\Fox` 执行：

```powershell
corepack enable
corepack prepare pnpm@11.7.0 --activate
pnpm.cmd install --frozen-lockfile
```

若机器未安装 Bun，请按 Bun 官方方式安装，并确认：

```powershell
bun --version
```

Rust 应使用 MSVC 工具链：

```powershell
rustup default stable-x86_64-pc-windows-msvc
rustc --version
cargo --version
```

不要混用 `npm install` 与 pnpm。仓库以 `pnpm-lock.yaml` 为依赖事实来源，根目录 `package-lock.json` 已被 `.gitignore` 排除。

## 启动方式

### 仅启动前端

```powershell
pnpm.cmd dev
```

Vite 固定监听 `http://127.0.0.1:1421`，且启用了 `strictPort`。端口被占用时不会自动换端口。

### 启动完整桌面应用

```powershell
pnpm.cmd tauri dev
```

Tauri 会先执行桌面包的 `pnpm dev`，随后启动 Rust 主程序。开发态默认从 `services/agent-runtime/src/pi-runtime.mjs` 启动本地 Runtime。

### 使用假 Runtime

在排查 UI、事件归并或数据库恢复时，可以隔离真实模型调用：

```powershell
$env:FOX_RUNTIME_MODE = "fake"
pnpm.cmd tauri dev
```

结束后清理当前终端变量：

```powershell
Remove-Item Env:FOX_RUNTIME_MODE
```

### 使用隔离数据目录

调试迁移、恢复和破坏性测试时不要直接使用日常数据：

```powershell
$env:FOX_DATA_DIR = "$env:TEMP\fox-development-data"
pnpm.cmd tauri dev
```

`FOX_DATA_DIR` 会替代 Tauri 默认应用数据目录，数据库、附件、Skills、Runtime Session 和缓存都会写入该目录。

## 外部服务

Fox 通用助手需要可用的模型供应商。真实知识库和远程智能体功能还需要知识库服务，但知识库服务不是启动 Fox UI 的硬依赖。

开发者应通过应用设置页保存服务地址与凭证。API Key、知识库 Token 和 MCP 环境变量进入 Windows Credential Manager，不应写入 `.env`、SQLite、日志或测试夹具。

## 首次验证

```powershell
pnpm.cmd --dir apps/desktop build
pnpm.cmd runtime:test
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml
```

需要验证生产 Sidecar 时再执行：

```powershell
pnpm.cmd runtime:build
pnpm.cmd runtime:smoke
```

## 常见故障

### `tauri` 不是内部或外部命令

先确认从工作区根目录安装了依赖：

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd --dir apps/desktop exec tauri --version
```

不要依赖全局 Tauri CLI；项目声明的是 `@tauri-apps/cli` 本地依赖。

### `Pi Runtime dependencies are missing`

开发态 Rust Host 会检查 `@earendil-works/pi-agent-core` 与 `@earendil-works/pi-ai`。从根目录重新执行 `pnpm.cmd install --frozen-lockfile`，不要只在 `apps/desktop` 安装。

### 端口 1421 被占用

结束占用进程后重试。不要临时修改端口而不同时更新 `apps/desktop/vite.config.ts` 和 `apps/desktop/src-tauri/tauri.conf.json`。

### 白屏后才出现内容

先比较“仅 Vite”和“完整 Tauri”的启动时间。若 Vite 很快而 Tauri 较慢，重点检查数据库迁移、Runtime 初始化和外部服务探测；若前端本身较慢，检查重型预览器或图谱依赖是否被提前加载。

## 验证清单

- `pnpm.cmd install --frozen-lockfile` 无依赖漂移。
- `http://127.0.0.1:1421` 可在开发态打开。
- `pnpm.cmd tauri dev` 能启动 Fox 窗口。
- 假 Runtime 和隔离数据目录均可用。
- TypeScript 构建、Runtime 测试和 Rust 测试通过。
