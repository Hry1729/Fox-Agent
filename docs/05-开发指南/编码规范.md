# 编码规范

> 状态：当前<br>
> 适用版本：Fox 0.1.0<br>
> 维护范围：TypeScript、React、CSS、Rust、Node Runtime 与文档<br>
> 最后更新：2026-07-29

## 目标与范围

本文总结仓库已经采用的编码约束，并补充跨层变更必须遵循的工程规则。仓库当前没有 ESLint、Prettier、rustfmt.toml 或 clippy.toml；格式与静态质量主要由 TypeScript strict、Cargo 工具和评审约束保证。

## 通用原则

- 优先复用现有模块、组件和错误模型，不创建平行实现。
- 让数据所有权清晰：SQLite 保存产品事实，Runtime 负责执行，前端负责展示与交互。
- 对网络、文件、子进程和长耗时渲染提供失败、取消、超时和清理路径。
- 凭证不得进入 SQLite、JSONL、诊断输出或日志。
- 避免无关格式化、目录移动与抽象重构。
- 代码注释解释“为什么”和约束，不复述语句行为。

## TypeScript 与 React

### 编译约束

`apps/desktop/tsconfig.json` 已开启：

- `strict`
- `isolatedModules`
- `forceConsistentCasingInFileNames`
- `noEmit`
- `moduleResolution: Bundler`

使用 `@/` 别名引用 `apps/desktop/src/` 内模块。不要通过深层相对路径绕开现有模块边界。

### 目录职责

- `app/`：应用入口与全局组合。
- `features/`：按业务域组织页面、Hook、数据适配与模型。
- `components/ui/`：shadcn/Radix 基础组件。
- `components/ai-elements/`：对话与 Agent 语义组件。
- `components/effects/`：可复用视觉效果。
- `styles/`：全局 Token 与页面级样式。
- `lib/`：无业务状态的通用函数。

展示组件不要直接承担 Tauri 事件订阅、数据库恢复合并和网络生命周期；这些逻辑应进入 feature Hook、model 或 API adapter。

### 状态与异步

- 实时事件必须按 `runId`、`conversationId` 和序号归并，拒绝跨会话事件。
- 乐观消息必须有稳定临时 ID，并能被 SQLite 返回的真实消息替换。
- Effect 中注册的 Tauri listener、Blob URL、第三方查看器、Timer 与 AbortController 必须在卸载时释放。
- 不把 Runtime 的瞬时状态当成历史来源；刷新后应从 SQLite 快照恢复。
- 对大文档和重型查看器使用动态导入，不进入首屏依赖。

### 组件与样式

- 基础控件优先使用 `components/ui/` 中的 shadcn/Radix 实现。
- 图标优先使用项目现有 Remix Icon 或 Lucide 依赖，不手写重复 SVG。
- 新颜色先落到 CSS 变量或已有语义 Token，避免页面散落硬编码颜色。
- 正文默认 14px，小型代码、注释和辅助信息使用 12px；遵循现有页面基线。
- 交互控件需要 hover、focus、disabled、loading、error 状态，并保持键盘可达。
- 卡片 hover 不使用粉红色临时样式；采用已定义的中性或淡蓝语义状态。

## Rust 与 Tauri

### 模块职责

- `commands/`：输入校验、命令编排与稳定错误响应。
- `database/`：Migration、Record 和 Repository。
- `runtime_host/`：Sidecar 生命周期、JSONL 协议、事件与审批。
- `tool_host.rs` / `tool_guard.rs`：本机工具执行与路径/权限控制。
- `yuxi/`：知识库服务和远程 Runtime 适配。
- `maintenance.rs`：备份、恢复、诊断与缓存维护。
- `skills.rs` / `mcp.rs`：扩展加载与进程协议。

### API 约束

- 对前端暴露的结构使用 `#[serde(rename_all = "camelCase")]`。
- Command 返回统一 `ApiResponse<T>`，业务错误使用稳定错误码和可读信息。
- 输入先 trim、枚举校验、范围校验和路径规范化，再写数据库或发起网络请求。
- 锁的持有时间保持短小，不在持有同步锁时等待网络或长耗时子进程。
- 网络请求必须设置连接与总体超时。
- Windows 子进程默认隐藏窗口；Runtime 和 MCP 都已采用此约束。

### 数据库

- Migration 只追加并在事务内运行。
- Repository 负责状态不变量，不能只靠前端禁用按钮。
- 写入多表状态时使用事务，确保 Run、Message、Event、Tool Call 一致。
- 查询大历史使用分页和索引；不要启动时扫描全部历史事件。
- 新增文件路径记录时考虑备份恢复后的路径重定位。

### 安全

- 模型和知识库远程地址必须使用 HTTPS；HTTP 仅允许本机或局域网。
- URL 禁止内嵌用户名、密码、查询凭证和片段。
- 模型 API Key、知识库 Token、MCP 环境变量使用 Windows Credential Manager。
- 文件工具必须经过项目授权目录、规范化路径和审批策略。
- MCP 工具调用需要用户审批；MCP 输出按不可信数据处理。

## Node/Bun Runtime

- 使用 ESM `.mjs`，Runtime stdout 只输出单行 JSONL 协议消息。
- 调试信息写 stderr，且不得包含密钥或完整敏感内容。
- `runtime-contract.mjs` 是工具目录与能力清单的 JS 事实源；Rust 端必须镜像并验证。
- 工具注册顺序必须与 `RUNTIME_TOOL_CATALOG` 一致。
- 运行会话必须可取消、可恢复，并将标准事件交给 Host 持久化。
- Sidecar 构建先写临时 EXE，成功后原子替换正式产物；不要退化为直接覆盖。

## 命名与错误

- TypeScript：组件和类型使用 PascalCase，函数和变量使用 camelCase。
- Rust：类型使用 PascalCase，函数、字段与模块使用 snake_case。
- Runtime 事件使用稳定的点号名称，如 `message.delta`、`run.completed`。
- Tauri 事件使用 `fox://` 前缀。
- 错误信息说明行动建议，但不泄露请求头、Token、项目内容或用户对话。

## 文档规范

- 除 `README.md` 外，常青文档使用中文文件名。
- 每篇包含状态、维护范围、更新时间和适用版本。
- 命令必须可从文档声明的工作目录执行。
- 设计目标与当前已实现能力分开写；未实现内容明确标注。
- 删除旧文档前，先确认其有效内容和历史决策已迁移。

## 验证方式

```powershell
pnpm.cmd --dir apps/desktop build
cargo fmt --manifest-path apps/desktop/src-tauri/Cargo.toml -- --check
cargo clippy --manifest-path apps/desktop/src-tauri/Cargo.toml --all-targets -- -D warnings
pnpm.cmd runtime:test
git diff --check
```

说明：当前 Rust 源码可能仍存在既有 dead-code 警告；若 `clippy -D warnings` 失败，应区分本次新增警告与已登记的历史问题，并在提交说明中记录，不应静默忽略。
