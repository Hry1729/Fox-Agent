Security
安全:四档审批
模型不能直接访问操作系统,只能提结构化工具请求
1
只读read / grep / find / ls
2
询问高风险需人工批准
3
自动前缀规则放行 + 审计
4
完全访问二次确认 + 全审计

不用沙箱

命令以用户本人身份执行,Host 只管超时/取消/清理进程树。

block 规则全档生效

删除盘符根、家目录、项目根等,任何档位都拒绝。

路径防逃逸

规范路径 + 项目根校验,阻止绝对路径、..、符号链接。

证据化完成

模型说"完成"不算,必须有有效 Evidence + Reviewer 复核。
