Security
安全:四档审批
模型不能直接访问操作系统,只能提结构化工具请求
1
只读read / grep / find / ls
2
询问高风险需人工批准
3

4
完全访问二次确认 + 全审计

不用沙箱

命令以用户本人身份执行,Host 只管超时/取消/清理进程树。

block 规则全档生效

删除盘符根、家目录、项目根等,任何档位都拒绝。

路径防逃逸

规范路径 + 项目根校验,阻止绝对路径、..、符号链接。

证据化完成

模型说"完成"不算,必须有有效 Evidence + Reviewer 复核。

Limitations
已知边界
明确的能力边界,诚实告知
  • 团队首版为串行 Supervisor,暂不提供 mailbox、成员并行领取任务或自动共享写 worktree。
  • Child Run 限制深度、并发与每父 Run 总数;远程知识库 Agent 尚不参与本地 Memory 与 Child Run 池。
  • MCP/OpenAPI 暂不支持完整 OAuth、证书固定、外部 $ref 与操作级限流。
  • 命令不在沙箱内执行(已接受的取舍,靠四档审批 + block 规则 + 审计追溯)。
