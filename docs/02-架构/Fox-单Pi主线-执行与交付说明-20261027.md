## 六 Pi 会话与 Fox 数据的映射（阶段二契约，尚未实现）

契约已冻结在 `docs/02-架构/Fox-单Pi主线与SDK原型-接入契约-20261027.md` 第三节，这里是摘要：

- 状态归属：模型消息、工具上下文、压缩记录、活动分支归 Pi `SessionManager`；专家身份、绑定、聊天展示、引用、工具准入归 Fox。
- 需要关联的字段：conversation id、专家绑定版本、runtime session id、Pi session id、受控会话文件路径、存储格式版本、上下文代次。缺的字段用增量迁移补，只有 C 改 schema version。
- 成功顺序：先落会话文件、再提交数据库映射；反向顺序会产生"数据库说可恢复、文件不存在"的记录。
- 失败分类要可区分：文件缺失、内容损坏、会话 ID 不符、聊天绑定不符、目录不可写。**新建空会话是明确的新上下文操作，不是恢复失败的兜底**。
- 旧 Fox JSON 只做一次性导入，保存原文件并记录转换版本；不执行旧工具调用；缺失的工具结果标为未知/中断。
- 同一聊天只允许一个有效写入者，复用 Host 现有准入与锁。

**以上全部未实现，因此未验证。** 本轮没有任何代码声称满足这些条目。
