实现说明

本页是 Grok 引擎（状态机 / 弹簧物理 / 25 套眼形 morph / 14 种 overlay 特效 / 特技全家桶）在狐狸头像上的全量移植，身形切换除外。情绪/生命周期等状态沿用 overlay 特效（如思考=小狐狸+两颗跳动点）；产品动作组（生成/哼歌/加载/语音/ 书写/发送/接收/上传/警报/拖拽/弹跳/关机）为"怼脸特写"模式：镜头推近到脸部， 只留眼睛和鼻子，白色绒毛铺满画面，蓝圈渐隐。特技（转一圈/弹跳转/眩晕转/狂野转） 一律旋转整个头像，眼睛只在脸上随头倾斜。容器动画（呼吸/浮动/摇摆/挤压）可用上方开关单独关闭。 眼位来自对 Fox头像.png 的像素测量。「眼位对位」可叠加原版核对。
