实现说明

本页是 Grok 引擎（状态机 / 弹簧物理 / 25 套眼形 morph / 14 种 overlay 特效 / 特技全家桶）在狐狸头像上的全量移植，身形切换除外。 情绪/生命周期等状态沿用 overlay 特效（如思考=小狐狸+两颗跳动点）；产品动作组（生成/哼歌/加载/语音/ 书写/发送/接收/上传/警报/拖拽/弹跳/关机）为"怼脸特写"模式：镜头推近到脸部， 只留眼睛和鼻子，白色绒毛铺满画面，蓝圈渐隐。特技（转一圈/弹跳转/眩晕转/狂野转） 一律旋转整个头像，眼睛只在脸上随头倾斜。容器动画（呼吸/浮动/摇摆/挤压）可用上方开关单独关闭。 眼位来自对 Fox头像.png 的像素测量。「眼位对位」可叠加原版核对。

两处 overlay 的本地改动（相对 Grok 源实现）：① 语音（dictating） 脸心左右各两颗小圆随声波胀缩时，圆心钉住不动、只长半径。源版此处另有一项竖直抬升 （dn = 6·clamp(En,0,1)·an）：半径涨 9 的同时圆心还要上移 6，于是下边缘几乎不动、 上边缘抬 18 —— 读起来是"从底边长上来"的一根柱子，而不是一颗在原地胀大的圆，实测圆心 y 会 来回摆动约 8px（占屏）。去掉这一项后圆心逐帧恒等于 R0，上下伸展严格对称。 ② 发送（sending）出射方向每轮（1500ms）随机重掷，取值域与 接收共用同一段弧（DIR_ARC，扫过左侧/上方/右侧、避开正下方 —— 朝下的点会 贴着下巴飞出去、在小尺寸缩点里读不出来）。源版把方向写死成 (0.74,−0.62)（≈ −40°）， 每 1.5s 都往同一处飞、读起来像机械臂；现在收发对称：接收的来向随机，发送的去向也随机。 方向只在换轮时重掷（sendTick/recvTick，一轮之内恒定）—— 每帧重掷会抖成噪点。

情绪反应组（14 态）另有专属"眼部语言"，几个正交维度自由组合 —— 视线行为（扫视 / 斜睨 / 上翻 / 躲闪 / 垂视 / 仰视 / 慢漂 / 斗鸡眼 / 抖视 / 绕圈）、 眼内装饰（四角闪 / 五角星 / 泪滴 / 螺旋晕圈）、 眼形本体接管（笑眼弧线 arc 在用；爱心形变 shape:"heart" 保留备用）、 高光点改写（hlHeart 白点变白心、orbit 白点绕圈）、 眼部放大增益 boost、左右同形等大 sym。 兴奋=星星眼+高频抖视、惊讶=双眼整体等比睁大瞪视（无装饰、左右等大）、狐疑=半闭+斜睨、 生气=锁定凝视、犯困=眼睛在"睁（苏醒 0 号眼形）"与"闭（睡着 13 号眼形）"之间来回点头 （慢慢沉下去 → 闭住 → 迅速弹开，像打瞌睡）、开心=上弯笑眼弧线（进这个状态时眼睛 先被压扁成一条线、再往上弯成 ^^，不是"眼睛直接消失"）、好奇=左右扫视、 困惑=双眼放大 + 高光白点在眼里转圈+斗鸡眼、无聊=眯缝眼+翻白眼、骄傲=仰视、 害羞=正常大小的大眼，高光白点换成白色爱心+躲闪、难过=泪滴垂视、 贪玩=五角星眼+绕圈看、庆祝=闪光眼+仰视。 眼内高光白点默认保留；只有带装饰/弧线/爱心眼形的情绪会把它淡出（装饰自己就是眼睛的内容）。 眼形素材的"大小眼"陷阱：3 / 5 / 9 / 12 / 14 / 18 / 21 / 23 这 8 个索引左右两眼 天生不一样大（18 号左 111×98、右 62×57；5 / 14 / 23 更极端 —— 一只大竖椭圆配一条横眯缝线）， 选中它们就会出现"一大一小"。惊讶 / 困惑必须用标准竖椭圆（归一化后 87×111）： 18 / 9 / 12 归一化后是横的（111×98 / 111×87），一放大就变成"眼睛变宽"； 庆祝原来是 18 + 9，正好是全表最不对称的两个。 此外 14 条眼形播放列表已重排 —— 原先多数情绪共用同一组合（这正是"看起来重复"的根源）， 现在两两之间最多只共用一个眼形索引。生命周期 / Agent 形态 / 产品动作组不受影响。
