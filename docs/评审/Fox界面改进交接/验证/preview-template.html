真实 · 可逐项核对
  • 组件 DOM：时间线、工具卡、输入框、审批卡、模型服务表单、侧栏、标题栏，均由产品 TSX 直接渲染

提案 · 尚未落地
  • 标注 data-patch="on" 的增量 CSS，只作用于本轮组件
  • 少量新增 DOM：恢复提示、输出空态、常驻凭据说明、取消回合入口
  • 输入框外壳统一：把历史对话切到产品已有的 is-new-conversation 真实类名
  • 不改主题 token、侧栏、吉祥物；不打产品补丁、不提交
演示 · 不证明后端
  • 状态切换只替换已渲染片段，不跑 Runtime、不发消息
  • 连接测试、审批结果、再次发送均为页内反馈
  • 不访问模型、不读写凭据、不执行任何命令
  • 进程清扫、凭据迁移、跨适配器一致性仍需实机证据
先说清楚一条会影响决策的事实：本页渲染的是当前工作区源码，不是 1339 的打包产物。当前源码在收到 run.cancelled 终态时，已经会显示「1 项已取消 · 过程已取消」、工具标题「已取消」，展开后能看到取消前的真实输出与附注。1339 截图里的「正在执行」更可能出在 Pi / Codex / dsh 适配器的事件送达、终态或历史重载链路上 —— 这属于 T01 / T02 要用事件序列证明的部分，静态预览不能替它背书。
