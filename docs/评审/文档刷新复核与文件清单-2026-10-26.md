## 重现统计

在 Fox Git 仓库根目录执行：

```powershell
git rev-list --count c8a42a9..3bb1880
git diff --shortstat c8a42a9 3bb1880
git -c core.quotePath=false diff --numstat c8a42a9 3bb1880
git -c core.quotePath=false log --reverse --format='%h %s' --name-only c8a42a9..3bb1880
```

历史文件核验使用 Git blob，避免工作区换行符转换影响结果。文档更正后的功能测试、真实桌面、模型和安装包验收仍按[测试指南](../05-开发指南/测试指南.md)分别记录。
