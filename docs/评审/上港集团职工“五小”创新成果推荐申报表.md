# **上港集团职工“五小”创新成果推荐申报表**

## Fox Agent-面向集团内部的个人智能体平台

### 一、成果简介

随着集团数字化转型深入，职工在制度查询、材料撰写和数据整理等日常工作中，对AI的需求正从基础的“问答型助手”升级为“深度结合业务、具备任务闭环能力”的智能体。同时，面对企业核心数据资产与内网安全合规的严格要求，打造基于内网受控环境的集团专属个人智能体平台已势在必行。
Fox Agent是职工自主研发、可运行与集团内网的个人智能体（Agent）工作台。平台基于Pi Agent Runtime构建运行核心，通过独立运行进程、统一工具协议和流式事件机制，在受控范围内连接大模型、内部知识、个人文件及岗位工具。平台兼容多种大模型服务，支持Skills、MCP协议和专家模板等扩展方式；并结合文档智能解析与精准溯源技术，实现从任务理解、工具协同到成果输出的全流程闭环。平台将文件、命令及插件均纳入统一权限校验和审批环节，配合严格的内外网数据隔离机制，确保运行过程安全可控。
平台形成四项核心能力：一是Agent闭环办事能力，支持复杂文件检索、内容整理、文稿生成、数据处理和受控工具调用；二是统一插件生态能力，将Skills、MCP服务和内建工具纳入统一管控入口，按需组合和启用；三是岗位专家配置能力，把业务角色、专业方法、知识库和工具配置为标准的“专家能力包”；四是双层知识管理能力，既可连接集团内部知识库，又可建立个人本地知识库，支持多格式文档的深度解析、分块检索与原文定位。
项目成功把“通用大模型能力”转化为“职工可掌控的个人智能体”，实现从简单问答到任务执行；从通用助手到岗位专家；从分散文件到知识库的三重转变。为集团内网规模化智能体应用提供可控、可追溯、可复制的技术底座。

### 二、实施应用情况

  目前，Fox Agent已完成桌面工作台、智能体运行、插件中心、专家中心、远程知识库接入和本地知识管理等核心模块建设，主要实现以下三大核心功能的稳定应用：  **一是实现Agent任务闭环自动化处理功能：打通端到端流程，提升日常办公质效。**职工可围绕制度查找、材料起草、会议纪要整理、方案比对、文件检索和项目资料处理等任务提出目标。智能体在权限范围内读取项目与附件、检索知识、调用工具并生成结果；同时，系统对会话、附件、引用来源、工具状态和审批记录持久化留存，应用重启后仍可恢复，终结了职工在海量文件夹、业务系统与聊天窗口间反复切换的割裂模式，大幅提升员工办公效率。  **二是实现插件与岗位专家标准化复用功能：沉淀业务经验，降低能力扩展门槛。**一方面，平台通过插件中心可视化管理Skill、MCP服务与内建工具，可轻松新增业务能力；另一方面，平台通过专家中心创建面向具体岗位的专家，将特定岗位的作业规范、工作方法、资料库和受控工具固化为可复用的“能力配置包”。员工在对话中可一键绑定相应专家，获得稳定的专业口径。  **三是打通组织与个人资料双层知识管理：融通组织与个人资产，保障知识安全可信。**平台搭建“公司统一知识底座+个人端侧知识空间”的双层知识体系。一方面，职工可直连公司统一知识库，获得带来源标引的权威制度检索与在线资料阅读；另一方面，职工可在本地自主创建个人离线知识库，一键导入PDF、Word、PPT、Excel、Markdown等多种格式的常用制度、业务手册与项目资料。文件导入采用受管存储、完整性校验和任务状态恢复机制，原文件与知识库副本互不覆盖。通过“公司知识统一供给、个人知识自主沉淀、智能体按需受控调用”的机制，切实保障核心数据不离内网，实现知识资产的可持续积累与安全应用。  

### 三、经济效益和社会效益

  **一是降本提效“双重突破”：重复工时大幅锐减，资料检索效率提升75%以上。**Fox Agent改变了传统员工在多系统、海量文件夹与网页间翻找资料的传统模式，将制度检索、跨文档核对及初稿整理等任务由单次30-45分钟缩短至2-5分钟，显著提升文档起草、数据整理、资料查找与归纳效率，减轻一线职工的日常事务负担。同时，智能体基于知识库实现100%带标引、可溯源输出，有效降低人工核对差错率，确保业务口径统一。  **二是自主开发“零采购成本”：规避高额外部采购，实现低成本高产出。**经公开同类项目调研测算，若委托第三方从零建设与Fox Agent功能相当的企业内网个人智能体平台，预计市场开发费用约为50万至150万元，合理建设周期约为6个月。本项目由职工依托现有软硬件条件自主研发，实现“零外部采购成本”开发落地，更实现了核心技术代码与内网业务知识的自主可控，从源头上保障了企业核心数字资产的绝对安全。  **三是是运营安全与管理升级：内网受控与审计溯源，筑牢合规运营底座。**公司内部资料仅在内网环境受控使用，外网模式无法访问，确保内外网信息边界清晰；智能体基于已授权的内部知识工作，并对知识引用来源、工具调用和审批过程全程留痕，实现结果可查，过程可追，有助于减少口径不一致、资料遗漏和重复核对；对于代码执行、文件删除等高风险操作，平台通过权限校验、风险提示和人工确认统一管控，有效降低敏感信息外泄、越权访问和误操作风险，进一步提升应用安全、规范和可管理性。  **四是模式创新全港可推广：沉淀组织隐性经验，激发全员微创新活力。**员工可把个人经验、常用资料和成熟工作方法沉淀为知识库、Skill或岗位专家，使隐性经验转化为可检索、可复用的组织能力，帮助新员工快速熟悉制度和岗位流程。平台通用能力与具体业务场景相对解耦，可在码头生产、设备管理、安全监督和综合职能等场景中按需扩展，逐步形成“个人拥有专属智能体、岗位沉淀专业专家、集团共享可信知识”的应用生态，可激发职工立足岗位开展技术总结和知识沉淀，助力集团智慧港口建设与数字化转型。
