## 4. 验收边界说明

- `t2_kernel_recovery_after_reopen_settles_once` 是**进程内故障注入恢复测试**：故障用 `catch_unwind`
  在进程内抛出以停在「文件提交已持久、派发结果未结算」的边界；**数据库关库重开是真实的**，
  但**不等价于真实进程死亡（SIGKILL/断电）验收**，后者**未验收**。
- 前端 DOM 用例为**组件级真实 DOM 证据**（挂载真实组件并派发真实 click，仅 mock Tauri IPC 边界），
  与打包后桌面应用的真人点击走查证据等级不同，不可互相替代。
