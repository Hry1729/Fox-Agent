# Kernel 剩余改造实施记录

## 授权与运行边界

本轮接续总方案剩余工程实现。保留现有 main 工作区改动，不清理或替换运行中的桌面程序。用户于本轮追加授权要求及时提交和推送，后续按已验证里程碑提交；独立 Kernel/协议库已以 `6b4f969` 推送。生产放量与工程实现分开；默认仍为 Legacy，任何既有 Run 不原地换权威。真实业务和审批 UI 证据未完成前，不自动批准生产切权。

## 已完成的基础拆分

- 建立 Cargo workspace；纯决策核位于 `crates/fox-agent-kernel`，桌面 `src/kernel/mod.rs` 仅保留兼容重导出。
- 原有核心单元测试和决策语料随实现迁移，未删除测试以缩减覆盖。独立 Kernel 45 项通过；桌面 Shadow 专项 61 项通过（部分 Shadow 单元测试现属于独立 crate，不能只用桌面计数比较覆盖）。
- `crates/fox-engine-protocol` 承载原 JSONL DTO、协议常量、能力 DTO 和 canonical 工具目录；实际 Host handler 可用性校验留在桌面适配层。
- Rust DTO 经 schemars 生成 `packages/fox-engine-protocol` 的 JSON Schema、TypeScript 声明与运行时目录；Rust 与 Node 共享同一份 65 项工具目录，顺序和分类保持一致。
- 保留 v1 协议兼容；原有 Node 协议测试与新跨语言 schema/canonical 契约测试合计 8 项通过，Rust 协议 crate 2 项通过，桌面协议适配层 10 项通过。Node 全量当前 223 项通过。
- 生成文件可用 `node scripts/generate-engine-protocol.mjs --check` 检查漂移。独立 Kernel 可用 `cargo test -p fox-agent-kernel` 验证。

### 冻结控制一致性补齐（本轮续作）

- Shadow 新观察上下文从 Run 冻结绑定投影权限，保留旧 JSON grants 二元数组合同；不再读取变更后的实时会话权限。旧版无绑定 Run 保留兼容读取，但校验 Run 所属会话；绑定损坏不得回退。此处共享权限内容来源，不宣称两种协议投影的哈希值相同。
- Shadow 四类预算读取冻结记录；生命周期 Hook、Task Repair 人工升级、MCP、Host 工具和通用能力五个审批入口的实际等待接入同一审批预算。旧 Run 默认五分钟，未知 Run 与损坏绑定拒绝继续；失败仍走已有审批清理和拒绝处理。
- 工具级取消即使先于 Run 注册到达也保留，之后注册不能清除该工具的取消状态，其他工具身份不受影响。
- 新增权限 grant 保留、旧 Run/跨会话拒绝、数据库重开后短审批预算、超时/拒绝/通道中断和损坏绑定不接受已排队批准等回归。独立 Kernel 47 项通过；这不等于持久审批绝对截止时刻、全局执行计时器或生产恢复派发已经完成。
- 续作桌面 Rust 默认特性全量回归：549 项通过、0 失败、3 项原有显式忽略；本批差异检查通过。未重新宣称 UI 或真实账号链路验收。
- Pi 接收端在接受 prompt 及产生模型事件前校验共享 Schema、Run/Conversation/Profile、Legacy/Pi 身份、权限内容哈希和预算合法性；项目上下文必须与冻结权限一致。显式空/损坏绑定拒绝，只有缺省字段按 v1 兼容。不存在或属于另一会话的 session、重复活动 Run 均在应答阶段拒绝。
- Host 启动入口同步拒绝冻结引擎或会话不匹配。Node 全量 228 项、Rust RuntimeHost 专项 140 项通过；独立程序构建和 smoke 通过，smoke 实际验证错误引擎绑定不产生运行事件、正确冻结绑定完成模型回合（faux provider）。不等于已接入 Codex/DeepSeek；二者仍被当前 Pi adapter 明确拒绝。

### 资源读取接线与跨进程验收

- Graph Preview 子节点接入与父 Run 相同的冻结读取路由，不能因为选用 Rust 而缺少执行入口或回退本地。节点调用 ID 由父工具、节点和局部工具 ID 组合哈希生成，避免并行节点的模型工具 ID 碰撞。
- Host 验证嵌套读取属于仍在运行的 Graph Preview 父工具及其声明节点；Rust 侧独立执行较严的图节点上限（24000 UTF-16 单元、50 个匹配、1000 个目录项、1000 单元行预览）。
- 修复 Host `payload.result` 与 Node 读取返回包装不一致；保留不可变原始参数，另行校验预检规范化参数。相对路径转绝对路径不再被当作身份冲突，改变读取目标仍被拒绝。
- 新联测启动真实 Pi 子进程（faux provider），通过 JSONL 调用正式 Host 共用 Rust 执行入口，验证文件内容返回模型且 SQLite 留存一致；同时验证重复调用读取旧结果、不重新打开变化后的文件。该测试不包含 Tauri UI，不视为全部桌面验收。
- Node 全量 229 项通过；桌面默认特性全量 554 项通过、0 失败、3 项原有显式忽略。未放宽安全或性能门槛。

### 审批持久截止时间

- 五类 Host 审批等待按已落库 `requested_at` 加冻结审批预算计算剩余时间；重进等待和数据库重开不重新获得完整时限。未知/跨 Run 审批、损坏绑定、非法时间和时钟回拨拒绝继续。
- 人工批准在写事务取得后重新比较绝对截止时间；过期记录为 `expired`，不授予会话权限、不允许领取执行。Host 发送落库结果而非用户原始选择。绑定损坏仍允许拒绝清理。
- 审批专项 26 项通过，含重开后剩余时限、迟到会话授权拒绝、回拨和损坏绑定清理；桌面默认特性全量 556 项通过、0 失败、3 项原有显式忽略。该修复不等于恢复后的实际派发已实现。

### 受控协调入口与恢复派发

- 增加 `KernelCoordinator` 适配入口：重建 Kernel 控制器并核对同一 Run 的权威身份、引擎、权限、Profile 和全部冻结预算；事务失败不把推测状态留在内存。
- Outbox 只允许 Authoritative 领取；支持按单个待办领取，未执行的兄弟工具不提前进入不确定状态。结果提交在同一事务核对租约持有者并完成工具、批次屏障与派发记录；恢复标记也需匹配原租约持有者。
- 工具执行不持有控制器锁，传递稳定幂等键与作用于该工具的取消令牌；取消先落库再通知执行器。执行失联或结果落库失败保持 leased，不自动重跑。
- 协调入口专项 7 项通过：数据库重开后的审批、真实 Rust 文件读取、逆序完成的有序结果、重复调用不重读、失联/事务失败、伪造租约、取消迟到结果及双工具并发进入。独立 Kernel 47 项通过；桌面默认特性全量 564 项通过、0 失败、3 项原有显式忽略。
- 此入口尚未挂接默认 RuntimeHost 启动、Pi 权威模式协议与 UI。真实文件测试覆盖受控协调器，不等于真实 Tauri 会话的重启恢复或生产切权验收。
