- 建立 Cargo workspace；纯决策核位于 `crates/fox-agent-kernel`，桌面 `src/kernel/mod.rs` 仅保留兼容重导出。
- 原有核心单元测试和决策语料随实现迁移，未删除测试以缩减覆盖。独立 Kernel 45 项通过；桌面 Shadow 专项 61 项通过（部分 Shadow 单元测试现属于独立 crate，不能只用桌面计数比较覆盖）。
- `crates/fox-engine-protocol` 承载原 JSONL DTO、协议常量、能力 DTO 和 canonical 工具目录；实际 Host handler 可用性校验留在桌面适配层。
- Rust DTO 经 schemars 生成 `packages/fox-engine-protocol` 的 JSON Schema、TypeScript 声明与运行时目录；Rust 与 Node 共享同一份 65 项工具目录，顺序和分类保持一致。
- 保留 v1 协议兼容；原有 Node 协议测试与新跨语言 schema/canonical 契约测试合计 8 项通过，Rust 协议 crate 2 项通过，桌面协议适配层 10 项通过。Node 全量当前 223 项通过。
- 生成文件可用 `node scripts/generate-engine-protocol.mjs --check` 检查漂移。独立 Kernel 可用 `cargo test -p fox-agent-kernel` 验证。

## 尚在实施 / 尚需验证

### 已接入、仍需扩展覆盖的控制边界

- v54 新增 `run_control_bindings`，冻结 Run/Conversation、Legacy 权威、Pi 引擎、执行 Profile、权限内容及哈希、读执行位置和四类时间预算。权限输入在同一数据库读事务捕获；重启复用已保存记录，内容/列/哈希冲突拒绝继续。启动请求和读预检读取该绑定；这不等于所有 Legacy 写工具和外部能力已统一权限决策。
- 新增纯 Rust 分 Run/Tool 取消注册表；实际 Host 写文件/编辑/命令执行入口获取令牌，取消在写入前和命令轮询中检查。专项测试证明取消不创建目标父目录、已启动的测试命令能被停止。外部网络、Office/MCP 等能力尚未全部接入，不宣称所有副作用都可撤回。
- `FOX_RESOURCE_GATEWAY_READS=rust` 仅为新 Run 显式选择 Rust 的 read/ls/find/grep；默认 runtime，未知配置拒绝。既有 Run 不随环境变量变化而更换执行位置。Node 接收冻结路由并将请求交 Host，拒绝/失败不回退 Node；Host 重新核验绑定、权限哈希和工具类别。
- Rust 读取逐个校验嵌套路径；Windows 校验打开句柄最终路径，并在读取期间限制改名/替换共享。单文件 8 MiB、整次文本扫描 64 MiB、遍历 4000 项、结果 200 项、输出 120000 UTF-16 单元；超界明确失败/标记截断。与旧执行器差异包括：越界链接和超大文件拒绝、扫描信息更明确。尚无真实 Tauri 会话下的 Rust reader 全链路验收，不据此开启默认迁移。
- 已通过：Kernel 47、协议 Rust 3、绑定数据库 3、ToolHost 5（含实际命令取消）、Rust reader 3（含真实 Windows junction 越界）、Node reader 3；Node 全量 224、前端 181、TypeScript、Vite release、bundle budget、release isolation。Rust 默认特性全量 546 通过、0 失败、3 显式忽略；新增 v54 后修正了 v53 升级夹具的旧版本模拟，未放宽迁移验证。

### 冻结控制一致性补齐（本轮续作）

- Shadow 新观察上下文从 Run 冻结绑定投影权限，保留旧 JSON grants 二元数组合同；不再读取变更后的实时会话权限。旧版无绑定 Run 保留兼容读取，但校验 Run 所属会话；绑定损坏不得回退。此处共享权限内容来源，不宣称两种协议投影的哈希值相同。
- Shadow 四类预算读取冻结记录；生命周期 Hook、Task Repair 人工升级、MCP、Host 工具和通用能力五个审批入口的实际等待接入同一审批预算。旧 Run 默认五分钟，未知 Run 与损坏绑定拒绝继续；失败仍走已有审批清理和拒绝处理。
- 工具级取消即使先于 Run 注册到达也保留，之后注册不能清除该工具的取消状态，其他工具身份不受影响。
- 新增权限 grant 保留、旧 Run/跨会话拒绝、数据库重开后短审批预算、超时/拒绝/通道中断和损坏绑定不接受已排队批准等回归。独立 Kernel 47 项通过；这不等于持久审批绝对截止时刻、全局执行计时器或生产恢复派发已经完成。
- 续作桌面 Rust 默认特性全量回归：549 项通过、0 失败、3 项原有显式忽略；本批差异检查通过。未重新宣称 UI 或真实账号链路验收。
