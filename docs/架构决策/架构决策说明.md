# 架构决策说明

> 状态：生效<br>
> 适用范围：Fox 架构决策记录<br>
> 最后更新：2026-07-29

架构决策记录用于保存影响多个模块、迁移成本较高或容易被后续开发误解的技术决定。它记录当时的上下文、选择和后果，不替代详细架构文档。

## 状态

- **建议中**：仍在讨论，不能作为强制实现依据。
- **已接受**：当前实现应遵循该决策。
- **已替代**：被另一项架构决策替代，但保留用于追溯。
- **已撤销**：确认不再适用且没有直接替代方案。

## 编号规则

文件以四位编号开头并使用中文主题，例如：

```text
0001-SQLite作为产品事实源.md
0002-Host收口系统权限.md
```

编号创建后不复用。替代旧决策时创建新编号，并在新旧文档中互相链接。

## 内容要求

每项决策至少包含：

1. 状态和日期。
2. 决策背景与约束。
3. 最终决定。
4. 正面与负面后果。
5. 被拒绝的主要替代方案。
6. 相关代码、测试和后续工作。
