# 产品概览

> 状态：生效<br>
> 适用版本：Fox `0.1.x`<br>
> 维护范围：产品定位与能力边界<br>
> 最后更新：2026-08-27

## 产品定位

Fox 是面向个人和小型技术团队的桌面智能体工作台。它把本地项目、模型服务、工具执行、知识库、Skills 和 MCP 连接放在同一个桌面应用中，并通过可恢复的会话记录保留用户消息、模型回复、工作过程、工具调用、附件和引用来源。

Fox 不是单纯的聊天壳。它把对话、工具执行、任务状态、证据、审查、验收和恢复组织成一条可执行、可审计、可恢复的桌面 Agent 链路。用户能够理解智能体做了什么、授权了什么、产生了什么结果，并在应用重启后继续查看这些事实。

## 目标用户

- 需要在本地项目中阅读、修改和验证文件的开发者。
- 需要结合组织知识库完成问答、检索和资料阅读的知识工作者。
- 希望统一管理不同模型供应商、智能体、Skills 和 MCP 工具的高级用户。
- 需要追踪任务过程、证据和产物的小型协作团队。

## 核心场景

### 本地项目协作

用户选择一个本地目录作为项目，将会话绑定到该项目后，Fox 可以在授权范围内读取文件、搜索内容、修改文件和运行命令。高风险能力由 Tauri Host 统一执行和审批，Runtime 不直接拥有系统权限。

### 通用智能对话

用户可以选择本地 Fox 通用助手和已配置模型进行普通问答。消息、推理过程、工具状态与最终回复通过统一事件模型进入前端，并持久化到 SQLite。

### 知识库问答与资料阅读

Fox 可以连接外部知识库服务，同步智能体和知识库，查询知识内容与知识图谱，预览或下载远程文档，并从对话引用跳转到对应资料。独立的本地知识工作区支持导入、解析、分块、检索和引用本机资料，不与远程知识库混用事实源。

### 能力扩展

Fox 支持模型供应商、Skills、MCP、OpenAPI 服务和受控工具。插件中心负责统一发现与配置，扩展能力通过能力清单、配置和权限策略进入 Runtime，而不是直接把任意脚本暴露给模型。

## 产品原则

### 本地事实由 Fox 掌握

会话、项目、运行状态、权限和用户配置以 Fox SQLite 为产品事实源。Runtime Session 和远程服务状态用于执行与恢复，但不能悄悄替代本地事实。

### 权限在 Host 收口

写文件、运行命令、调用 MCP 等操作必须经过 Host 工具和审批策略。模型输出、知识库内容和外部工具返回都视为不可信输入。

### 过程可见但不伪装成隐藏思维

界面展示可审计的工作步骤、工具调用、状态和来源，而不是声称暴露模型不可验证的内部思维。完成后工作过程仍应保留。

### 简单任务保持简单

普通问答不应被强制包装为复杂任务。Goal、Task、Evidence 等工作闭环能力只在确有执行和追踪价值时启用。

### 外部服务可降级

知识库服务不可用时，本地 Fox 智能体、项目和历史会话仍应可用；远程能力需要清楚显示连接状态和恢复方式。

## 当前非目标

- Fox 当前不是多人实时协同平台。
- 文档能力以安全预览和下载为主，不提供完整 Office 在线编辑。
- 费用统计不是当前产品目标。
- 有界只读 Graph Lead、受治理长期记忆、有限并发 Child Run、串行 Supervisor Team 和持久数字同事可以支持受控工作；无界多 Agent、并行 Team mailbox、自动共享写 worktree 和专用 IM Adapter 不在当前范围内。
- 不允许模型无审批执行任意本地脚本或访问项目授权范围之外的文件。

## 成功标准

- 用户发送消息后能够稳定看到实时过程和最终回复，无需刷新恢复。
- 应用重启后，会话、运行状态、附件、引用和用户配置保持一致。
- 工具操作具有清晰的权限边界、审批记录和错误反馈。
- 知识库服务异常不会拖垮本地会话链路。
- 新工程师能够根据文档完成环境搭建、定位模块、运行测试并提交变更。
