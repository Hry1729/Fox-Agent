# 产品概览

> 状态：生效<br>
> 适用版本：Fox `0.1.x`<br>
> 维护范围：产品定位、用户、核心场景与能力边界<br>
> 最后更新：2026-10-28（单 Pi 分支同步；本轮未复跑产品测试）

## 结论

Fox 是 Windows 优先的桌面智能体工作台。本分支只有一个受支持的本地驱动：Pi。新会话绑定 `agent_backend=fox`，本地 Kernel 使用 `engine_id=pi`；默认执行权仍是 Authoritative。旧外部 Pi ACP、Codex、DeepSeek 会话保留原绑定与历史，只读且不能继续执行。

Fox Host 与 SQLite（Schema v98）保存会话、消息、运行、审批、权限和用户配置。Yuxi 远程知识库与远程专家保留；单 Pi 收敛不取消远程资料能力。阶段二原生会话与 C gap **未完成**，不能把历史回灌续聊等同于原生会话恢复验收。

当前状态与证据边界见[单 Pi 主线状态](单Pi主线状态.md)和[当前状态与核验基线](当前状态与核验基线.md)。

## 目标用户

- 需要在本地项目中阅读、修改和验证文件的开发者。
- 需要结合本机资料库或组织知识库完成问答、检索和资料阅读的知识工作者。
- 希望统一管理模型供应商、Agent、Skills、MCP 和专家的高级用户。
- 需要追踪任务过程、证据和产物的小型团队。

## 核心场景

### 本地项目协作

用户把一个本地目录添加为项目，会话绑定项目后：

- **Fox 会话**：在项目权限（只读 / 询问 / 允许）范围内读文件、搜索、写文件和运行受控工具。所有系统操作由 Tauri Host 执行和审批，Runtime 不直接拥有系统权限。Fox Agent 的任意 Shell 由真实 SRT 限制；`git_read`、`test_run`、`code_check`、`format_code` 这类固定能力工具由 Host 生成固定的程序和参数来运行。
- **旧外部会话**：只读历史，不执行项目工具或权限切换。需要继续工作时由用户新建受支持的会话，系统不自动改写旧绑定。

### 通用对话

不绑定项目时，用户可以和 Fox 通用助手进行普通问答。消息、推理过程、工具状态和最终回复通过统一事件进入前端，并写入 SQLite，应用重启后仍可查看。

### 资料与知识库

- **本机资料库**：导入、解析、分块、关键词与向量混合检索（RRF），并在回复中引用。ONNX Runtime 在 CPU 上生成向量，Zvec 负责向量索引。存储位置不可写时进入只读或不可用的降级状态，并在 设置 →「资料库」中提示。
- **知识库服务（远程，代码名 `yuxi`）**：同步远程 Agent 和知识库，查询内容和知识图谱，预览或下载原文件，并从引用跳转到资料。服务不可用时本地功能照常可用。

### 能力扩展

插件中心和 设置 →「插件」统一管理 Skills、MCP / OpenAPI 连接器和声明式生命周期 Hook（「策略」）。扩展经过能力清单、凭据隔离和审批策略进入运行，不能直接把任意脚本暴露给模型。

### 专家与自动化

专家能力包（`.foxexpert`）有版本、Hash、升级和回滚；在此之上有持久工作流、串行 Supervisor 团队和数字同事（按计划或签名 Channel 触发）。这些能力只用于 Fox 会话。

## 产品原则

### 本地事实由 Fox 掌握

会话、项目、运行状态、权限和用户配置以 `fox.db` 为事实源；阶段二 Pi JSONL 是模型上下文载体，不能用 SQLite 展示副本随意覆盖。远程服务状态与本地产品状态分别维护。

### 权限在 Host 收口

本地执行的写文件、命令、MCP 等操作必须经过 Host 工具和审批。退休外部会话不执行工具。模型输出、资料内容和外部工具返回均为不可信输入。

### 过程可见，但不伪装成隐藏思维

界面展示可审计的工作步骤、工具调用、状态和来源，不声称暴露模型的内部思维。

### 简单任务保持简单

普通问答不强制进入 Goal / Task 工作模式，只有确有执行和追踪价值时才启用。

### 外部服务可降级

知识库服务离线、资料库存储位置不可写、预览缓存目录异常时，本地会话和历史记录仍然可用，并在界面上说明状态。

## 当前非目标

- 多人实时协同。
- 完整的 Office 在线编辑（只提供安全预览和下载）。
- 费用统计。
- 无界多 Agent、并行 Team mailbox、自动共享写 worktree、专用 IM Adapter。
- 让模型在没有验证过的隔离后端时执行任意 Shell 命令，或访问授权范围之外的文件。

## 待办（计划，未实现）

- 自定义 ACP Agent 入口未实现；本分支不提供外部驱动恢复或接入开关。
- 历史四 Agent 方案阶段 4：Legacy 路径与 Shadow 观察路径的清理，尚未开始。
- 四 Agent 方案阶段 1 第 2 项：`test_run` 的授权没有绑定工作区修订或脚本内容，未关闭。

## 成功标准

- 发送消息后稳定看到实时过程和最终回复，无需手动刷新。
- 应用重启后，会话、运行状态、附件、引用和用户配置保持一致；启动问题能降级的不阻止启动，不能降级的给出可读原因并保留数据。
- 工具操作有清楚的权限边界、审批记录和错误反馈。
- 外部服务异常不拖垮本地会话链路。
- 新工程师能按文档完成环境搭建、定位模块、运行测试并提交变更。
