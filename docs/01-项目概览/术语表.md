# 术语表

> 状态：生效<br>
> 适用版本：Fox `0.1.x`<br>
> 维护范围：产品、架构和界面统一术语<br>
> 最后更新：2026-07-29

| 术语 | 定义 |
| --- | --- |
| Fox | 本项目的桌面智能体产品。 |
| 工作台 | Fox 主窗口的整体交互容器，代码入口为 `Workbench`。 |
| 项目 | 用户授权给 Fox 的本地目录，以及与该目录关联的会话和权限。 |
| 会话 | 用户与某个智能体持续交互的产品级记录，是消息、运行和附件的容器。 |
| 消息 | 会话中的用户输入、助手回复或结构化内容记录。 |
| Run | 一次用户请求对应的执行实例，具有排队、运行、等待、完成、失败或取消等状态。 |
| 智能体 | 具有名称、模型、提示、能力和运行环境的助手配置。可以来自本机或知识库服务。 |
| Fox 通用助手 | 使用本地 Agent Runtime 执行任务的默认智能体。 |
| 知识助手 | 由知识库服务提供、具备知识检索能力的远程智能体。 |
| 模型供应商 | 提供模型 API 地址、协议、密钥和模型目录的服务配置。 |
| 默认模型 | 未被智能体或会话覆盖时，Fox 发起本地 Run 使用的模型配置。 |
| Agent Runtime | 独立 Node 进程，负责模型循环、上下文和工具请求，不直接拥有 Fox 产品状态。 |
| Runtime Host | Tauri/Rust 中负责启动 Runtime、发送请求、接收事件、执行 Host Tool 和持久化状态的组件。 |
| Sidecar | 随 Fox 安装包分发并由 Tauri 管理的外部 Runtime 可执行进程。 |
| Runtime Session | Runtime 保存的执行上下文，用于恢复模型循环；它不是会话事实源。 |
| JSONL 协议 | Host 与 Runtime 使用的一行一个 JSON 对象的进程通信协议，当前名称为 `fox-runtime-jsonl`。 |
| 能力清单 | Runtime 初始化时声明的协议版本、流式、恢复、审批、多模态和工具能力集合。 |
| 工具 | 智能体可请求的具体操作，例如读取文件、写文件、运行命令或查询知识库。 |
| Host Tool | 必须回到 Tauri Host 执行的工具，用于收口权限、凭据和系统能力。 |
| 审批 | 用户或策略对高风险工具调用作出的允许、拒绝或等待决定。 |
| Skill | 可发现、可启停的能力说明或工作流扩展，由 Fox 管理并提供给 Runtime。 |
| MCP | Model Context Protocol，用于连接外部工具服务；调用仍受 Fox 配置和审批控制。 |
| 知识库服务 | Fox 连接的外部知识与远程智能体服务。当前兼容实现的代码模块名保留为 `yuxi`。 |
| 知识库 | 知识库服务中的资料集合，可以绑定到会话并用于检索。 |
| 知识图谱 | 知识库服务提供的实体、关系、标签和统计数据的图形化视图。 |
| 附件 | 用户随消息上传并由 Fox 管理的文件副本或元数据。 |
| 产物 | 智能体生成或修改的文件、图片、代码差异、测试结果等可交付结果。 |
| 引用 | 助手回复与知识库文档、网页或其他来源之间的可追溯关联。 |
| 预览缓存 | Fox 为远程知识库原文件建立的受控本地缓存，具有容量限制和生命周期管理。 |
| 产品事实源 | 决定用户可见状态的权威数据源。Fox 的本地产品事实源是 SQLite。 |
| Goal | 路线图中的工作目标实体；A0 开始引入，不能与普通会话强绑定。 |
| Task | Goal 下可独立跟踪状态的工作项。 |
| Evidence | 证明 Task 已执行或完成的工具调用、文件差异、测试结果、产物或用户确认。 |
| Trace | 用于关联 Run、事件和工具调用的诊断标识体系。 |
| Artifact | 代码和协议中常用于表示可展示产物的英文名称；中文界面和文档优先称“产物”。 |

## 用词约定

- “本机”描述 Fox 桌面端及本地 Runtime；“知识库”描述外部知识库服务环境。
- “后端”必须进一步说明是 Tauri 后端、Agent Runtime 还是知识库服务。
- “工作过程”指可审计事件与工具步骤，不称为模型的完整内部思维链。
- “恢复”指从 SQLite、Runtime Session 或远程状态重新构造一致状态，不等同于简单刷新页面。
