# 仓库结构

> 状态：生效<br>
> 适用版本：Fox `0.1.x`<br>
> 维护范围：Monorepo 目录和模块职责<br>
> 最后更新：2026-10-25

## 结论

仓库同时是 pnpm 工作区和 Cargo 工作区：

- pnpm（`pnpm-workspace.yaml`）：`apps/*`、`packages/*`、`services/*`。实际成员是 `apps/desktop`、`packages/fox-engine-protocol`、`services/agent-runtime`。
- Cargo（根 `Cargo.toml`）：`apps/desktop/src-tauri`、`crates/fox-agent-backend`、`crates/fox-agent-kernel`、`crates/fox-engine-protocol`；`default-members` 只含三个 crate，不含桌面 Host。`zvec-rust-sys` 通过 `[patch.crates-io]` 指向 `vendor/zvec-rust-sys-0.6.0`。

本页所有路径都从仓库根目录开始，以 `main` 当前代码为准。

## 根目录

```text
Fox-Agent/
├─ apps/desktop/              React 前端 + Tauri/Rust Host
├─ crates/
│  ├─ fox-agent-backend/      外层 Agent 后端：路由、ACP、外部 Agent 启动与沙箱、原生权限、凭据规则
│  ├─ fox-agent-kernel/       Kernel 决策核（Fox 会话的 Authoritative 执行）
│  └─ fox-engine-protocol/    Kernel 与模型引擎之间的协议（Rust）
├─ packages/fox-engine-protocol/  同一协议的 JS 版本与 schema.json
├─ services/agent-runtime/    Node Agent Runtime（Pi）、Kernel worker、Sidecar 构建、离线 Eval
├─ scripts/                   跨模块校验、Rust 测试入口、Windows 运行时准备、Smoke 脚本
├─ vendor/zvec-rust-sys-0.6.0/ Zvec 绑定的本地补丁版本
├─ web/                       锁定版本的外部参考快照，不属于产品工作区
├─ docs/                      项目文档
├─ .github/                   `workflows/windows-ci.yml` 与 `scripts/ci_failure_summary.py`
├─ README.md、CHANGELOG.md、LICENSE
├─ package.json、pnpm-workspace.yaml、pnpm-lock.yaml、bunfig.toml
├─ Cargo.toml、Cargo.lock
└─ 根目录历史文档（UI 改造期间，不再维护）
```

`web/Yuxi-main-feat-chat-ai-elements-b0d86e8-20260812` 是锁定版本的 Yuxi 参考源码，不参与 Fox 构建。根目录的 `ASSISTANT-UI-MIGRATION.md`、`AUI-PENDING.md`、`STEP6-HANDOFF.md`、`UI-CHANGES-*.md`、`UI-PLAN.md`、`PAGE-REDESIGN.md`、`design-qa.md`、`COMPONENT-REUSE.md`、`DESIGN-apple.md` 是历史文档，清单见[架构文档导航 · 根目录历史文档](../02-架构/架构文档导航.md#根目录历史文档)。`apps/desktop` 根下的 `p2e-*.mjs`、`r2-*.mjs`、`r3-*.mjs`、`cdp-drive.mjs` 等是人工验收驱动脚本（说明见 `apps/desktop/ACCEPTANCE-DRIVERS.md`），不是产品代码。

## 桌面前端

```text
apps/desktop/src/
├─ app/App.tsx                应用入口
├─ components/                ui、fox-ui、ai-elements、assistant-ui、animate-ui、effects 等组件
├─ features/
│  ├─ agents/                 Agent 与专家页面
│  ├─ chat/                   Workbench、侧栏（shell/）、输入框（composer/）、时间线、右侧面板
│  ├─ conversations/          会话 API、Hook、事件 Reducer、模型（含 model/agent-backend.ts）
│  ├─ jobs/                   后台任务进度卡片
│  ├─ knowledge/              远程知识库页面、预览器、图谱
│  ├─ local-knowledge/        本机资料库
│  ├─ notifications/          通知
│  ├─ plugins/                插件中心
│  ├─ profile/                用户资料
│  ├─ profiling/              性能剖析 Harness
│  ├─ settings/               设置页（7 个入口）与服务配置 Hook
│  └─ workspace/              通用页面、实体卡片、旧设置路由映射（management-navigation.ts）
├─ generated/、hooks/、lib/、styles/
└─ main.tsx
```

设置页结构：侧栏在 `apps/desktop/src/features/chat/shell/fox-sidebar.tsx`，分三组 7 个入口（通用 / 对话 / 模型 / Agent / 插件 / 资料库 / 数据与关于）；页面在 `apps/desktop/src/features/settings/settings-pages.tsx`、`settings-agent-page.tsx`、`settings-plugins-page.tsx`、`settings-library-page.tsx`、`settings-data-page.tsx`；外部 Agent 设置在 `agent-backend-settings.tsx`。详见 [docs/README · 设置页现状](../README.md#设置页现状)。

## Tauri Host

```text
apps/desktop/src-tauri/src/
├─ lib.rs                      setup（启动 10 步）与 Command 注册
├─ startup_failure.rs          无法降级的启动错误：日志 + Windows「Fox 无法启动」对话框
├─ commands/                   Tauri Commands（含 agent_backend_routing.rs、plugin_center.rs、kernel_*）
├─ database/                   migrations.rs（schema v97）、migration_backup.rs、models、repositories/
├─ runtime_host/               RuntimeHost、Kernel 协调（kernel_coordinator、kernel_authority、kernel_model_worker 等）、
│                              工作工具、固定能力工具（capability_tools.rs）、命令作业、交付检查
├─ kernel/、kernel_*.rs        Kernel 兼容入口、模型配置、对账、压缩、状态发布
├─ external_backend.rs         ExternalBackendHost：外部 Agent 的 Host 胶水
├─ external_model.rs           外部 Agent 使用的模型供应商配置
├─ yuxi/                       知识库服务适配与远程 Runtime
├─ local_knowledge*.rs         本机资料库（存储、导入、OOXML、文件选择、向量）
├─ local_embedding.rs、vector_store.rs  ONNX 向量与 Zvec 索引
├─ expert_*.rs、digital_colleagues.rs   专家包、工作流、团队、数字同事
├─ mcp.rs、mcp/、mcp_openapi.rs MCP 与 OpenAPI
├─ lifecycle_hooks.rs          声明式生命周期策略
├─ model_service.rs            模型供应商连接与测试
├─ skills.rs                   Skills
├─ tool_guard.rs、tool_host.rs  路径与权限检查、Host 工具执行
├─ process_jobs.rs、command_environment.rs  进程作业（Windows Job Object）、环境变量白名单
├─ maintenance.rs              备份、恢复、预览缓存、维护
├─ data_paths.rs、app_state.rs  数据目录与共享状态
└─ office.rs、report_pdf.rs、html_preview.rs、artifact_gateway.rs、resource_gateway.rs 等
```

`apps/desktop/src-tauri/resources/` 存放随包资源：默认知识（含 fox-guide）、内置专家库、模型、Office Skills、OfficeCLI、PDF 渲染器和向量运行时。前端不得绕过 `commands` 直接访问数据库或本地文件。

crates/fox-agent-backend/

## Agent Runtime

```text
services/agent-runtime/
├─ src/
│  ├─ pi-runtime.mjs           Pi Runtime 进程入口（Legacy / JSONL 路径）
│  ├─ pi-kernel-worker.mjs、pi-kernel-loop.mjs、pi-kernel-description.mjs 等  Kernel 路径的模型 worker
│  ├─ runtime-instructions.mjs、prompt-composer.mjs、prompt-registry.mjs、typed-context.mjs  Prompt 组装
│  ├─ execution-profile.mjs、runtime-contract.mjs   Execution Profile、能力清单
│  ├─ host-tools.mjs、read-only-tools.mjs、graph-readonly-tools.mjs  工具定义
│  ├─ planner-runtime.mjs、fox-planning-extension.mjs  Planner 与工作工具
│  ├─ model-profile.mjs、native-model-*.mjs         模型画像与原生模型配置
│  ├─ codex-kernel-adapter.mjs、deepseek-kernel-adapter.mjs  Kernel 引擎适配（engine_id，非外层后端）
│  ├─ fake-runtime.mjs         测试用 Runtime
│  └─ offline-evaluator.mjs
├─ test/                       Node 原生测试
├─ evals/                      fixtures、harness-v1、manifests、run-offline-evals.mjs
├─ scripts/                    build-sidecar.mjs、smoke-sidecar.mjs
└─ dist/                       打包产物目录（只提交 .gitkeep）
```

Runtime 与 Host 之间一行一个 JSON。不要在标准输出打印普通日志，诊断信息走标准错误或结构化事件。

`codex-kernel-adapter.mjs` / `deepseek-kernel-adapter.mjs` 对应 Fox 会话内部 Kernel 的 `engine_id`（`FOX_KERNEL_ENGINE`，默认 `pi`），和外层的 `agent_backend` 不是一回事。
