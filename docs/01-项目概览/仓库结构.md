# 仓库结构

> 状态：生效<br>
> 适用版本：Fox `0.1.x`<br>
> 维护范围：Monorepo 目录和模块职责<br>
> 最后更新：2026-08-06

## 根目录

```text
Fox/
├─ apps/
│  └─ desktop/                 React + Tauri 桌面应用
├─ services/
│  └─ agent-runtime/           Node Agent Runtime 与 Sidecar 构建
├─ scripts/                    跨模块验证和维护脚本
├─ docs/                       项目文档
├─ package.json                根级命令入口
├─ pnpm-workspace.yaml         pnpm 工作区声明
└─ pnpm-lock.yaml              依赖锁文件
```

工作区声明包含 `apps/*`、`packages/*` 和 `services/*`。当前主要成员是 `apps/desktop` 与 `services/agent-runtime`；新增共享包时应优先放入 `packages`，不要继续扩大单文件或跨目录复制代码。

## 桌面前端

```text
apps/desktop/src/
├─ app/                        React 应用入口
├─ components/
│  ├─ ui/                      基础 UI 组件
│  ├─ ai-elements/             对话、推理、工具、引用和产物组件
│  └─ effects/                 受控视觉效果
├─ features/
│  ├─ agents/                  智能体页面与数据读取
│  ├─ chat/                    Workbench、布局与对话编排
│  ├─ conversations/           会话 API、Hook、事件 Reducer 和模型
│  ├─ knowledge/               知识库页面、预览器、图谱和阅读状态
│  ├─ profile/                 用户资料
│  ├─ settings/                设置页面和服务配置 Hook
│  └─ workspace/               通用业务页面与实体卡片
├─ styles/                     全局、工作台和管理页面样式
└─ main.tsx                    浏览器入口
```

`features/chat/workbench.tsx` 当前承担较多顶层页面、导航和状态编排责任。新增功能应优先进入对应 Feature，避免继续把业务逻辑堆入 Workbench。

## Tauri 后端

```text
apps/desktop/src-tauri/src/
├─ commands/                   暴露给前端的 Tauri Commands
├─ database/                   迁移、模型与 Repository
├─ runtime_host/               Sidecar 生命周期、协议和事件转发
├─ yuxi/                       知识库服务兼容适配与远程 Runtime
├─ app_state.rs                共享应用状态
├─ maintenance.rs              备份、恢复、缓存和维护操作
├─ mcp.rs                      MCP 配置与调用
├─ model_service.rs            模型供应商连接与配置
├─ skills.rs                   Skills 发现和启停
├─ tool_guard.rs               工具权限与审批决策
├─ tool_host.rs                Host 工具执行
└─ lib.rs                      Tauri 启动与 Command 注册
```

前端不得绕过 `commands` 直接访问数据库或本地文件。新增系统能力通常需要依次补充 Repository、Host 服务、Command、前端 Client/Hook 和测试。

## Agent Runtime

```text
services/agent-runtime/
├─ src/
│  ├─ pi-runtime.mjs           真实 Pi Runtime 进程入口
│  ├─ fake-runtime.mjs         测试与降级 Runtime
│  ├─ protocol.mjs             JSONL Envelope
│  ├─ runtime-contract.mjs     能力清单和工具目录
│  ├─ runtime-session.mjs      Session 持久化与恢复
│  ├─ pi-event-mapper.mjs      Pi 事件到 Fox 事件的映射
│  ├─ model-profile.mjs        模型族、能力和 Provider 兼容画像
│  ├─ runtime-instructions.mjs Fox 稳定运行规则与安全边界
│  ├─ prompt-composer.mjs      稳定提示词与动态 Host 上下文分层
│  ├─ planner-runtime.mjs      复杂任务的内部只读 Planner
│  ├─ fox-planning-extension.mjs Host Work Tools 与 Work Snapshot 注入
│  ├─ host-tools.mjs           Host Tool 定义
│  └─ read-only-tools.mjs      受限只读工具
├─ test/                       Node 原生测试
├─ evals/                      离线 Agent Harness 评测与 Fixture
├─ scripts/                    Sidecar 构建与 Smoke 测试
└─ dist/                       打包产物目录
```

Runtime 通过标准输入输出交换一行一个 JSON Envelope。不要在标准输出打印普通日志；诊断信息应进入标准错误或结构化事件，否则会破坏协议解析。

## 本地生成目录

以下目录不属于源代码，不应提交：

- `node_modules`、`node_modules-new`
- `apps/desktop/dist`
- `apps/desktop/src-tauri/target`
- `.runtime-build`、`.runtime-smoke`、`.runtime-yuxi-*`
- 本地 `.env`、数据库、下载缓存和诊断导出

`services/agent-runtime/dist/.gitkeep` 仅用于保留 Sidecar 输出目录，实际构建产物由构建流程生成。

## 常见修改入口

| 需求 | 优先检查 |
| --- | --- |
| 对话流式渲染 | `features/conversations`、`features/chat/workbench.tsx` |
| 消息发送、编辑、取消、恢复 | `features/conversations`、Rust `commands`/`repositories` |
| 新页面或管理界面 | 对应 `features`、`features/workspace` |
| 新 Tauri 能力 | `commands`、`app_state.rs`、对应 Rust 服务 |
| 数据结构变化 | `database/migrations.rs`、`models.rs`、`repositories.rs` |
| Runtime 事件或工具 | Rust `runtime_host` 与 Node `agent-runtime` 同步修改 |
| 新 Runtime Adapter | Agent `runtime_type` 路由、Host Adapter、统一事件与恢复契约 |
| 模型兼容或提示词 | `model-profile.mjs`、`runtime-instructions.mjs`、`prompt-composer.mjs`、`evals` |
| Goal/Task/Evidence | `database/repositories/work_graph.rs`、`runtime_host/work_tools.rs`、Work UI |
| 知识库接口 | `src-tauri/src/yuxi` 与 `features/knowledge` |
| 知识文件预览 | `features/knowledge/knowledge-*-viewer.tsx`、缓存 Commands/Repository |
| 模型供应商 | `model_service.rs` 与 `features/settings/use-model-*` |
| 权限策略 | `tool_guard.rs`、`tool_host.rs` 和 Runtime 能力清单 |
| 诊断与评测 | `runtime_host`、`work_diagnostics.rs`、Runtime `evals` |
