## 项目、知识与工具

| 领域 | 当前能力 | 关键边界 |
| --- | --- | --- |
| 项目 | 授权目录、文件树、读写、搜索、命令与测试执行 | Host 校验项目根目录；写入和进程操作按策略审批 |
| 远程知识库 | 列表、查询、图谱、原文件预览/下载和引用定位 | 外部服务可降级，不替代本地 SQLite 事实源 |
| 本地知识工作区 | 导入、解析、分块、SQLite 事实库、检索、引用与资源管理 | 向量能力依赖显式安装的受信模型/原生库，缺失时明确降级 |
| 插件中心 | 统一展示内建工具、Skills、MCP 与 OpenAPI 源 | 凭据进入 Keyring；扩展调用继续受 Host 策略和审计约束 |
| 通用工具 | `http_request`、`system_info`、`sqlite_read` | URL、环境变量、数据库路径、行列数、响应体和执行时长均有上限 |
| 数据治理 | SQLite 迁移、备份恢复、诊断导出、维护清理 | 产品事实只由 Host Repository 写入 |

## 验证方式

Fox 使用 Rust Repository/Host 测试、Runtime 协议测试、桌面前端测试、完整与快速离线 Eval、文档合同、Fixture、格式检查和生产构建共同验证能力。测试数量与结果 Hash 由基线工具生成，不在项目概览中维护容易过期的阶段数字；复现命令和当前口径见[Agent 能力测试基准](../05-开发指南/Agent能力测试基准.md)。

## 维护规则

- 新能力只有在数据持久化、错误码、用户入口和回归测试同时落地后，才能标记为“已实现”。
- 本页不复制字段、Command 和 Schema；这些细节由 `04-技术参考` 维护。
- 历史研究、交接稿和阶段报告不能用于判断当前完成度。
