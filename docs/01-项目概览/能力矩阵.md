# Fox 能力矩阵

> 状态：生效<br>
> 适用版本：Fox `0.1.x`<br>
> 维护范围：已经实现的产品能力、工程事实源与当前边界<br>
> 最后更新：2026-10-25

## 结论

本页回答“Fox 现在能做什么”。状态只用三种：**已实现**（当前 `main` 代码中存在）、**已实现首版**（有明确边界的首版）、**未实现 / 计划**。“已实现”不等于“已验收”，验收口径见[当前状态与核验基线](当前状态与核验基线.md)。未来计划在[Agent 能力路线图](../07-路线图/Agent能力路线图.md)维护，未解决的问题在[已知限制](../07-路线图/已知限制.md)。

## 项目、资料与工具

| 领域 | 当前能力 | 关键边界 |
| --- | --- | --- |
| 项目 | 项目列表、文件树、固定、归档；Fox 会话的读写、搜索与固定能力工具；外部会话必须绑定项目 | Host 校验项目根目录；Fox 会话的任意 Shell 由真实 SRT 限制；`test_run` 授权未绑定工作区修订（未关闭） |
| 远程知识库 | 列表、查询、图谱、原文件预览 / 下载和引用定位 | 服务可降级，不替代本地 SQLite 事实源；Fox 桌面没有向远程知识库上传文件的入口 |
| 本机资料库 | 导入、解析、分块、关键词与向量 RRF 混合检索、引用与资源管理 | 向量依赖随包的模型与原生库；存储位置不可写时降级为只读或不可用 |
| 插件中心与设置「插件」 | 技能、连接器（MCP / OpenAPI）、策略（生命周期 Hook） | 凭据进入凭据库；扩展调用受 Host 策略和审计约束 |
| 通用工具 | `http_request`、`system_info`、`sqlite_read` | URL、环境变量、数据库路径、行列数、响应体和执行时长有上限 |
| 模型服务 | 多供应商、一个供应商多协议、连接测试、默认模型 | Fox 自身连接协议为 Completions / Anthropic；`openai-responses` 用于 pi 和 Codex 的默认协议 |
| 数据治理 | 迁移（schema v97）、迁移前备份、备份恢复、诊断导出、维护清理 | 产品事实只由 Host Repository 写入 |
| 启动 | 资料库存储、预览缓存、缺失 Agent 行降级或修复；致命错误在 Windows 上弹出「Fox 无法启动」并退出 | 不删除数据库；非 Windows 只有日志 |
| 设置 | 7 个入口：通用 / 对话 / 模型 / Agent / 插件 / 资料库 / 数据与关于；旧路由重定向 | 「通用」页仍用旧的卡片结构，其余 6 页用统一布局 |

## 验证方式

能力由 Rust Host / Kernel / 引擎协议 / 外层 Agent 后端测试、Runtime 协议测试、桌面前端测试、离线 Eval、契约 Fixture 和生产构建共同验证；CI 只在 Windows 上运行。各范围的测试规模和 CI 结构见[可观测性与测试架构](../02-架构/可观测性与测试架构.md)，最近一次的 CI 结论和未验证项见[当前状态与核验基线](当前状态与核验基线.md)。本页不维护易过期的测试数字。

## 维护规则

- 新能力只有在数据持久化、错误码、用户入口和回归测试都落地后，才能标为“已实现”。
- 本页不复制字段、Command 和 Schema；细节由 `docs/04-技术参考` 和 `docs/02-架构` 维护。
- 历史研究、交接稿和阶段报告不能用来判断当前完成度。
