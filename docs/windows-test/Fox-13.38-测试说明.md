# Fox 13.38 Windows 测试说明

这份说明基于 main `0fdc231d`（之后只多了本说明这一个文档提交，用最新 main 构建结果相同）。相对 13.37（`bb6f88a9`）新增两路修复：

- **fox-fix-1337-run**（合入 `73d8e085`）：停止/取消链路、外部 Agent 取消后保留过程、后台任务状态回写、dsh 授权被拒的提示、审批卡路径、后台输出解码；
- **fox-ui-1337**（合入 `0fdc231d`）：设置 → Agent 启用即检测、模型连接验证记录、发送被拒必弹 toast、未回复会话可改项目和 Agent、权限菜单非模态。

13.37 已经通过的 P0（P0-1～P0-7）、批次 1、批次 2 不再重复。本轮只测两类：**这一轮修过的项**（A-1～A-8、B-1～B-6），以及 **13.37 里失败或没测到的项**（B3-1～B3-6、批次 4、5、6）。

一共 6 个批次，每批约 10–15 分钟，互不依赖，可以各开一个新会话、按任意顺序执行。每批开头写了前置条件和复位步骤，结尾给出回传格式。证据优先用脚本收集，截图只在界面类项目里要求。

> **重要提醒：做 B3-1 之前不要先进「设置 → Agent」。** 从这一版起，打开这个页面就会触发一次真实的模型连接测试，测试通过会把当前地址记为「已验证」，B3-1 就复现不出来了。批次 3 里按步骤顺序做，中途不要打开「设置 → Agent」。

## 通用准备（只做一次）

1. **构建**：源码用 main `0fdc231d`（`git fetch && git checkout origin/main`，确认 `git log -1` 是本说明的提交或 `0fdc231d`）。运行时包仍用 **0.1.8**，SHA256 为 `0f9c199da3aed28b3ccdc52885c04a49548c79f65e98a89106836e50e35d397f`，来源和校验方法同 13.35。

   VS 2026 的构建机需要先设置运行库目录，路径中的 `<版本>` 和 `<CRT 目录>` 按本机实际填写，然后再执行 `pnpm tauri:build:windows`：

   ```powershell
   $env:FOX_WINDOWS_CRT_DIR = 'C:\Program Files\Microsoft Visual Studio\18\<Edition>\VC\Redist\MSVC\<版本>\x64\<CRT 目录>'
   ```

   安装器钩子跑在 Windows PowerShell 5.1 里，所以安装日志 `%ProgramData%\Fox\logs\sandbox-installer-*.log` 里不应出现乱码。

2. **目录**：
   - exe 复制到 `D:\fox-test\Fox-app\`，以普通用户（Medium 完整性）运行；
   - 测试项目放在 `D:\fox-test\测试项目\`，备份到 `D:\fox-test\backup\project-1338\`；
   - 取证脚本复制到 `D:\fox-test\tools\windows-test\`（仓库里的 `scripts\windows-test\*`，本轮没有改动）。

3. **建一份基线数据目录**：用 `FOX_DATA_DIR=D:\fox-test\data-1338-base` 启动一次 Fox，然后：
   - 在「设置 → 模型服务」配好两个供应商：官方 DeepSeek（有 Key 时），以及一个 **OpenAI 兼容** 供应商（例如 Magpie）。默认供应商设为 OpenAI 兼容那家。这家下面**不要**加 Anthropic Messages 地址（批次 3 会现加）；
   - 到 **设置 → Agent** 里**打开 Pi、Codex、dsh 三个「启用」开关**。外部 Agent 默认不启用，不启用就不会出现在对话的 Agent 选择里，批次 1、2、4 都要用到它们。确认三者状态都是「已检测到」（这一版打开开关后应自动刷新，不需要切页；如果仍要切页，在 R2-3 里记失败）；
   - 关闭 Fox。各批复位时复制这份目录，不在基线上直接测。

4. **启动方式**：每批都用下面的命令启动，stderr 就是日志文件：

   ```powershell
   $env:FOX_DATA_DIR = 'D:\fox-test\data-<批次>'
   Start-Process -FilePath 'D:\fox-test\Fox-app\fox-desktop.exe' -RedirectStandardError "D:\fox-test\logs\fox-<批次>.log"
   ```

   如果 exe 名是 `Fox.exe`，换成这个名字即可，取证脚本两种名字都能识别。

5. **取证**：开一个**管理员** PowerShell（5.1 或 7 都可以），`cd D:\fox-test\tools\windows-test`。需要管理员是为了读到其他账户（例如 Codex 沙箱账户）的进程信息；Fox 本身仍按普通用户运行。

   ```powershell
   .\Collect-FoxEvidence.ps1 -Label <编号>-before -ProcessOnly        # 动作前的进程基线
   .\Collect-FoxEvidence.ps1 -Label <编号> -Baseline .\fox-evidence\<编号>-before-*.json `
       -LogPath D:\fox-test\logs\fox-<批次>.log -DataDir D:\fox-test\data-<批次>
   ```

   输出在 `.\fox-evidence\` 下：`<编号>-<时间>.json` 是全部数据，`<编号>-<时间>.txt` 是摘要。回传时只给证据文件名，最后把整个 `fox-evidence` 文件夹打包发回。数据库副本含对话内容，脚本默认用完就删除。

   **停止耗时怎么抄**（A-1）：json 里 `log.cancelSwept[].text` 是 `cancel_swept` 那一行原文，末尾有 `confirm_ms=… grace_ms=… sweep_ms=…`；`log.foxExternalTail` 里找含 `cancel_settled_ms=` 的一行。也可以直接在日志里搜：`Select-String -Path D:\fox-test\logs\fox-<批次>.log -Pattern 'cancel_settled_ms|cancel_swept'`。`confirm_ms` 可能是 `-`（没有走到确认这一步），照抄即可。

**通用复位步骤（每批开头都执行）**：

1. 关闭 Fox，确认任务管理器里没有残留的 `fox-desktop` / `node` / `codex*` / `dsh*` / `pi*` 进程（可以跑一次 `.\Get-FoxProcessTree.ps1` 查看）；
2. `Copy-Item D:\fox-test\data-1338-base D:\fox-test\data-<批次> -Recurse`；
3. 用备份覆盖 `D:\fox-test\测试项目\`；
4. 按第 4 步启动 Fox。

**回传格式（所有批次通用）**：每项一行。

```
<编号> 通过|失败|未触达  证据：<文件名>[, <文件名>]  备注：<一句话，失败或未触达时必填>
```

涉及停止的项，备注里加一段：`耗时 confirm=<ms> grace=<ms> sweep=<ms> settled=<ms> 体感=<点停止到出现「正在取消」的秒数>/<到「已取消」的秒数>`。
