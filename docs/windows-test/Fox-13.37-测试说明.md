# Fox 13.37 Windows 测试说明

这份说明基于 main `5f5feb04`，包含 fox-fix-1335 的全部改动、取证脚本 `scripts/windows-test/`、e2e-1101 的 Host 修复（发送被拒的原因、模型服务保存、Pi 配置来源默认取模型服务），以及 UI 1103（外部 Agent 改为在设置里主动启用、删除输入框上方的登录卡、新对话输入框恢复高框加托盘）。13.35 实测里没跑完的项目都已并入下面各批。

先做最前面的「最短完整路径」（约 10 分钟），再做后面 6 个批次。测试分成 6 个批次，每批约 10–15 分钟。批次之间互不依赖，可以各开一个新会话、按任意顺序执行。每批开头写了前置条件和复位步骤，结尾给出回传格式。证据优先用脚本收集，截图只在界面类项目里要求。

**CI 已经覆盖、这里不再列出的项目：**

- 删除项目根的内置拦截（`host_block_e2e`）；
- 取消清扫孙进程、Job 外后代的判定逻辑（`cancel_sweep`、`outside_job_descendants`）；
- PiNative 后台命令的准入单测（`native_background_*`）；
- 改供应商后的缺口分类（`login_gap_*`）；
- MCP stdio 会话（`lists_and_calls_tools_*`）；
- 提示文案的前端单测；
- Fox 原生一整轮（询问档：写工具出卡后批准、拒绝、多轮、`run_command` 运行中停止后子进程按 pid 确认被回收、停止后继续下一轮）：`e2e_fox_native_full_turn_approval_second_turn_and_cancel`（Windows CI）；
- 外部 ACP 一整轮（pi / codex / dsh 各一条：流式回复、审批、工具子进程、复用会话、取消清扫后继续）：`e2e_acp_full_turn_{pi,codex,dsh}`（Windows 和 Linux CI，用 mock Agent）；

## 通用准备（只做一次）

1. **构建**：源码用 main `5f5feb04`（`git fetch && git checkout 5f5feb04`），运行时包仍用 **0.1.8**，SHA256 为 `0f9c199da3aed28b3ccdc52885c04a49548c79f65e98a89106836e50e35d397f`，来源和校验方法同 13.35。

   VS 2026 的构建机需要先设置运行库目录，路径中的 `<版本>` 和 `<CRT 目录>` 按本机实际填写，然后再执行 `pnpm tauri:build:windows`：

   ```powershell
   $env:FOX_WINDOWS_CRT_DIR = 'C:\Program Files\Microsoft Visual Studio\18\<Edition>\VC\Redist\MSVC\<版本>\x64\<CRT 目录>'
   ```

   安装器钩子跑在 Windows PowerShell 5.1 里，所以安装日志 `%ProgramData%\Fox\logs\sandbox-installer-*.log` 里不应出现乱码。

2. **目录**：
   - exe 复制到 `D:\fox-test\Fox-app\`，以普通用户（Medium 完整性）运行；
   - 测试项目放在 `D:\fox-test\测试项目\`，备份到 `D:\fox-test\backup\project-1336\`；
   - 取证脚本复制到 `D:\fox-test\tools\windows-test\`（仓库里的 `scripts\windows-test\*`）。

3. **建一份基线数据目录**：用 `FOX_DATA_DIR=D:\fox-test\data-1336-base` 启动一次 Fox，配好模型服务（官方 DeepSeek，以及一个 OpenAI 兼容供应商）；再到 **设置 → Agent** 里打开 Pi、Codex、dsh 的「启用」开关（外部 Agent 默认不启用，不启用就不会出现在对话的 Agent 选择里），确认各自状态为「已检测到」；然后关闭 Fox。各批复位时复制这份目录，不在基线上直接测。

4. **启动方式**：每批都用下面的命令启动，stderr 就是日志文件：

   ```powershell
   $env:FOX_DATA_DIR = 'D:\fox-test\data-<批次>'
   Start-Process -FilePath 'D:\fox-test\Fox-app\fox-desktop.exe' -RedirectStandardError "D:\fox-test\logs\fox-<批次>.log"
   ```

   如果 exe 名是 `Fox.exe`，换成这个名字即可，取证脚本两种名字都能识别。

5. **取证**：开一个**管理员** PowerShell（5.1 或 7 都可以），`cd D:\fox-test\tools\windows-test`。需要管理员是为了读到其他账户（例如 Codex 沙箱账户）的进程信息；Fox 本身仍按普通用户运行。

   ```powershell
   .\Collect-FoxEvidence.ps1 -Label <编号>-before -ProcessOnly        # 动作前的进程基线
   .\Collect-FoxEvidence.ps1 -Label <编号> -Baseline .\fox-evidence\<编号>-before-*.json `
       -LogPath D:\fox-test\logs\fox-<批次>.log -DataDir D:\fox-test\data-<批次>
   ```

   输出在 `.\fox-evidence\` 下：`<编号>-<时间>.json` 是全部数据，`<编号>-<时间>.txt` 是摘要。回传时只给证据文件名，最后把整个 `fox-evidence` 文件夹打包发回。数据库副本含对话内容，脚本默认用完就删除。

**通用复位步骤（每批开头都执行）**：

1. 关闭 Fox，确认任务管理器里没有残留的 `fox-desktop` / `node` / `codex*` / `dsh*` / `pi*` 进程（可以跑一次 `.\Get-FoxProcessTree.ps1` 查看）；
2. `Copy-Item D:\fox-test\data-1336-base D:\fox-test\data-<批次> -Recurse`；
3. 用备份覆盖 `D:\fox-test\测试项目\`；
4. 按第 4 步启动 Fox。

**回传格式（所有批次通用）**：每项一行。

```
<编号> 通过|失败|未触达  证据：<文件名>[, <文件名>]  备注：<一句话，失败或未触达时必填>
```

## 批次 1：后台 run_command 与 Fox 命令取消（约 15 分钟）

**前置条件**：执行通用复位，数据目录为 `data-B1`；新建 **Fox** 会话并绑定测试项目，档位设为**询问**。

说明：后台任务属于发起它的那一轮，这一轮结束时 Fox 会一并结束它的后台任务。所以 start、status、output、cancel 必须在**同一条消息**里让 Fox 连续完成，分成几条消息发时，后一条看到的任务已经随上一轮结束了。

| 编号 | 步骤 | 期望 |
|---|---|---|
| B1-1 | 先采集基线 `B1-1-before`。**在同一条消息里**让 Fox 依次做完：「用 run_command 的 start（后台）执行 `ping -n 120 127.0.0.1`；拿到任务 id 后，对它执行 status 和 output；再执行 cancel，然后告诉我每一步的结果」。出现审批卡后点「只允许这一次」 | 后台任务启动成功，**不再**报 `resource admission requires an active Kernel owner`。回复里能看到任务 id |
| B1-2 | 看 B1-1 回复里 status / output 两步的结果 | status 为运行中，output 有 ping 的输出 |
| B1-3 | 看 cancel 一步的结果；回复结束 3 秒后采集 `B1-3`（`-Baseline` 用 B1-1-before） | 任务状态为已取消。摘要里没有和 Fox 相关的 `ALIVE` 行（`PING.EXE`、`cmd.exe`、`conhost.exe` 都已消失）。db 段 `jobs` 里这条任务为 `cancelled` |
| B1-4 | 新发一条消息：「用 start 后台执行 `ping -n 120 127.0.0.1`，然后每隔几秒查一次 status，一共查 10 次」，批准后在它查询的过程中点输入框的**停止**。3 秒后采集 `B1-4` | 后台进程随 Run 一起回收，没有 `ALIVE` 行。Run 显示「已取消」 |
| B1-5 | B1-4 停止 10 秒后再采集一次 `B1-5`（`-Baseline` 用 B1-1-before），然后在同一会话发一条新消息 | 已结束的 Run 不会再拉起后台进程，没有 `ALIVE` 行。日志和数据库里没有这个 Run 在停止之后启动的新任务。新消息能正常回复 |

回传：B1-1 至 B1-5，每项一行。（原 B1-6「前台命令的孙进程随停止回收」已由 CI 的 Fox 原生 e2e 证明，删去。）

|---|---|---|
