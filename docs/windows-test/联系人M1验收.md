# 联系人 M1 Windows 验收

在 Windows 上使用 Node.js 24 或更高版本。从仓库根目录运行。准备同一份源码构建的桌面调试程序和 Windows Agent Runtime。脚本会使用本机 1421 端口启动开发版前端，请先关闭占用此端口的开发服务。

```powershell
$desktop = '实际构建的 fox-desktop.exe 路径'
$runtime = 'services/agent-runtime/dist/fox-agent-runtime-x86_64-pc-windows-msvc.exe'
node scripts/windows-test/Run-ContactsM1.mjs --exe $desktop --sidecar $runtime --dev
```

这条命令启动桌面程序、WebView2 和本地模型模拟服务。它通过实际桌面命令创建联系人、保存聊天附件、读文件、处理草稿、归档、授权与删除。脚本会退出测试版 Fox，清空测试会话文件，再启动测试版验证修复前后的消息条数、会话代次和文件读取。协议检查可以通过 `node scripts/windows-test/Run-ContactsM1.mjs` 单独运行。

## 真实模型

先在已安装的 Fox 中配置并验证全局模型。下面的命令会调用该服务，使用测试脚本生成的报价、文件和对话。测试进程只读安装版数据库中的模型服务配置，凭据由 Fox 从 Windows 凭据库取得。每次运行都使用新的测试资料目录。

```powershell
$profile = Join-Path $env:APPDATA 'com.fox.agent/fox.db'
node scripts/windows-test/Run-ContactsM1.mjs --exe $desktop --sidecar $runtime --dev --live-profile $profile
```

模型用例同时核对回答、工具回执或数据库结果。例如，判断“我喜欢先看结论”是否已保存时，要找到已确认的共享记忆及对应的用户原话。项目笔记采用随机编号，先撤权再询问新编号，可区分模型记住的聊天记录与本轮能读取的资料。

## 读取结果

控制台第一行列出本轮目录。`evidence.json` 记录源码提交、桌面与运行时的 SHA-256、逐项结果和失败原因。请用进程退出码判断整轮是否成功。真实模型首个响应超时时，只有零次工具调用的回合才允许重试一次，两次结果都会保留。调试版桌面验证、安装包覆盖升级和 GitHub CI 分别记录。
