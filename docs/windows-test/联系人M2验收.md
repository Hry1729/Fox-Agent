# 联系人 M2 验收

M2 在联系人私聊中开放主动重置。本组测试需要 Windows 测试版 Fox、与之配套的 Pi 运行时，以及安装版 Fox 中已验证的全局模型。测试版使用独立数据库、工作目录和 WebView2 配置。真实模型只接收本次生成的编号和台账。

## 运行

从工作树根目录用 PowerShell 执行。将两项程序路径替换为本次构建产物。

```powershell
$desktop = '本次构建的 fox-desktop.exe 路径'
$runtime = 'services/agent-runtime/dist/fox-agent-runtime-x86_64-pc-windows-msvc.exe'
$profile = Join-Path $env:APPDATA 'com.fox.agent/fox.db'
$testTemp = New-Item -ItemType Directory -Force .test-target/m2-profiles
$env:TEMP = $testTemp.FullName
$env:TMP = $testTemp.FullName
node scripts/windows-test/Run-ContactsM1.mjs --exe $desktop --sidecar $runtime --m2 --dev --live-profile $profile
```

开发版默认读取端口 1421。同时验收两个版本时，可在构建 M2 桌面前设置 `$env:TAURI_CONFIG='{"build":{"devUrl":"http://127.0.0.1:15341"}}'`，运行测试前将 `FOX_CONTACTS_DEV_PORT` 设为同一端口。每次运行会输出测试目录。其中的 `evidence.json` 记录提交、两个程序的 SHA-256 和逐项结果。

## 判定

| 用例 | 实际检查 |
| --- | --- |
| A14 | 第一次对话给出随机编号。退出并重新启动测试桌面后，真实模型应在同一个原生会话中答回该编号。对照会话 ID、代次、原生文件路径和重新启动前后的文件内容。 |
| A15 | 在空白的小狐私聊中，把上下文窗口设为 24,576 token，输出上限设为 4,096 token。分批发送合成台账直到 Pi 压缩对话。核对随机交接号只出现在当前分支的活动摘要中。重启桌面，核对会话映射和文件内容，再让模型只回复完整编号。逐轮检查工具调用数为零。 |
| A16 | 用界面对应的命令重置私聊。检查代次加一、原会话文件内容完整，逐项检查消息、主笔记、专题、共享偏好、工作文件和项目授权。在新代次的第一轮对话中，让真实模型答回主笔记里的随机编号。 |
| A17 | 在完全退出桌面后，依次制造已持久化会话的文件丢失、文件头损坏和原生身份错配。首次恢复失败后，再次发送应被拒绝。用户确认修复后，下一轮可发送。此项使用本地模型模拟服务和真实 Pi 运行时。零字节且未持久化的会话另见 M1 的 A20。 |
| A18 | 运行 Rust 的 `context_reset_tests`、`sidecar_sessions::tests`、旧代次工具调用和跨会话身份回归。它们分别检查另一个联系人的会话、同时活动的会话以及退休代次的调用。 |
| A19 | 有可恢复上下文的联系人被归档后，发送会被拒绝。恢复后继续同一代次，并让模型重新回答归档前的交接号。 |

A17 中，已持久化会话在首次恢复时才发现文件错误。Fox 会保留该次用户消息和失败记录。映射进入不可用状态后，重复发送不会新增消息。M1 的零字节未持久化情形在创建消息前即可识别。
