# FoxOps 数据总览页面完整迁移方案

## 1. 迁移目标

完整迁移 Yuxi `/dashboard` 管理员数据总览，保持 `/api/dashboard` 统计口径不变，以 ArtDesignPro 卡片、统计组件和 ECharts 重建视觉。页面必须覆盖基础指标、调用趋势、用户活跃、智能体、工具、知识库和用户反馈，不以静态示例图替代真实数据。

## 2. 路由与权限

- 建议路由：`/dashboard/overview`，旧 `/dashboard` 可重定向。
- 仅 `superadmin` 可访问，菜单和路由守卫同时控制；后端继续执行管理员鉴权。
- 默认不 keep-alive，进入时重新取数；若后续开启缓存，必须提供刷新和过期策略。

## 3. 页面布局

- 顶部状态条：当前用户、系统设置入口、主题、任务中心等与全局容器协调，避免重复。
- 指标总览条：核心统计卡和反馈入口。
- 第一行：调用统计占两列，用户活跃占一列。
- 第二行：AI 智能体、工具调用、知识库各一列。
- 1200px 以下两列，768px 以下单列；图表随容器而不是只随 window resize。

## 4. 基础统计与反馈入口

- 展示后端返回的对话、消息/调用、用户等核心总数及趋势。
- 反馈卡展示好评/差评、满意率等 `feedback_stats`，满意率按阈值使用语义色。
- 点击反馈卡打开“用户反馈详情”，不是跳转空页面。
- 数值为 0 时正常显示 0；缺失字段显示占位并保留卡片结构。

## 5. 调用统计

- 默认类型为智能体，支持模型、智能体、Token、工具四类切换。
- 时间范围支持最近 14 小时、14 天、14 周，对应后端 `time_range`。
- 请求 `/api/dashboard/stats/calls/timeseries?type=&time_range=`。
- 多序列折线/面积图展示分类数据；智能体 ID 映射为名称。
- Tooltip 显示当前时间点非零系列、各值和合计；Token 使用 K/M 等可读格式。
- 图例过长可滚动/截断但 tooltip 保留完整名称；主题切换后重绘。
- 切换筛选有局部 loading，快速切换避免旧请求覆盖新结果。

## 6. 用户活跃度

- 标题“用户活跃度分析”。
- 展示用户总数、活跃用户等后端提供摘要。
- `daily_active_users` 用时间序列图呈现，日期、值和 tooltip 准确。
- 空数组显示“暂无活跃数据”，不能留下空白 ECharts 容器。

## 7. AI 智能体分析

- 摘要：智能体总数、总对话数、工具调用总数。
- 将 `agent_conversation_counts` 与 `agent_tool_usage` 合并，展示 Top 智能体对比图。
- 通过 `agent_names` 映射友好名称，保留 ID tooltip。
- 排行表展示名次、智能体、满意率、对话数等后端 performer 数据。
- 满意率使用进度/颜色表达；空反馈不能误算成 0% 差评。

## 8. 工具调用监控

- 摘要：总调用、失败调用、成功率。
- Top 10 常用工具横向图，按调用次数排序。
- 有错误数据时增加错误分析：Top 失败工具表和 Top 5 图表。
- 工具无调用和无错误是两个不同空态；名称过长可省略并保留 tooltip。

## 9. 知识库使用情况

- 摘要：知识库总数、文件总数、存储容量。
- 文件类型分布环形图，显示总文件数、图例/轮播信息。
- 展示平均每库文件数、平均每文件节点数、平均节点大小等后端指标。
- 存储单位自动格式化；分母为 0 时不得出现 NaN/Infinity。
- 文件类型为空时显示空态并停止轮播定时器。

## 10. 用户反馈详情弹窗

- 筛选全部、好评、差评，并按可选 `agent_id` 请求 `/api/dashboard/feedbacks`。
- 卡片展示用户头像/名称、评级、时间、会话标题、智能体、消息内容和反馈原因。
- 长标题、长消息独立展开/收起；关闭后清理展开状态或按既定策略保留。
- 加载、空态、失败和重试齐全；弹窗在小屏改为全屏/抽屉。
- 不展示后端未授权的敏感会话内容。

## 11. 数据加载与生命周期

- 首屏并行请求 basic/users/tools/knowledge/agents；某一模块失败不应让所有已成功模块消失。
- 原 Yuxi `getAllStats()` 全失败后仅回退基础统计的策略应升级为 `Promise.allSettled` 等价的分区状态。
- 调用趋势由组件独立按筛选加载；提供页面刷新按钮并防止并发重复。
- 页面卸载、主题切换和容器尺寸变化时正确 dispose/resize 图表、清除定时器和取消请求。
- 修复原清理函数把 tool/knowledge/agent cleanup 误调用到 `userStatsRef` 的问题。

## 12. API 清单

- `GET /api/dashboard/stats`
- `GET /api/dashboard/stats/users`
- `GET /api/dashboard/stats/tools`
- `GET /api/dashboard/stats/knowledge`
- `GET /api/dashboard/stats/agents`
- `GET /api/dashboard/stats/calls/timeseries`
- `GET /api/dashboard/feedbacks`
- 保留 `getConversations`、`getConversationDetail` API 适配，以便后续从指标下钻；本轮不虚构未存在的下钻 UI。

## 13. 验收清单

- [ ] 非超级管理员无法从菜单或 URL 进入。
- [ ] 七类内容均使用真实 API：基础、调用、用户、智能体、工具、知识库、反馈。
- [ ] 调用类型和时间范围切换正确，无旧请求覆盖。
- [ ] 单个模块失败时其他模块仍可展示并可单独重试。
- [ ] 亮/暗主题、窗口/容器缩放后图表正确重绘且无泄漏。
- [ ] 0、空数组、缺字段、大数值和长名称均显示合理。
- [ ] 反馈弹窗筛选、展开和隐私边界正确。
