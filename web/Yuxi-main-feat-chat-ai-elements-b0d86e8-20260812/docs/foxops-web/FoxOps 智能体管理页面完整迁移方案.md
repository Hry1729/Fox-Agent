# FoxOps 智能体管理页面完整迁移方案

## 1. 迁移目标

完整迁移 Yuxi `/model-manage` 页面，包含“智能体”和管理员可见的“模型供应商”两个页签。FoxOps 使用 ArtDesignPro 页面头、卡片、表单、抽屉/弹窗和 Element Plus 反馈组件，保持 Yuxi 智能体、运行配置、共享权限与模型供应商 API 不变。

## 2. 路由与权限

- 建议路由：`/agent/manage`，可为旧 `/model-manage?tab=agents|providers` 配置兼容跳转。
- 登录用户可见智能体页签；只有 `admin`/`superadmin` 显示并访问模型供应商页签。
- `tab` 查询参数与选中页签双向同步；普通用户手工输入 `providers` 必须归一化回 `agents`。
- 智能体卡片的编辑/删除能力以 `can_manage` 和内置标记为准，不仅依赖前端角色。

## 3. 页面骨架

- 页面标题“智能体管理”，顶部页签和加载状态。
- 智能体统计：总数、全局、内置、可管理。
- 供应商统计：总数、启用、凭证缺失、模型数。
- 页签内容保持各自滚动和状态，切换不应重复丢失搜索条件。

## 4. 智能体列表

- 加载智能体后端选项与包含子智能体的完整列表。
- 搜索名称、ID/slug、`backend_id`；中文稳定排序，内置项优先。
- 按“智能体 / 子智能体”分组；空列表和无搜索结果使用不同文案。
- 卡片展示图标/回退头像、名称、slug/ID、描述、后端标签和只读标签。
- 顶部支持新增和刷新；卡片点击编辑；更多菜单支持编辑、删除。
- 内置智能体不可删除；不可管理项只读；删除前说明历史对话仍保留绑定信息。
- 保存/删除后同时刷新管理列表与全局 agent store，保证 Chat 选择器立即更新。

## 5. 新建与编辑智能体

### 5.1 基本信息

- 新建时选择智能体后端；编辑时后端不可随意更换。
- 图标上传、预览与回退头像；名称、ID/slug、描述等字段依照后端 schema 校验。
- 根据后端识别是否为子智能体，并自动设置 `is_subagent`。
- 编辑前获取详情而不是只使用卡片摘要；保存时仅提交后端支持字段。

### 5.2 共享范围

- 支持 `user`、`department`、`specific_users`、`global` 等后端实际访问级别。
- 部门与指定用户选择器接真实列表；普通用户只能保存个人范围，管理员才可扩大范围。
- 内置智能体按全局只读规则显示；前端不可伪造越权范围。

### 5.3 运行配置

- 由 `AgentRuntimeConfigForm` 等价组件根据后端配置/schema 呈现，不把字段硬编码在迁移页。
- 页签至少包含：模型配置、工具配置、其他配置；仅对运行时智能体后端展示。
- 模型：模型规格、推理/温度/上下文等后端已支持参数。
- 工具：工具、MCP、Skill、知识库等可用能力选择及必要参数。
- 其他：系统提示词、运行限制、子智能体或后端扩展字段。
- 保存前调用 `validateAndFilterConfig` 等价校验，过滤无效字段；配置与基本资料的保存结果必须一致反馈。

## 6. 模型供应商列表与编辑

- 卡片展示供应商名称、ID、Base URL、能力、启用状态、凭证缺失告警和模型数。
- 搜索/刷新、新增、编辑、启停、删除；删除有二次确认和依赖错误反馈。
- 表单字段以现有后端为准：`provider_id`、展示名、供应商类型、Base URL、API Key/凭证、能力、启用状态及高级配置。
- 凭证编辑采用“未修改则不覆盖”语义，不把遮罩值提交回后端。
- 列表、弹窗和操作按钮均有独立 loading，防止重复提交。

## 7. 供应商模型管理

- 已启用模型按全部、Chat、Embedding、Rerank 分类筛选。
- 支持从远端拉取候选模型、刷新候选列表、添加到启用列表、移除模型。
- 模型行展示 ID/名称、类型、价格信息、启用状态和配置入口。
- 支持单模型连接测试，按 `provider/model` 规格请求状态；测试中、成功、失败清晰可见。
- 模型配置弹窗支持类型、显示名、上下文/维度等后端允许的覆盖配置。
- 添加、移除、编辑后更新 `enabled_models` 并刷新全局模型缓存/选择器。
- 远端接口不可用、无模型、部分模型重复、凭证缺失都需要专门状态。

## 8. API 对照

- 智能体：获取后端、列表/详情、创建、更新、删除、图标上传、运行配置与共享范围。
- 供应商：`GET/POST/PUT/DELETE /api/system/model-providers...`。
- 模型：远端获取、状态测试、`enabled_models` 更新、模型缓存刷新。
- 所有 API 封装进入 `foxops-web/src/api`，组件不得直接散写 fetch。
- 保留 `agent_id/slug/backend_id/share_config/model_spec` 等后端字段含义。

## 9. 状态与安全

- 覆盖首次加载、刷新、空态、搜索无结果、详情失败、保存冲突、删除依赖、凭证缺失、连接测试超时。
- 页面层与按钮层双重权限不是后端授权替代；403 时刷新用户/实体权限并给出说明。
- API Key 永不回显完整旧值；日志和 toast 不包含敏感信息。
- 离开未保存表单时提示，保存成功才关闭弹窗。

## 10. 实施顺序

1. 路由、权限、页签和统计条。
2. 智能体卡片、搜索、CRUD、内置/只读规则。
3. 智能体基本信息、共享范围、运行配置全字段。
4. 供应商 CRUD、启停、凭证状态。
5. 远端模型、模型配置和连接测试。
6. 响应式、错误态、权限与 Chat 联动回归。

## 11. 验收清单

- [ ] 普通用户只见智能体，管理员可见供应商，查询参数不能越权。
- [ ] 智能体/子智能体分组、搜索、统计和只读规则准确。
- [ ] 新建、编辑、图标、共享范围、运行配置、删除全部接真实 API。
- [ ] 内置智能体不可删除，历史对话不因删除自定义智能体而丢失。
- [ ] 供应商增删改、启停、凭证告警、远端模型管理可用。
- [ ] Chat 页能立即获得更新后的智能体与模型数据。
