# FoxOps 404 页面完整迁移方案

## 1. 迁移目标

替换 Yuxi 目前只有“Page not found”的最小 `EmptyView.vue`，使用 ArtDesignPro 结果页重建 FoxOps 404，但保持轻量，不扩展为复杂业务页。

## 2. 路由与内容

- 捕获 `/:pathMatch(.*)*`，公开可访问，必须放在路由表最后。
- 展示 404、页面不存在说明、返回首页按钮。
- 已登录用户额外提供“进入 Chat/工作台”；未登录可提供登录入口。
- 不回显可能含敏感参数的完整 URL；不自动跳转导致用户无法阅读。

## 3. 交互与视觉

- 使用 FoxOps 品牌图形或 ArtDesignPro 本地资源，不从未知站点热链。
- 返回按钮优先 `router.back()` 仅在有可靠站内历史时使用，否则回首页。
- 页面支持亮/暗主题、移动端和键盘焦点。
- 设置合理页面标题，如“页面不存在 - FoxOps”。

## 4. 验收清单

- [ ] 任意未知路径均进入 404，不吞掉正常动态路由。
- [ ] 首页、Chat/登录入口按登录态正确展示和跳转。
- [ ] 不泄露原 URL 参数，不依赖外部图片。
- [ ] 桌面和移动端均无滚动溢出。
