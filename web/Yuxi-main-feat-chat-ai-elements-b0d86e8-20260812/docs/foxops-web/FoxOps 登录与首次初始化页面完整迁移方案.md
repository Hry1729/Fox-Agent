# FoxOps 登录与首次初始化页面完整迁移方案

## 1. 迁移目标

迁移 Yuxi `/login` 的账号登录、首次启动超级管理员初始化、服务健康检查、账户锁定、协议确认和 OIDC 入口。可以复用 ArtDesignPro 登录页布局，但所有表单、状态、品牌和后端流程必须换成 Yuxi 真实能力。

## 2. 路由与安全导航

- 路由 `/login`，公开访问；已登录用户按经过清洗的 `redirect` 返回目标页。
- 未登录用户由路由守卫保存站内 redirect；禁止 `//evil.com`、协议 URL 等开放重定向。
- 页面初始化顺序：健康检查 → 首次运行状态 → 品牌/协议 → OIDC 配置。
- 若 OIDC 配置要求自动跳转，仍需防循环和保留原 redirect。

## 3. 品牌与布局

- 顶部 Logo、组织名、产品名、登录背景、页脚和协议链接来自 info/branding 配置。
- 桌面端图像+表单双栏，移动端隐藏/压缩图像区，表单保持完整。
- 服务连接失败时页面顶部常驻告警，显示错误摘要和“重新检测”。
- 不硬编码 Yuxi 名称、图片或版权到 FoxOps 产品页。

## 4. 普通登录

- 账号支持后端允许的用户名/UID/手机号语义，密码必填。
- 登录按钮有 loading、防重复提交；Enter 提交并兼容输入法。
- 若配置了用户协议/隐私政策，提交前必须勾选同意；链接新窗口安全打开。
- 成功后写入 token 和用户状态、初始化智能体列表，再跳 redirect 或 Chat。
- 失败区分凭证错误、锁定、服务不可达、限流和未知错误，不回显敏感后端堆栈。

## 5. 账户锁定

- 从响应头 `X-Lock-Remaining` 或后端错误提取剩余秒数。
- 锁定期间禁用登录并显示天/时/分/秒倒计时。
- 倒计时归零后恢复按钮；重新登录成功或页面卸载时清理定时器。
- 客户端倒计时仅用于提示，不能替代后端锁定校验。

## 6. 首次初始化

- `checkFirstRun` 为 true 时切换为“创建超级管理员”，不显示普通登录表单。
- 字段：UID/用户名（以后端定义为准）、手机号、密码、确认密码、协议确认。
- UID/用户名长度与字符规则、手机号、密码强度和两次密码一致性均需校验。
- 初始化按钮在服务不健康、表单无效、未同意协议时禁用。
- 成功后建立登录态并进入首页/工作台；重复初始化冲突提示重新获取状态。

## 7. OIDC 登录入口

- 请求 `/api/auth/oidc/config`，检查期间显示 skeleton，启用后展示提供方名称/图标/按钮文案。
- 点击请求 `/api/auth/oidc/login-url`，保存 redirect 到 `sessionStorage.oidc_redirect` 后跳转。
- 配置关闭时整个第三方区域隐藏；请求失败不影响账号密码登录。
- URL 中 `oidc_error` 应显示并在适当时清理，防刷新重复提示。

## 8. API 与状态

- 健康：`GET /api/health` 等现有健康接口。
- 首次运行检查与初始化：沿用 user store 当前 API。
- 密码登录、当前用户：沿用 Yuxi 用户认证接口。
- OIDC：config、login-url；code 交换由独立回调页处理。
- token 持久化集中在 auth/user store；页面不维护第二套字段映射。

## 9. 验收清单

- [ ] 服务健康告警与重试不遮挡表单，服务恢复后状态更新。
- [ ] 普通登录、redirect、用户/智能体初始化工作正常。
- [ ] 协议配置存在时强制确认，不存在时不展示无效控件。
- [ ] 锁定倒计时准确、可清理，后端仍为最终判断。
- [ ] 首次运行只显示超级管理员初始化，并能处理并发初始化冲突。
- [ ] OIDC 检查、手工登录、自动启动及失败降级正确。
- [ ] FoxOps 品牌配置完整替换模板和 Yuxi 硬编码内容。
