# 登录页改版设计

日期：2026-07-13  
范围：foxops-web 登录页视觉与布局，不改登录 API 契约。

## 目标

全屏底层背景视频 + 居中登录卡片；去掉注册、主题色切换、中英切换；仅保留光暗模式切换。

## 布局

1. 底层：全屏 video，静音、自动播放、循环、cover。
2. 遮罩：约 45% 暗色半透明。
3. 顶栏：左 Logo+网站名；右仅光暗切换。
4. 中间：单张登录卡片。

## 卡片内容（保留）

标题、UID/手机号、密码、拖拽验证、记住密码、忘记密码、登录按钮。

## 明确不做

注册入口、主题色切换、中英切换、左侧插画分栏。

## 视频资源

- 目录：foxops-web/public/videos/
- 主文件：login-bg.mp4（引用 /videos/login-bg.mp4）
- 可选：login-bg.webm
- 缺失时：遮罩+纯色兜底，不阻断登录

## 实现

改写 views/auth/login/index.vue 与 style.css，复用现有 fetchLogin 与验证逻辑。

## 验收

- 有视频时全屏循环
- 卡片居中可读
- 顶栏左 Logo 右光暗
- 无注册/主题色/语言切换
- 登录跳转与改版前一致
