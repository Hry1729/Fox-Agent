# 常见问题

## 为什么本地文件没有出现？

确认文件夹已添加、文件格式受支持且文件没有超过扫描大小限制，然后点击该文件夹右侧的重新扫描按钮。

## 为什么点击文件后无法预览？

文件可能已被移动、删除、占用、损坏或超过内置查看器限制。Fox 会显示错误，并提供系统打开或打开所在文件夹的入口。

## 加入知识库会修改原文件吗？

不会。Fox 会把文件复制到本地知识库的受管存储中，原文件保持不变。

## 本地知识会上传吗？

本地知识库文件和索引保存在你选择的本机存储位置。模型是否能看到检索结果取决于你使用的模型服务和当前对话配置；发送给模型的检索片段应按所选模型服务的隐私政策处理。

## 插件安装后为什么不能调用？

检查插件是否启用、是否分配给当前助手或专家、配置是否完整，以及当前项目权限是否允许相关工具运行。技能和连接器的开关、连接器健康检查在 设置 →「插件」里。

## 启动时弹出“Fox 无法启动”怎么办？

这是 Windows 上的系统提示框，表示 Fox 在启动时遇到了无法自动处理的问题，例如主数据库无法打开或升级失败。提示里会写出数据库或数据目录的路径和原因。Fox 不会删除数据库文件；数据库升级前的自动备份在数据目录的 `backups` 文件夹里。请先复制备份提示里的数据库文件，再把提示内容和启动日志发给维护人员。

资料库存储位置不可写、预览缓存目录异常这类问题不会阻止启动：资料库会进入只读或不可用状态并在设置的「资料库」页提示，预览缓存会在使用时报出带路径的错误。

## 如何让 Fox 更准确？

说明目标、材料、限制和验收标准；需要资料时明确指定知识库；只想讨论时写清楚“先不要执行”。
