# 工作区和文档

工作区用于查看项目文件、打开文档并配合 Agent 完成任务。打开文档时，Fox 会根据文件类型选择文本视图或只读预览。

## 安全边界

- Fox 只在已授权项目或你主动选择的文件夹中读写；
- 工具调用仍需遵守当前 Host 权限；
- 本地知识库不会自动获得项目目录之外的访问权限；
- 使用系统应用打开文件不会把文件上传到远端知识库。

## 设置页面

设置用于模型、连接、个人资料和应用级配置。

- 「模型服务」：同一个供应商可以配置多个协议（OpenAI Chat Completions、Anthropic Messages、OpenAI Responses），并指定外部 Agent 默认使用哪个协议。API Key 保存在系统凭据库里，按供应商地址在本机共享：地址相同的供应商共用同一把 Key，删除供应商也会删除这把 Key。
- 「外部 Agent」：选择新对话默认使用的 Agent、新外部对话是否默认完全访问，以及各外部 Agent 的默认权限。
- 需要确认或输入名称时，Fox 使用应用内的对话框。

进入设置前，Fox 会记录你来自哪个主页面；点击返回时应回到之前的对话、知识或其他主页面。
