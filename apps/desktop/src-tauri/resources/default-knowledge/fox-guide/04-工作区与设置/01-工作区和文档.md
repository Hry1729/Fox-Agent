# 工作区和文档

工作区用于查看项目文件、打开文档并配合 Agent 完成任务。打开文档时，Fox 会根据文件类型选择文本视图或只读预览。

## 安全边界

- Fox 只在已授权项目或你主动选择的文件夹中读写；
- 工具调用仍需遵守当前 Host 权限；
- 本地知识库不会自动获得项目目录之外的访问权限；
- 使用系统应用打开文件不会把文件上传到远端知识库。

## 设置页面

设置左侧有 7 个入口，分为三组：

- **偏好**
  - 「通用」：个人资料、外观（明暗模式、配色主题、文字大小、过程详情）、通知，以及「重新设置」向导。
  - 「对话」：消息输入（发送方式、拼写检查）和快捷键；快捷键可以恢复默认。
- **能力**
  - 「模型」：默认模型和模型服务列表。点右上角「添加服务」会弹出居中的对话框，按“服务模板 → 服务地址和 API Key（可测试连接）→ 模型 → 协议与高级（默认收起）”填写；点已有服务会在右侧打开编辑面板，可以保存或删除服务。同一个服务可以配置多个协议（OpenAI Chat Completions、Anthropic Messages、OpenAI Responses），并指定外部 Agent 默认使用哪个协议。API Key 保存在系统凭据库里，按服务地址在本机共享：地址相同的服务共用同一把 Key，删除服务也会删除这把 Key。
  - 「Agent」：通用助手（改名称、介绍、工作要求等）、默认模型、「外部 Agent」（新会话使用的 Agent、新外部会话是否使用完全访问、各外部 Agent 的默认权限）、专家列表（点专家直接打开编辑面板），以及「项目权限」（新项目权限、各项目的执行方式、打开 / 迁移目录、归档）。
  - 「插件」：技能、连接器和策略（生命周期 Hook），见“插件中心”一篇。
  - 「资料库」：本机存储（存储位置、向量模型、任务队列）、本机资料库列表、资料库服务连接和资料库账户。
- **系统**
  - 「数据与关于」：使用情况、诊断、预览缓存（已用空间、缓存上限、清理未使用缓存）、备份与恢复（备份、恢复数据、清理数据），以及版本、技术栈和许可。

旧的入口（例如“快捷键”“项目权限”“使用情况”“关于”“技能”“连接器”）仍然可以打开，会自动跳到上面对应页面里的那一组。

需要确认或输入名称时，Fox 使用应用内的对话框。

进入设置前，Fox 会记录你来自哪个主页面；点击返回时应回到之前的对话、知识或其他主页面。
