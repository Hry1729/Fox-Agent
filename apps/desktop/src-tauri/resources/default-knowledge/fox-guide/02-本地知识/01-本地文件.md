# 本机文件夹

除了把文件复制进资料库，你也可以把电脑上的一个文件夹直接收录到 Fox 中浏览。Fox 只读取你选择的文件夹，不会自动扫描整个磁盘。

## 收录文件夹

1. 进入左上角“资料”，打开“资料库”。
2. 点击“新建资料库”。
3. 在弹出的对话框里点“将本机文件夹作为资料库”。
4. 选择一个目录，Fox 会读取其中支持的文档并生成文件列表。

收录后，这个文件夹会出现在“资料库”页面和左侧“本机”分组里。收录只登记文件信息，不会移动、修改或删除原文件。

## 文件夹页面

- 右上角可以搜索文件名称、点击刷新按钮重新读取文件夹；
- 点击文件，或在文件的更多操作里选“打开”，会在 Fox 的弹窗中预览；
- 更多操作里的“在文件夹中显示”会在系统文件管理器中定位原文件；
- 预览弹窗右上角也有“打开所在文件夹”和“系统打开”。

如果某种格式不支持内置预览，Fox 会说明原因，可以改用“系统打开”。

在“资料库”页面的文件夹卡片上可以“编辑信息”（只改 Fox 中显示的名称和简介）或“移除文件夹”（只取消 Fox 中的收录，磁盘上的文件会保留）。

## 文件类型

支持文本、PDF、Word、表格和演示文稿，不同类型使用不同图标。具体能否预览取决于格式、文件大小和文件是否损坏。

本机文件夹里的文件不会被整理成可供模型检索的段落。需要让 Fox 在对话中查找内容时，请新建资料库并把文件添加进去。
