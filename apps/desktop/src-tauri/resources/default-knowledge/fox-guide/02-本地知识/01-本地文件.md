# 本地文件

“本地文件”用于登记你选择的文件夹，并在 Fox 中集中浏览其中受支持的文档。Fox 不会自动扫描整个磁盘。

## 添加文件夹

1. 进入顶部“知识”。
2. 打开“本地文件”。
3. 点击“添加文件夹”。
4. 选择一个目录，Fox 会扫描支持的文档并生成文件列表。

扫描只登记文件信息，不会移动、修改或删除原文件。你可以随时重新扫描，也可以取消管理某个文件夹。

## 文件操作

文件列表右侧提供三个操作：

- **加入知识库**：复制文件到指定本地知识库并创建解析任务；
- **打开**：优先在 Fox 的弹窗中预览；
- **打开所在文件夹**：在系统文件管理器中定位原文件。

直接点击文件行等同于“打开”。如果该格式不支持内置预览，Fox 会说明原因并提供“用系统应用打开”。

## 文件类型

PDF、演示文稿、Word 文档、电子表格和文本文件会使用不同图标，便于快速识别。具体可预览能力取决于格式、文件大小和文件是否损坏。
