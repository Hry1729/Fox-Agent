# 本地知识库

本地知识库把文件复制到 Fox 的受管存储中，并建立可供模型检索的文本分块。它与“本地文件”的原文件列表相互独立。

## 创建知识库

1. 进入“知识 > 本地知识库”。
2. 点击“新建知识库”。
3. 填写名称和可选描述。
4. 从本地文件页面加入文件，或在知识库详情中导入文档。

## Fox 使用指南

Fox 首次启动时会自动创建“Fox 使用指南”知识库。本知识库中的文档按主题文件夹组织，用于说明每个页面的用途、主要功能和操作方法。

## 存储位置

点击“存储位置”可以选择新的根目录。确认后 Fox 会迁移数据库、受管文件和索引；迁移完成后按页面提示重启 Fox。

迁移期间不要退出应用、断开目标磁盘或手动移动知识库目录。

## 在对话中使用

当本地知识库已绑定到助手或专家后，模型可以通过 Fox 的本地知识工具检索分块并引用来源。当前未启用向量模型时，Fox 会使用本地文本检索作为回退。
