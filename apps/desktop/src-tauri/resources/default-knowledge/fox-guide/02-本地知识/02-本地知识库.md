# 本机资料库

本机资料库把文件复制到 Fox 管理的存储位置，并整理成可供检索的段落。它与本机文件夹里的原文件相互独立，修改或删除资料库里的资料不会影响电脑上的原文件。

## 新建资料库

1. 进入“资料 → 资料库”。
2. 点击“新建资料库”。
3. 第一步“挑选文件”：从电脑的不同位置挑选文件，可以多次添加。
4. 第二步“命名”：填写名称和可选简介，选择搜索方式；“更多选项”里可以调整段落长度和搜索模型。
5. 第三步“导入”：文件在后台导入，可以继续浏览其他页面。

搜索方式有两种：

- **按字词查找**：速度快，适合找确切的名称和编号；
- **智能搜索**：能理解意思相近的说法，需要先在“向量模型”页面装好一个搜索模型。

之后可以在资料库页面通过“添加文件 / 添加文件夹”继续加入资料。文件的更多操作里有打开、重新处理、在文件夹中显示、下载原件和从资料库移除。

## Fox 使用指南

Fox 首次启动时会自动创建“Fox 使用指南”资料库。它的文档按主题文件夹组织，用于说明每个页面的用途、主要功能和操作方法。这是 Fox 自带的资料库，名称和搜索方式不能改，也不能删除。

## 存储位置

在资料库页面点击“存储位置”图标，或进入 设置 →「资料库」→「本机存储」→「存储位置」点击“修改位置”，可以选择新的根目录。确认后 Fox 会迁移数据库、受管文件和索引；迁移完成后按页面提示重启 Fox。

如果存储位置不可写（例如文件夹没有写入权限，或该路径其实是一个文件），Fox 仍会正常启动，但资料库暂时只读或不可用。资料库页面和设置的「资料库」页顶部会显示“知识库路径不可写：〈路径〉”和“修改存储位置”按钮；在弹出的对话框里可以选择另一个可写的文件夹，或恢复默认位置。

迁移期间不要退出应用、断开目标磁盘或手动移动资料库目录。

## 在对话中使用

在对话输入框的“添加内容”里添加资料库，或使用已经绑定资料库的专家后，模型可以通过 Fox 的资料库工具检索段落并引用来源。资料库没有开启智能搜索时，Fox 会使用按字词查找。
