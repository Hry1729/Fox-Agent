# 任务中心

任务中心（页面标题为“处理进度”）集中显示添加资料、读取、切分段落、写入搜索数据和存储迁移等任务。任务状态会写入本机数据库，因此刷新页面后仍可继续查看。从“资料”左侧导航的“任务中心”进入，也可以从设置的「资料库」→「任务队列」进入。

## 常见状态

- **排队中**：等待后台执行；
- **进行中**：正在复制、读取或整理；
- **已暂停**：任务暂时停止；
- **已完成**：任务成功结束；
- **只完成一部分**：批量操作中部分文件失败；
- **失败** 或 **已中断**：可以查看错误，并在条件允许时重试；
- **已取消**：你主动停止了任务。

进行中的任务可以取消，失败的任务可以重试。

## 使用建议

导入大量文件时可以离开当前页面继续使用 Fox。若应用异常退出，重新打开后任务中心会根据保存的检查点恢复或标记中断，不会把部分成功显示成整批失败。
