# 认识 Fox

Fox 是一个面向日常工作和专业任务的桌面 AI Agent。它把对话、专家、资料库、插件和项目放在同一个应用中，并由你决定哪些内容和能力可以被使用。

## 左上角的“助手”和“资料”

- **助手**：用于对话、选择专家、使用插件和处理项目任务。
- **资料**：用于管理本机资料库和本机文件夹，也能浏览已连接资料库服务中的远程资料库。

本机资料库完全保存在你的电脑上，可以编辑、重新整理和迁移存储位置；远程资料库由资料库服务维护，Fox 只能连接和使用。

## 左侧导航栏

进入“助手”后，你会看到新建对话、专家、插件、项目和对话列表。进入“资料”后，导航栏会切换为：

- **最近**：搜索资料内容、查看最近打开的资料和最近动态；
- **资料库**：所有本机资料库、本机文件夹和远程资料库；
- **向量模型**：安装和检查“智能搜索”用的搜索模型；
- **任务中心**：添加、读取和整理资料的处理进度。

下方的“本机”分组列出本机资料库和本机文件夹，连接资料库服务并登录后还会出现“远程”分组。

## 第一次使用建议

1. 先在“助手”里新建一个对话。
2. 直接描述你想完成的结果。
3. 如果任务需要专业方法，再选择一个专家。
4. 如果需要使用自己的资料，进入“资料 → 资料库”，点“新建资料库”添加文件，然后在对话输入框里添加这个资料库。
