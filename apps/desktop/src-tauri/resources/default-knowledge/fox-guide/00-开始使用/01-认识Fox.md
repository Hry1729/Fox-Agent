# 认识 Fox

Fox 是一个面向日常工作和专业任务的桌面 AI Agent。它把对话、专家、本地知识、插件和工作区放在同一个应用中，并由你决定哪些内容和能力可以被使用。

## 顶部的“助手”和“知识”

- **助手**：用于对话、选择专家、使用插件和处理项目任务。
- **知识**：用于管理本机文件和本地知识库。这里的内容可以编辑、重新导入和迁移存储位置。

助手页面中出现的远程知识库由远端服务维护，Fox 只能连接和使用；知识页面中的本地知识库完全保存在你的电脑上。

## 左侧导航栏

进入“助手”后，你会看到对话、专家、插件和项目等入口。进入“知识”后，导航栏会切换为本地文件、本地知识库和任务中心，避免把两类功能混在一起。

## 第一次使用建议

1. 先在助手页面新建一个对话。
2. 直接描述你想完成的结果。
3. 如果任务需要专业方法，再选择一个专家。
4. 如果需要使用自己的资料，前往“知识”添加文件夹并创建本地知识库。
