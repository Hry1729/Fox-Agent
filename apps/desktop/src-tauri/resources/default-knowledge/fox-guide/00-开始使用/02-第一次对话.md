# 第一次对话

在“助手”里点击左侧的“新建对话”，输入你的需求后发送即可。Fox 会在对话中持续显示模型回复、工具调用和任务进度。

输入框里可以：

- 输入 `/` 查看命令，输入 `@` 引用项目文件；
- 点“添加内容”添加附件或资料库；
- 用“执行方式”菜单切换：执行前询问、自动执行、只读模式。设置里对应的名称是询问、允许、只读。

## 推荐的表达方式

一条清楚的需求通常包含四部分：

1. **目标**：最终要得到什么。
2. **背景**：这件事为什么要做，有哪些已有信息。
3. **限制**：时间、格式、语气、不能修改的内容。
4. **验收标准**：怎样算完成。

例如：

> 帮我整理这个项目的安装说明，面向第一次使用 Fox 的用户；保留现有命令，增加 Windows 常见问题；最后输出一份 Markdown 文档，并检查所有路径是否有效。

## 对话中的专家

专家提供专业提示词以及它被允许使用的资料库、技能、连接器和工具配置，但不会突破 Fox 的项目权限。

在输入框中可以查看、更换或移除当前专家。更换专家时会继续使用当前对话，聊天记录会保留；任务正在运行时要等它结束后才能更换。
