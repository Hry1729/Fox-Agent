# 第一次对话

在助手页面点击“新对话”，输入你的需求后发送即可。Fox 会在对话中持续显示模型回复、工具调用和任务进度。

## 推荐的表达方式

一条清楚的需求通常包含四部分：

1. **目标**：最终要得到什么。
2. **背景**：这件事为什么要做，有哪些已有信息。
3. **限制**：时间、格式、语气、不能修改的内容。
4. **验收标准**：怎样算完成。

例如：

> 帮我整理这个项目的安装说明，面向第一次使用 Fox 的用户；保留现有命令，增加 Windows 常见问题；最后输出一份 Markdown 文档，并检查所有路径是否有效。

## 对话中的专家

选择专家后，专家胶囊会出现在输入框底部。专家提供专业提示词以及它被允许使用的知识库、Skills、MCP 和工具配置，但不会突破 Fox 的项目权限。

已经发送消息的对话切换专家时，Fox 可能建议新建对话，以免不同专家的上下文互相干扰。
