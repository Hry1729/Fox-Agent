# 连接器、技能和工具

## 连接器（MCP）

连接器把外部应用、数据源或本地服务接入 Fox。Fox 支持三种扩展类型：stdio MCP（启动一个本机命令）、Streamable HTTP MCP 和 OpenAPI 3.x Connector。添加时需要填写命令和参数，或服务地址；环境变量和请求 Header 只保存在系统凭证库，保存后不会再显示。

连接器在 设置 →「插件」→「连接器」中添加、开关、做健康检查、编辑和删除。Fox 内置的 CLI 连接器只能开关和做健康检查。

## 技能

技能是一组可复用的工作说明，告诉 Agent 在特定任务中应采用什么流程。技能更接近“方法”，只注入指令，不会获得新的工具权限。

技能来自 Fox 数据目录下 `skills` 文件夹中包含 `SKILL.md` 的子文件夹。在 设置 →「插件」→「技能」中可以查看和开关；校验失败的技能不能启用。

## 工具

工具是 Agent 在运行时可以调用的具体动作，例如读取文件、搜索资料、运行命令或查询服务。插件中心的“内置工具”分页列出它们的状态与兼容性。

## 使用范围

“已安装”不等于“所有对话都能使用”。专家只能使用它声明的技能、连接器和工具；在专家的编辑面板里可以通过“添加技能”“添加连接器”调整。所有调用仍要经过项目权限和审批。
