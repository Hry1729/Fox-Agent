# MCP、Skills 和工具

## MCP

MCP 服务把外部应用、数据源或本地服务连接到 Fox。启用前通常需要配置启动命令、地址或凭据。

## Skills

Skill 是一组可复用的工作说明和资源，告诉 Agent 在特定任务中应采用什么流程。Skill 更接近“方法”，不一定直接提供外部连接。

## 工具

工具是 Agent 在运行时可以调用的具体动作，例如读取文件、搜索知识、运行命令或查询服务。

## 启用范围

部分插件可以全局启用，部分插件只能分配给指定助手或专家。插件卡片会显示当前范围；需要精细配置时进入“配置范围”，不要把“已安装”误认为“所有对话都能使用”。
