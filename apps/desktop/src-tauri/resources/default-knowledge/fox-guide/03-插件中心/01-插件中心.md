# 插件中心

插件中心用于统一查看和管理 Fox 的 MCP、Skills 和工具。它是助手工作区中的独立页面，从左侧导航的“插件”进入。

设置里也有一个「插件」页（设置 →「插件」），用来管理已经有的技能、连接器和策略：

- **技能**：开关技能，点开可以查看详情；
- **连接器**：右上角「添加连接器」接入本机 MCP、HTTP MCP 或 OpenAPI，每个连接器可以开关、做健康检查、编辑或删除；
- **策略**：「生命周期 Hook」点「管理」后在右侧面板里增删 Hook；「工具插件」点「插件中心」回到插件中心的工具页。

从专家的“添加技能 / 添加连接器”进入设置的插件页时，页面顶部会出现“返回〈专家名〉”，点击后回到该专家。

## 页面结构

- 页面顶部是主标题、搜索和常用操作；
- 标题下方的胶囊用于切换 MCP、Skills、工具和“策略”；“策略”用于管理声明式 Hooks（例如在某些工具调用前强制审批或直接阻止）；
- “我安装的”用于查看已经安装的内容；
- “添加插件”用于安装用户自定义插件；
- 精选区域用于展示系统提供或远端市场可安装的插件。

## 安装前检查

安装插件前请确认来源、权限、执行命令和网络访问范围。插件可以扩展 Fox 的能力，但实际调用仍受项目授权和专家工具白名单限制。
