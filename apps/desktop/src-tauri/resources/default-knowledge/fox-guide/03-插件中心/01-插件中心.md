# 插件中心

插件中心用于查看 Fox 已经安装的内置工具、技能和连接器，以及管理工具调用策略。它是“助手”里的独立页面，从左侧导航的“插件”进入。

## 页面结构

- 页面顶部是标题“插件”和搜索框；
- 标题下方的分页用于切换“内置工具”“技能”“连接器”和“策略”；
- 前三个分页以卡片列出已安装的内容，卡片显示名称、说明、来源（内置、官方、社区、本机）和类型；如果插件不兼容或运行异常，卡片会直接显示错误原因；
- “策略”用于管理生命周期 Hook，例如在某些工具调用前强制审批、直接阻止或附加说明。Hook 不执行脚本，每次命中都会写入审计。

当前插件中心只展示已经安装的插件，还不能从这里安装新插件、开关插件或设置使用范围。

## 设置里的「插件」页

技能和连接器的日常管理在 设置 →「插件」：

- **技能**：开关技能，点开可以查看说明、需要的工具、来源和指令；
- **连接器**：右上角「添加连接器」接入本机 MCP、HTTP MCP 或 OpenAPI，每个连接器可以开关、做健康检查、编辑或删除（删除前会弹出确认）；
- **策略**：「生命周期 Hook」点「管理」后在右侧面板里增删 Hook；「工具插件」点「插件中心」回到插件中心的内置工具页。

从专家的“添加技能 / 添加连接器”进入设置的插件页时，页面顶部会出现“返回〈专家名〉”，点击后回到该专家。

## 添加前检查

添加连接器前请确认来源、执行命令、网络地址和需要的凭证。连接器可以扩展 Fox 的能力，但实际调用仍受项目权限、专家工具白名单和审批限制。
