# 助手和专家有什么区别

## 助手

助手是对话的主要执行者。它负责接收消息、调用模型、使用已授权工具并保存对话历史。

## 专家

专家是叠加在助手上的专业能力包。专家可以包含：

- 专业角色和工作方法提示词；
- 推荐的开场问题；
- 可选的本机或远程资料库；
- 技能、连接器和工具白名单；
- 默认模型建议。

选择专家不会自动扩大权限。实际可用能力始终是 Fox 当前授权、助手约束和专家声明的交集。

## 什么时候使用专家

- 需要固定的专业流程，例如产品评审、代码审查或研究分析；
- 希望多次复用同一种输出结构；
- 需要把一组资料库和插件作为一个组合使用。

普通问答不必先选择专家，直接使用默认助手即可。

## 新对话由哪个 Agent 执行

目前新对话都由 Fox 自己执行，支持上面的助手、专家、资料库和插件。

DeepSeek（DeepSeek Harness）、pi 和 Codex 这些外部 Agent 计划在之后的版本里恢复为可选项，现在还不能选择。以前用它们创建的对话可以打开查看，但不能继续。

## 权限

Fox 对话有四种执行方式，可以在输入框的“执行方式”菜单里切换，对话进行中切换后从下一步操作开始生效：

- **只读**：只读取，不写文件、不执行命令。
- **询问**：写入文件、运行命令和联网前都先问你。
- **自动**：项目内写入和低风险命令直接执行；高风险命令（例如删除整个目录、推送代码、提权、全局安装）和受保护的位置（例如 `.git`、项目以外的文件）仍会询问。
- **完全访问**：所有操作直接执行，包括项目外的文件。每个项目第一次开启时会请你再确认一次。

不论哪种方式，删除磁盘根目录、用户主目录或整个项目这类操作都会被直接拒绝。

请注意：Fox 不把命令放进隔离环境运行，命令就像你自己在电脑上执行一样。在“自动”和“完全访问”下，Fox 不会逐条询问，相当于你本人在操作；不放心时请使用“询问”或“只读”。每次自动执行的操作都会记录下来，可以在运行详情里查看。

询问时，命令的审批卡上可以选“本项目总是允许”，以后这个项目里以同样开头的命令就不再询问。按钮上会显示将要记住的命令开头，可以修改；记住的规则在 设置 → Agent →「项目权限」里打开对应项目即可查看和撤销。

新加入的项目默认用哪一种方式，在 设置 → Agent →「项目权限」→「新项目权限」里选；已有项目可以在同一组里逐个修改。
