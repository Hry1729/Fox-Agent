# 助手和专家有什么区别

## 助手

助手是对话的主要执行者。它负责接收消息、调用模型、使用已授权工具并保存对话历史。

## 专家

专家是叠加在助手上的专业能力包。专家可以包含：

- 专业角色和工作方法提示词；
- 推荐的开场问题；
- 可选的本地或远程知识库；
- Skills、MCP 服务和工具白名单；
- 默认模型建议。

选择专家不会自动扩大权限。实际可用能力始终是 Fox 当前授权、助手约束和专家声明的交集。

## 什么时候使用专家

- 需要固定的专业流程，例如产品评审、代码审查或研究分析；
- 希望多次复用同一种输出结构；
- 需要把一组知识库和插件作为一个组合使用。

普通问答不必先选择专家，直接使用默认助手即可。

## 新对话由哪个 Agent 执行

每个新对话在发出第一条消息时确定由哪个 Agent 执行，之后不能更换：

- **Fox**（默认）：Fox 自己执行，支持上面的助手、专家、知识库和插件；
- **DeepSeek**（DeepSeek Harness，实验）和 **pi**：外部 Agent，在沙箱中运行，使用「模型服务」里的供应商或它们自己的登录。

默认用哪个 Agent 在 设置 → 助手设置 →「外部 Agent」→「新会话使用的 Agent」里修改；新对话输入框里的 Agent 菜单只影响本次新对话。已有对话保持创建时的 Agent。Codex 暂时不在可选列表里，以前创建的 Codex 对话仍然可以打开和继续。

## 权限

- Fox 对话使用项目权限：只读、询问、允许。
- 外部 Agent 对话按该 Agent 自己的选项显示权限，例如 pi 的“只读 / 询问 / 自动”，DeepSeek 的“只读 / 工作区可写（询问）/ 工作区可写（不询问）”。
- “完全访问”是单独的开关：不套沙箱、不再询问。它只能在新建对话时选择（或在设置里打开“新外部会话使用完全访问”），对话进行中只能撤销，不能开启。
