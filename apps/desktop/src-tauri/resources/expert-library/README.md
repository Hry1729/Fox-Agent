# Fox 适配专家库

本库包含 20 个版本化专家包（1.1.0）。来源为 `agency-agents-zh` 的固定提交 `972452cdedef8d04fed4a8dd1dc10623e33ed412`，以 MIT 许可保留来源快照、许可证、文件哈希和适配说明。

`catalog.json` 是专家清单、具体工作流程和资源分配的维护入口。`upstream/` 是原始提示词及许可证；`packages/` 是可导入导出的 `.foxexpert` 文件；`bundled.json` 供 Fox 启动时校验并安装。运行仓库根目录的 `node scripts/build-expert-library.mjs` 可从固定本地来源重新生成；仅维护者主动更新来源时使用 `--fetch`。

适配保留各角色的方法和交付边界，加入 Fox 权限、证据、知识库、文件读回与视觉核验要求。角色身份不代表真实履历；原提示词中的泛化 KPI 不作为实际成效。知识库继承会话中用户真实选择的资源，不预设虚构的知识库 ID，也不增加外部账号权限。

20 个专家覆盖办公 5、研发 5、设计 4、通用 6。前端、代码审查和架构专家复用原 ID，其他 17 个新增；通用助手、调试和安全审计角色保留。旧会话保留绑定时的专家快照，新会话选择新版本。重复启动不会重置已安装版本、用户回滚和技能选择；用户本地或远程来源专家不会被此初始化覆盖。

Office 能力通过 `fox-office` 按需绑定，技能只提供指令，Host 继续检查工具范围和项目权限。前后端角色的 Office 能力限于读取和预览需求材料。审查角色不开放代码写入。

新代码必须重新构建并启动后才会在本机应用中加载本库；仅热更新前端不会运行数据库初始化。
