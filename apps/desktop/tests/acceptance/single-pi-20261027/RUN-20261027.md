**完整重启这一条的限定**：连续对话成立，但**不是**阶段二要求的"恢复同一个 Pi 原生会话"。数据库事实是：
`runs.runtime_session_id = null`、`runtime_sessions` 表为空、没有 `.jsonl` 会话文件。
当前的续聊靠 Fox 每轮把 SQLite 历史重新注入 Pi，而不是 Pi `SessionManager` 持有上下文。这正是阶段二要替换的机制，验收脚本如实把它标成"未验证"。

## 三 环境与过程中的事实

- debug 构建加载 `devUrl = http://127.0.0.1:1421`，必须先运行 `node scripts/start-desktop-dev.mjs`，否则窗口显示"127.0.0.1 拒绝连接"。发布构建（`tauri build`）内嵌 `dist`，没有这个前提。
- 首次启动出现引导页；模型服务一项在写入隔离库的同源 provider 后显示「当前状态正常 · 商汤 · sensenova-6.8-flash-lite · 可使用」，说明凭据库按 `base_url` 命中的假设成立。
- 启动日志有 `sandbox_installer_receipt_failed=sandbox_runtime_not_installed`：本机没有安装沙箱运行时包。本轮对话与模型调用不受影响；依赖 SRT 的命令执行类工具未验证。
- 资料库页面内置「Fox 使用指南」11 份资料（应用自带）。
