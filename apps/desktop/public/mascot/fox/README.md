# Fox Mascot Assets

This directory contains the extended Fox expression and action library.

## Categories

- `idle/`: quiet idle states used for random sidebar rotation.
- `thinking/`: reasoning, inspection, reading, planning, and note-taking.
- `tools/`: concrete computer, file, support, presentation, and repair actions.
- `status/`: success, failure, emotion, greeting, confirmation, and feedback.
- `fun/`: sports, music, travel, daily life, and other playful actions.

## Naming

- Use lowercase English names with underscores.
- Keep the `fox_` prefix.
- Prefer a concrete action or pose over numeric suffixes.
- Add new files directly to the matching category directory.
